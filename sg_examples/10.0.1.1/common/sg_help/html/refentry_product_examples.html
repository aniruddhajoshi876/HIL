Product Examples — Product Examples

Get Started with your Speedgoat I/O Modules

The product examples will get you up and running with your first application in no time at all. They will show you how to build and load a Simulink® model using a specific interface to your Speedgoat real-time target machine. They demonstrate the best approach to get started with your system and provide information on using the interfaces in the most suitable way.

You can be confident using our technologies and in knowing that we will provide additional support if required. If you would like to share your feedback, please complete this form. We want to learn from your experience and continuously improve the examples available.

The examples use MATLAB® Live Scripts. Each Live Script contains the documentation and code for one example and provides a step-by-step guide to running an example successfully.

Follow the links below to learn more about the examples available for your I/O modules.
