IO731 Usage Notes — Usage information about the I/O module

Configure gPTP

If you want to synchronize your target machine's clock with gPTP (IEEE 802.1AS), you need to configure the Ethernet interface of the IO731. The PTP daemon on your target is configured with the following commands:

Master 

tg.ptpd.Command = 'ptpd-avb -L -K -W -b wm1'

Slave 

tg.ptpd.Command = 'ptpd-avb -L -K -g -b wm1'

This example shows the basic set of options needed to configure the PTP daemon. Make sure these settings align with the configuration of the IO731 and the network.

Note

A valid IP address must be assigned to the Ethernet interface of the IO731 to be able to use PTP.

Refer to the Speedgoat Ethernet Configuration Tool help for more information.

For information on all the PTP options available, refer to the ptpd daemon documentation.

Connectors

The PPS output is synchronized by gPTP (IEEE 802.1AS). The amplitude of the signal is 3.3 V and has a pulse width of 200 ms.
