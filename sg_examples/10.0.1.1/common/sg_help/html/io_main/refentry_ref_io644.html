IO644 — Configurable CANopen Slave I/O module

Introduction

The IO644 is a configurable CANopen Slave I/O module. The solution is part of the IO64X/IO75X I/O module family which provides support for a wide range of industrial protocols. The IO644 module acts as one CANopen Slave exclusively.
