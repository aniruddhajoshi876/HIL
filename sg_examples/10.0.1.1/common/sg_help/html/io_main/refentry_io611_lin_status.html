IO611 - LIN Status

IO611 - LIN Status — This block provides status information from the LIN channel

Library

Simulink Real-Time - Speedgoat

Description

This block provides status information from the LIN channel.

Ports

Outputs
Op_Mode

This port can have the following values:

  • 0: the board acts as a slave

  • 3: the board acts as a master

Data Types:uint32

Baud Rate

The current configured baud rate.

Data Types:uint32

BusLoad

The current percentage (0..100) of LIN bus load.

Data Types:uint32

Data_Overrun

1 if data overrun occurred.

Data Types:uint32

Init_Mode_Act

1 if LIN controller is still in init mode.

Data Types:uint32

Parameters

Block Setup
Module ID

Specifies the ID of the IO61X module this driver block should be connected to. It must correspond to the module ID of the according setup block. Check the setup block help for more details.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. It can also be set to -1 for inherited sample time. The units are in seconds.

Get Status for Channel

Choose the LIN channel to which this driver block should be connected.

Status

In the "Status" tab, the user can select the required status signals. The selected signals appear as block outputs.
