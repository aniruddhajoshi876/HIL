Introduction

Speedgoat provides multiple A2B driver blocks for the -40 I/O interface extension.

The -40 I/O interface extension provides two A2B channels based on AD2433 transceivers, each configurable as a main or subordinate node. It supports high-fidelity, low-latency audio and control data transport over a single unshielded twisted pair cable, using I²S/TDM audio, I²C over distance, and GPIO over distance.

With configurable 44.1 kHz or 48 kHz audio sampling, standard power delivery up to 2.7 W per channel, and line diagnostics for detecting wiring and node faults, the -40 enables scalable A2B networks of up to 10 subordinate nodes. Speedgoat Simulink driver blocks provide full access to all TDM channels and support importing SigmaStudio® configuration files for rapid system integration.
