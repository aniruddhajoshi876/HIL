IO112

IO112 — High-resolution 16 or 18-bit simultaneous sampling analog input I/O module with 4, 8, 16, or 32 differential channels

Introduction

This I/O module implements 32 x 18-bit (16-bit as build option) simultaneously sampled differential analog input channels (a 16 channel build-option is also available). Each channel has a dedicated A/D converter resulting in very low sampling and conversion times.

Warning

This I/O module has an automatic calibration feature. During the calibration process various signals may be present at the output pins.
