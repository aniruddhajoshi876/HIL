IO203 - Read v2

IO203 - Read v2 — Reads the IO203 digital inputs

Library

Simulink Real-Time - Speedgoat

Description

The IO203 Read block is used to read the channels defined as digital inputs in the Setup block.

For each IO203 module, only one Read block is permitted.

Ports

This driver block has no input ports. The number of output ports is determined by the IO203 Setup block configuration, and the Port Configuration setting of the IO203 Read block. The channel configurations are transmitted by the Setup block; the Read block does not automatically request these configurations. If the Setup block is configured before the Read block is added to the model, then the Setup block must be reinitialized (by changing a setting and clicking Apply, or by updating the model) in order to update the new Read block.

The output ports can be configured in the following two ways:

1 port with a 64-element vector

One output port with a fixed width of 64 is used. The index of each array element is equivalent to the channel number. Each element has a value of either 0 (Low) or 1 (High). Array elements for channels that have not been configured as digital inputs remain 0.

1 port for each active input channel

For each channel configured as digital input, one port is added to the IO203 Read block. Each port outputs a scalar with a value of either 0 (Low) or 1 (High).

Data Type

Select either Boolean or Double as the output data type.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Port Configuration

Select one of the two available port types.

Data Type

Select the data type of the block output signals.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Show Read Ports Indices

This part of the mask shows which channels are selected to be inputs. Modifying this field will not influence the configuration.
