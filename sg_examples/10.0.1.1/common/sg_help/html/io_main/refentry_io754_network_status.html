IO754 - Network Status

IO754 - Network Status — Reads or writes the current network status

Library

Simulink Real-Time - Speedgoat

Description

The Network status block is common to all IO64X- and IO75X-supported protocols. The driver is available in the IO75X base library (speedgoatlib_IO75X). You can use this block to read or write the current network status:

  • 0: Network communication disabled

  • 1: Network communication enabled

Ports

Inputs
Network Status

Allows the Network Status to be set. Type uint8. This port is enabled or disabled by the "Set Status Port" parameter in the dialog box of this block.

Outputs
Network Status

Allows the Network Status to be viewed. Type uint8. This port is enabled or disabled by the "Get Status Port" parameter in the dialog box of this block.

Parameters

Module ID

This ID defines the link to the corresponding Setup block.

Get Status Port

Enable the "network status" output port.

Set Status Port

Enable the "network status" input port.

Sample Time [s]

Defines how often this block is updated.
