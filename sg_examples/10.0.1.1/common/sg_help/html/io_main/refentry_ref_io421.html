IO421

IO421 — The IO421 is an LVDT/RVDT and Synchro/Resolver converter I/O module

Introduction

The IO421 is a multi-functional I/O module supported by Speedgoat for the use with Simulink Real-Time.

The IO421 I/O module is a PCI device and has three independent slots. Each slot can be populated with a function-specific I/O sub-module listed in the table below.

ModuleFunctionalityNAI, Inc. Reference
IO421-1LVDT/RVDT measurementL*
IO421-2Synchro/Resolver measurementS*
IO421-3LVDT/RVDT simulation5*
IO421-4Synchro/Resolver simulation6*
IO421-5AC reference signal sourceW*

This manual provides I/O pin mapping information for LVDT/RVDT simulation (NAI, Inc. 5* module), and instructions on how to use the provided Speedgoat Simulink Real-Time drivers.
