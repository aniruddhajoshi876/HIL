IO672 - Create BC Message List

IO672 - Create BC Message List — Allocates space for a BC Message List

Library

Simulink Real-Time - Speedgoat

Description

This block allocates space for a BC Message List. It sets the messages in the list to no-op. This implies that the execution of a message on a given time step requires an Encode BC Message block to execute on that time step. The Create BC Message List block performs a clearing operation that allows you to control when a message is sent by placing Encode BC Message blocks in enabled subsystems.

Ports

Outputs
MSG List

BC Message List.

Parameters

Number of message buffers

The number of message buffers for the list. This block allocates an empty list for these buffers in Simulink Real-Time memory.

Note

This value must be equal to or less than the number specified in Number of Bus Controller buffers to allocate from the IO672 Initialize block.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
