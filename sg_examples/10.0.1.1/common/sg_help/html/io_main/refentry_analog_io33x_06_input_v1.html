Analog IO33x-06 - Input v1

Analog IO33x-06 - Input v1 — This driver block is available for the IO33x-06 module only.

Library

Simulink Real-Time - Speedgoat

Description

This driver block is available for the IO33x-6 module only.

Your model can only contain one of these blocks for each I/O module in your target machine.

Ports

This block has as many outputs as defined by the channel vector.

Outputs
X (X is channel number)

The value read from analog input X. Type double.

Parameters

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Channel Vector

A vector of channels this driver block entity will access. You can specify channels in the range 1-N (N = the number of channels implemented in your specific configuration file defined in the Setup block). The width of this vector also defines the subsequent size of some of the following parameters if scalar expansion applies. With a single block, all the channels of the block are synchronized.

Analog input range

For better accuracy, small voltages can be amplified - this parameter is used to indicate the expected input voltage range:

  • ± 10 [V]

  • ± 5 [V]

  • ± 2.5[V]

  • ± 1.25 [V]

Inter-module synchronization

This parameter defines if the model initiates the sampling. In this case the driver is an initiator. The "ADC trigger" physical pin becomes an output which propagates this signal. If the sampling is triggered by an external source, the driver is then configured as target. In this case the "ADC trigger" physical pin becomes an input used to read a trigger signal.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
