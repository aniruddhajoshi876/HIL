EVSE - Status

EVSE - Status — Reads status information from the EVSE board.

Library

Simulink Real-Time - Speedgoat

Description

The EVSE Status block reads status information from the EVSE charging board during the charge cycle and outputs the data to Simulink.

Ports

Outputs
Charging State

The charge state the EVSE charging board is currently in.

  • 0: Not connected or transitioning between states.

  • 1: Initialization

  • 2: Authentication

  • 3: Parameter Discovery

  • 4: Isolation

  • 5: Pre-Charge

  • 6: Charging

  • 7: Welding

  • 8: Stop

Data Type: double

Protocol

The charging protocol in use in the current charge cycle. Possible values are:

  • "ISO 15118"

  • "DIN 70121"

  • "IEC 61851"

  • "NotSupported"

Data Type: string

CP

Indicates the current Control Pilot (CP) state. The possible values of this topic are the CP states according to IEC 61851:

  • 1: State A - EV unplugged

  • 2: State B - EV connected

  • 3: State C - Ready / Charging

  • 4: State D - With ventilation

  • 5: State E - Power outage or short of the control pilot to PE

  • 6: State F - Error - unavailability of the charging station

Data Type: double

PP

Indicates the current Proximity Pilot (PP) state. The possible values of this topic are the PP states according to IEC 61851:

  • 0: Unknown

  • 1: Not connected

  • 2: Connected

  • 3: Connected but not latched

Data Type: double

PWM

Indicates the current PWM duty cycle in percent. The value of this topic is between "0" and "100" %.

Data Type: double

TCP

Indicates the status of the TCP connection between the EV and the EVSE. The possible values of this topic are:

  • 0: Disconnected

  • 1: TCP connection established

  • 2: TCP connection with TLS established

Data Type: double

Plug

Indicates the status of the plug lock on the customer side. The possible values of this topic are:

  • 0: unlocked

  • 1: locked

  • 2: unknown

Data Type: double

Parameters

Station ID

Defines the Station ID of the corresponding Setup block. Must range between 0 and 65535.

Connection ID

Defines the Connection ID of the corresponding Setup block. Must range between 0 and 65535.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
