OPC UA - Client Setup

OPC UA - Client Setup — Configures one OPC UA client station

Library

Simulink Real-Time - Speedgoat

Description

The Setup block configures one OPC UA client station, allows the Connection block to connect with OPC UA servers and enables the Read and Write blocks to exchange data on the network. Every OPC UA Client Setup block in the model requires a runtime license.

Ports

This driver block has no input or output ports.

Parameters

Station ID

The Station ID is used to assign Setup, Connection, Read and Write blocks to a particular client station. Station IDs range between 0 to 65535 and must be unique along all OPC UA Client and Server Setup blocks in a model. You can define multiple clients by placing a Setup block with a unique Station ID for each client.

Local IP Address

Enter the IP address of the OPC UA client. This step does not assign the IP address to an Ethernet interface. Instead, it binds the Setup block to an IP address which was previously configured in the Ethernet Configuration Tool. Refer to the OPC UA usage notes for further information.

There is no need to specify a TCP port as TCP ports are automatically assigned to clients.
