A2B - Remote GPIO

A2B - Remote GPIO — Access remote GPIO over A2B

Library

Simulink Real-Time - Speedgoat

Description

This block acquires the chosen remote GPIO.

Ports

Inputs
X (X is the GPIO number)

Value to set the chosen remote GPIO.

Enable

Controls whether the chosen GPIO is enabled or disabled.

Outputs
X (X is the GPIO number)

Value read from the chosen remote GPIO.

Parameters

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

A2B Interface ID

This parameter selects the physical A2B interface on the -40 I/O interface extension from which to read data.

Direction

Select the direction for the remote GPIO.

Node ID

Specify the ID of the subordinate node as indicated in the configuration file.

GPIO Number

Specify the number of the remote GPIO to control.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Show Enable Port

Select whether the enable input is active.
