MQTT Client — Simulink driver blocks for MQTT client

Introduction

Simulink driver blocks for MQTT client enable data to be exchanged with multiple remote MQTT brokers. Support for the MQTT client is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
