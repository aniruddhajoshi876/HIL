Analog IO325-160k

Analog IO325-160k — 8 x 16-bit ADCs up to 1.5 MSPS sampling rate, 4 x 16-bit DACs up to 10 MSPS update rate

Introduction

The IO325-160k I/O module provides the following analog functionality:

  • 8 x 16-bit ADCs up to 1.5 MSPS sampling rate with simultaneous sampling

  • 4 x 16-bit DACs up to 10 MSPS update rate

The Analog setup, Analog input and Analog output driver blocks are described in more detail in the following sections.
