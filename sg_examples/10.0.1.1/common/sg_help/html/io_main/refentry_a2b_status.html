A2B - Status

A2B - Status — Get status information of the A2B network

Library

Simulink Real-Time - Speedgoat

Description

This block provides status information about the A2B network and line fault diagnostics.

Note

Line fault diagnostics must be enabled and configured in SigmaStudio to be available.

Ports

Outputs
Status

General status information of the A2B network. The output is false if an error occurs.

Node

ID of the node on which the error has occurred. If the faulty node cannot be determined, "-1" is returned.

LineFault

Outputs the error code if a line fault has occurred. The following errors codes are defined:

  • 1: Cable shorted to GND

  • 2: Cable shorted to VBAT

  • 3: Cable shorted together

  • 4: Cable disconnected or open circuit (AD240x/10/2x only)

  • 5: Cable connected in reverse, wrong port or undetermined fault (all devices). Open circuit (AD243x only)

  • 11: Unknown short to GND

  • 12: Unknown short to VBAT

  • 21: Startup error

  • 255: Undefined error

Disc

Discovery status of the A2B network. The output is true if all the connected subordinate nodes are successfully discovered. If not, then the output is false.

ReDisc

Amount of bus re-discovery attempts.

NumSubs

Number of successfully discovered subordinate nodes.

Parameters

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

A2B Interface ID

This parameter selects the physical A2B interface on the front connector of the -40 I/O interface extension from which to read data.

Line Fault Diagnostics

Select if this output should be enabled.

Discovery Status

Select if this output should be enabled.

Number of Bus Re-Discovery

Select if this output should be enabled.

Number of Discovered Subordinate Nodes

Select if this output should be enabled.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
