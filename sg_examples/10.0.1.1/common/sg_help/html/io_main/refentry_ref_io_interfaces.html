IO33X I/O interfaces

IO33X I/O interfaces — Front I/O interfaces for the IO331, IO332, and IO333 configurable I/O modules

I/O Interfaces

The following front I/O interfaces are available for the IO332 and IO333 configurable I/O modules. Depending on the required I/O functionality, different digital standards and analog functionality are available.

  • IO33X-1-LV: 64 x digital LVTTL (3.3V) front I/O lines

  • IO33X-2: 30 x RS485 (RS422 compliant) front I/O lines

  • IO33X-3: 16 x CMOS (5V) and 22 RS485 (RS422 compliant) front I/O lines

  • IO33X-4: 30 x LVDS I/O lines

  • IO33X-5: 2 x 16-bit 105 MHz differential simultaneous analog inputs

  • IO33X-6: 16 x 16-bit 500kHz ADs, 8 x 16-bit DAs with 10 µs settling time, 16 x digital TTL I/O lines

  • IO33X-7: 16 x 16-bit analog outputs with 2µs settling time, +/- 10V

  • IO33X-8: 8 x 16-bit analog outputs with 2µs settling time, +/- 10V

Note

Further information on the I/O interfaces is also available in the HDL Coder help.
