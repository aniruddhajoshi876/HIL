EV - Charging Read

EV - Charging Read — Reads data from the EV board during the Charging state of the charge cycle.

Library

Simulink Real-Time - Speedgoat

Description

The EV Charging Read block reads data from the EV charging board during the Charging state of the charge cycle.

Ports

Outputs
EVSE Present Voltage

The charger's present voltage communicated to the EV.

EVSE Present Current

The charger's present current communicated to the EV.

EVSE Current Limit Achieved

A flag indicating that the charger has reached its maximum current limit.

EVSE Voltage Limit Achieved

A flag indicating that the charger has reached its maximum voltage limit.

EVSE Power Limit Achieved

A flag indicating that the charger has reached its maximum power limit.

EVSE Max Voltage Limit

The maximum voltage limit of the EVSE in volts.

EVSE Max Current Limit

The maximum current limit of the EVSE in amperes.

EVSE Max Power Limit

The maximum power limit of the EVSE in watts.

Parameters

Station ID

Defines the Station ID of the corresponding Setup block. Must range between 0 and 65535.

Connection ID

Defines the Connection ID of the corresponding Setup block. Must range between 0 and 65535.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
