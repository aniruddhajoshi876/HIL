OPC UA Client — Simulink driver blocks for OPC UA client

Introduction

Simulink driver blocks for OPC UA client enable data to be exchanged with multiple remote OPC UA servers. Support for OPC UA client is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
