IO624

IO624 — PSI5 and wheel speed sensor I/O module with eight channels

Introduction

The IO624 I/O module provides eight isolated automotive sensor emulator channels, which can act as PSI5 or wheel speed sensors. PSI5 provides asynchronous and synchronous data transmission and support including PSI5-A, PSI5-P, PSI5-U, PSI5-D, and PSI5-V bus topologies at both 125 kbps and 189 kbps transmission rates. The IO624 can also emulate wheel speed sensors using Square Wave, PWM, AK/VDA protocols, plus any other wheel speed sensor using different current levels up to 75 [mA].

Firmware Versions

Different firmware versions are supported for the IO624 I/O module. Newer firmware has additional or improved features.

If your firmware is old, but still supported, a warning message will appear on the Status Monitor of the RTTM at Model Load. Some older firmware versions are not supported with newer Speedgoat I/O Blocksets. In this case, an error will occur during Model Load. To update the firmware, please contact Speedgoat Support.

Versions

Firmware versions are represented in hexadecimal values.

Previous to 0x1000008: Not supported

  • 0x1000008: Old firmware still supported, but offers limited features

  • 0x1010000: Newest firmware
