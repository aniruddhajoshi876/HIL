IO682 - Update Scheduled Messages v4

IO682 - Update Scheduled Messages v4 — Updates ARINC 429 Scheduled Messages entries

Library

Simulink® Real-Time™ - Speedgoat

Description

This driver block allows ARINC 429 message entries in the scheduler to be updated.

Ports

Inputs
Msg

Defines the new content for the ARINC 429 message entry. The value can be created by using an ARINC 429 Encode block. Use a Mux block to update multiple scheduler entries at once.

Rate

Defines the new rate of the scheduled message. This value represents an integer multiple of 1 ms.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Message Index

Defines the message entry to update. Note that the indices are one-based. To update multiple messages at once, specify the indices as a vector.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Show Rate Input

Select whether the Rate Input should be available.
