IO106

IO106 — Fast 16-bit analog module with 64/32 multiplexed analog input channels

Introduction

Each channel has a dedicated A/D converter resulting in very low sampling and conversion times.

IO106-32/16 variant with 68-pin MDR connector (Item ID 2C106)

This simultaneous sampling I/O module implements either 32 single ended (31 in pseudo differential mode) or 16 differential analog input channels.

IO106-64/32 variant with 68-pin MDR connector (Item ID 2D106)

This simultaneous sampling I/O module implements either 64 single ended (63 in pseudo differential mode) or 32 differential analog input channels.

IO106-32/16 variant with 80-pin P50E80 connector (Item ID 2A106)

This simultaneous sampling I/O module implements either 32 single ended (31 in pseudo differential mode) or 16 differential analog input channels.

IO106-64/32 variant with 80-pin P50E80 connector (Item ID 2B106)

This simultaneous sampling I/O module implements either 64 single ended (63 in pseudo differential mode) or 32 differential analog input channels.

Warning

This I/O module has an automatic calibration feature. During the calibration process various signals may be present at the input pins.
