IO61X - LIN Write

IO61X - LIN Write — Send messages over LIN

Library

Simulink Real-Time - Speedgoat

Description

This LIN Write driver block is part of the generic block library for the IO611, IO612, IO613 and IO614 I/O modules. This block allows LIN messages to be transmitted. The message information (LIN version, ID, DLC) can be set in the block mask.

The buffer size is 20 messages per channel, so depending on the selected baud rate and the "LIN Write" block sample times, it is important to not let the input buffer overflow.

For each LIN message a single write block is required.

Ports

Inputs
Data

The number of bytes is defined in the block mask with the parameter DLC. Data Type: uint8

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel Number

Choose the LIN channel to which this driver block should be connected.

Channel Mode

Displays the channel mode (Disabled, Slave, Master) that has been set in the CAN and LIN Setup block for the selected Channel Number.

Message Type

Currently only the message type RAW is supported.

Show Enable Response Input

If this option is checked, an additional input port is created, which allows response messages to be enabled/disabled for the selected ID during untime. This option is only available when the Channel Mode is set to Slave.

DLC

Identifies the length of the LIN message data array (Data Length Code). The value can be chosen in the range of 1 through 8. When using the LIN Pack block, the parameter DLC must always be set to 8. For more information on using the LIN Pack block, refer to the usage notes of this I/O module.

Caution

LIN version 1.1 defines the DLC as a function of the ID (0-31: 2; 32-47: 4; 48-63: 8).

LIN version

Select the LIN version:

  • LIN 1.X representing versions 1.1, 1.2 and 1.3 uses Classic Checksum.

  • LIN 2.X representing versions 2.0, 2.1 and 2.2 uses Enhanced Checksum except for IDs 60 and 61.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
