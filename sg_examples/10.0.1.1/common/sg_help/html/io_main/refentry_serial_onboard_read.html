Serial Onboard - Read

Serial Onboard - Read — Reads the serial onboard ports

Library

Simulink Real-Time - Speedgoat

Description

This block is part of the Speedgoat Serial driver block set for the Speedgoat Serial Onboard supported real-time target machines. The Serial Read block reads characters from the onboard FIFO in the UART.

It then outputs those characters as the low-order byte of an unsigned 32-bit integer vector. This output vector is large enough to hold the maximum number of characters that the FIFO can hold.

Ports

Outputs
Count

Amount of received bytes.

Data

Data output signal.

Block Parameters

Machine Type

Select the type of your real-time target machine.

Port

This parameter specifies the port from which this block reads the data.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Enable Legacy Mode

This checkbox can be used to enable/disable the legacy mode of the Serial Read block. If this mode is enabled, the Data output contains a vector where the first element of the vector specifies the number of data elements in the remainder of the vector. Please refer to the Serial Usage Notes for additional information about the legacy mode.

Output Data Type

Select the output data type from a list of standard data types[3]
