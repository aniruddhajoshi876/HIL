IO643 - NMT

IO643 - NMT — Controls the network state of CANopen slaves

Library

Simulink Real-Time - Speedgoat

Description

The IO643 NMT (Network Management) block is used to control the network states of the CANopen slave devices connected with the I/O module.

Your model can contain only one NMT block for each I/O module in your target machine.

Ports

Inputs

The input port expects the desired network states for the remote slave devices. The vector length equals the number of elements in the CAN Node ID parameter. The input's first element corresponds to the slave device whose CAN node ID is specified in the first element of the parameter's vector. The block sends a state change request to a slave device each time the corresponding input value changes.

The block only processes the following values:

StateDescription
1Operational
2Stop
128Pre-operational
129Reset node (Initialization)
130Reset communication (Initialization)

Data Type: scalar|vector of uint32

Note

By default, the IO643 sends node start commands to all slave devices in the network right after model initialization or model start (the time depends on the Start of bus communication parameter in SYCON.net). This causes the slave devices to switch to operational state without regard to the states specified at the NMT block's input port. To prevent the IO643 from sending start commands by default, clear the Send Global Start Node, Send the Reset-Node command and Send the Start-Node Command checkboxes in the SYCON.net project. This makes the NMT block the only source for sending change state requests.

Outputs

This block does not have any output ports.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

CAN Node ID

The addresses of the slave devices to be controlled. Each device has a unique address between 1 and 127. The values must match the addresses of the related nodes in the SYCON.net configuration file.

Data Type: numeric scalar|vector

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.
