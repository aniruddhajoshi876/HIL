IO752 - Receive v2

IO752 - Receive v2 — Receives cyclic data from the PROFINET network

Library

Simulink Real-Time - Speedgoat

Description

This block is used to receive cyclic data from the PROFINET network. To use, your Simulink model must contain one of these driver blocks for each IO752 I/O module installed in your target machine.

Ports

Depending on the value of the Port Type parameter, this block will have:

  • n output ports of type uint8, where n is defined by the Input Data Bytes parameter, or

  • 1 output port which is a vector with n elements, where n is defined by the Input Data Bytes parameter

Outputs (n ports of type uint8)
1

Data byte to receive. Type uint8.

X (X is the port number, between 1 and the value in the Input Data Bytes parameter)

Data byte to receive. Type uint8.

Outputs (1 port with n element vectors)
In

A vector of data bytes to receive. The number of elements in the vector is defined by the Input Data Bytes parameter.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Port Type

The type of the input/output ports. The options are:

  • n ports of type uint8 to have an input/output port for each signal

  • 1 port with n element vector of type uint8 to have a single vector with an element for each signal

Output Data Bytes

The number of bytes that are received from the PROFINET device. TIP: Use the "Byte Unpack" block to send the data.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.
