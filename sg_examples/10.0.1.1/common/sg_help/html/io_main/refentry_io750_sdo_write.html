IO750 - SDO Write

IO750 - SDO Write — Writes data to local EtherCAT Service Data Ojects

Library

Simulink Real-Time - Speedgoat

Description

This block is used to write the service data objects of the subordinate device. Use the IO750 Setup block to define those objects. On the network side the objects can be read and written by the EtherCAT main device.

Your model can contain only one SDO Write block for each I/O module in your target machine. This single block handles all SDO writing accesses of the model to the SDO dictionary.

Your model must contain one Setup block and one SDO Read block for proper SDO communication. The SDO Write block is optional.

Caution

This block is only supported by MATLAB from R2019b.

Ports

Inputs

This block has one input port for each SDO defined in the SDO table in the Setup block whose Access Mode is "write" or "read-write". The type of the port depends on the property Data Type. The Name of the port will be assembled with the properties Index, Sub Index and Name.

If no SDO has Access Mode "write" or "read-write" then the block will have no input ports.

Outputs

This block does not have any output ports.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.

Retrieve SDO Configuration

Retrieves the SDO configuration from the related Setup block and updates the input ports.
