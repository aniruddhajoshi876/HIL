IO133

IO133 — Fast simultaneous sampling 16-bit analog input and output module

Introduction

The IO133 I/O module is a 16-bit analog and digital module providing 16 simultaneous sampling differential analog input channels, 8 simultaneous update single-ended analog output channels and 14 digital TTL I/O lines.

  • 16 analog input channels featuring:

    • True differential inputs

    • Simultaneous sampling

    • Voltage ranges of ±5 V and ±10 V (one common setting for 8 channels)

    • Maximum sample rate: 200 kS/s

    • Oversampling capability with digital filter

    • Frame based autonomous data transfer (DMA)

  • 8 analog output channels featuring:

    • Single-ended outputs

    • Simultaneous update

    • Voltage ranges of 0–5 V, 0–10 V, 0–10.8 V, ±5 V, ±10 V and ±10.8 V (individual setting for each channel)

    • Settling time 10μs

    • Frame based autonomous data transfer (DMA)

  • 14 digital I/O channels featuring:

    • Output driver LVTTL 3.3 V (5 V output selectable - only for high-impedance loads)

    • Input driver 5 V tolerant

    • Configurable debounce filter

    • ESD protection

Note

This driver version does not yet support temperature compensation.
