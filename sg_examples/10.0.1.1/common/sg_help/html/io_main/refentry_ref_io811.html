IO811

IO811 — The IO811 is a Camera Link® frame grabber I/O module

Introduction

The IO811 I/O module provides real-time image acquisition and processing for multiple industrial applications.

The driver for the IO811 I/O module can be accessed via the Speedgoat I/O Blockset. Note that from I/O blockset version 9.1.3, the driver block is named Speedgoat IO811.

Driver Block

  • Setup

Port

This driver block supports the BitFlow™ Neon-CLB board with one camera port as well as a camera that is compliant with Camera Link®. The Speedgoat IO811 Setup block acquires real-time video frames or still images from a Camera Link camera.
