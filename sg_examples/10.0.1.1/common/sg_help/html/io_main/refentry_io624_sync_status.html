IO624 - Sync Status

IO624 - Sync Status — Reads sensor synchronous status information

Library

Simulink Real-Time - Speedgoat

Description

Your model can only contain one of these blocks for each I/O module in your target machine.

When PSI5-U/P (Synchronous without Daisy Chain) is selected in the Setup block, the Sync Status block provides sensor synchronous status information for the specified channel in the corresponding Setup block.

Ports

Outputs
X (X is the sync status channel number)

The following values are obtained from Sync Status Channel X:

  • 0 - No unexpected sync pulse detected yet

  • 1 - Absence of the sync pulse during the expected time window

  • 2 - Too short for a short pulse

  • 3 - Too long for a short pulse OR too short for a long pulse

  • 4 - Too long for a long pulse

  • 5 - Long pulse instead of expected short pulse detected

  • 6 - Data Frame FIFO (Send block) is full*

Data Type: double

Note

*6 - Data Frame FIFO (Send block) is full

If one pulse message status (1 to 5) shows at the same time as message 6, the output value will be the sum of both messages; for example, if the sync pulse does not occur during the expected time window (1) and the Data Frame FIFO is full (6), this will result in a value of 7.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
