IO682 - Send v3

IO682 - Send v3 — Transmits ARINC 429 messages

Library

Simulink® Real-Time™ - Speedgoat

Description

This block allows ARINC 429 messages to be transmitted and can be placed in your model as many times as required.

Ports

Inputs
X (X is the channel number)

ARINC 429 message to send.

Parameters

The configuration details are all defined in the setup block.

Module ID

This ID defines the link to the corresponding Setup block

Channel

Defines from which channel the message will be sent.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
