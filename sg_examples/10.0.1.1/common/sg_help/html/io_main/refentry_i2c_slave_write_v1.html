I2C - Slave write v1

I2C - Slave write v1 — The I2C Slave write driver block allows data to be written to any register in the register bank of the code module. This write operation is asynchronous with the I2C protocol.

Library

Simulink Real-Time - Speedgoat

Description

The I2C Slave write driver block allows data to be written to any register in the register bank of the code module. This write operation is asynchronous with the I2C protocol.

Ports

This driver block has one input port.

Inputs
Data

The data to write to the registers. The input port width is equal to the number of registers as configured in the Registers parameter.

Parameters

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Channel

The number of the channel which this driver block entity will access. Only one channel per driver block can be addressed. You can specify channels in the range 1-N (N = the number of channels implemented in your specific configuration file defined in the Setup block).

Registers

A vector which defines the registers to write. Registers are numbered in the range 1 to 256.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
