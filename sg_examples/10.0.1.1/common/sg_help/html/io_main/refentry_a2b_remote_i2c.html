A2B - Remote I2C

A2B - Remote I2C — I2C communication to remote devices over A2B

Library

Simulink Real-Time - Speedgoat

Description

This block reads or writes data from or to the specified peripheral I2C device via an existing A2B main node.

Ports

Inputs
Data Count

Number of data bytes to read or write.

I2C Addr

I2C address of the specified device from which to read or write.

Reg Addr

I2C register address of the specified device from which to read or write.

Data

Data to transmit to the specified I2C device. This input port is only active when Direction is set to Write.

Enable

Controls whether data transmission is enabled or disabled. This input port is only active when Show Enable Port is selected.

Outputs
Data

Received data bytes from the specified I2C device. This output port is only active when Direction is set to Read.

Parameters

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

A2B Interface ID

This parameter selects the physical A2B interface on the -40 I/O interface extension for remote I2C access.

Note

I2C remote accesses only are possible when the corresponding A2B Interface ID is acting as a main node.

Direction

Select the direction for the I2C peripheral device.

Node ID

Specify the ID of the subordinate node as indicated in the configuration file for the remote I2C access.

Buffer Size

Specify the maximum number of bytes expected for reading or writing data.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Use 2-Byte Register Address

Select whether the register address is one or two bytes long.

Show Enable Port

Select whether the enable input is active.
