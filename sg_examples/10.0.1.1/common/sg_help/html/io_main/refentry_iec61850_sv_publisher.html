IEC 61850 - Sampled Values Publisher

IEC 61850 - Sampled Values Publisher — Publishes SV data through MAC addressing.

Library

Simulink Real-Time - Speedgoat

Description

This block is used to publish data to the network using a destination MAC address. Your model can contain multiple IEC 61850 SV publisher blocks and requires at least one IEC 61850 Client or Server license.

Ports

Inputs
Input

Array of dynamic length that is published to the given Destination MAC Address. The data type is specified by the Message Data Type parameter.

Use Byte Pack blocks to convert to signed values or floating-point numbers. You can pack one double value to a vector of type int8 and length 8.

Outputs

This block does not have any output ports.

Parameters

Ethernet Port

Define from which local Ethernet port SV messages should be published. The internal Ethernet interfaces of Speedgoat target machines have for example 'ETH1' as an available port.

Message Data Type

Select one of the data types listed in the dropdown list:

  • Int8

    1-byte signed integer.

  • Double

    8-byte floating point.

  • Quality

    4-byte unsigned integer.

Append Time Stamp to Broadcast

The SV Publisher has a functionality to append a time stamp value to the payload. The time stamp in the message represents the time at which the values have been updated during a poll. The time is taken from the operating system. To synchronize the date and time of your target machine with the host date and time, execute the following command in the MATLAB console:

>> speedgoat.setTargetTime;

Polling Time

The polling time is the time interval between publishing SV messages. Must range between 0 and 360,000 milliseconds, which corresponds to a maximum of 6 minutes. The default value is 50 ms.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Application Service Data Unit Name

Name the ASDU for better readability of the published messages.

Destination MAC Address

Define the multicast/broadcast MAC address of the SV message. For the purpose of broadcasting use ff:ff:ff:ff:ff:ff.

Sampled Values App ID

The SV app ID will be inserted into the published message. This way you can filter the messages when publishing on the same MAC address.

VLAN ID

The VLAN identifier is used to tag a message. The values of 0 and 4095 (0x000 and 0xFFF in hexadecimal) are reserved. All other values may be used as VLAN identifiers, allowing up to 4,094 VLANs.

Refer to this webpage for further information about VLAN parameters: IEE_802.1Q Wiki.

VLAN Priority

The VLAN priority (Priority code point 'PCP') sets the priority level of the message.

Refer to this webpage for further information about VLAN parameters: IEE_802.1Q Wiki.
