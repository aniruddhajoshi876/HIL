IO752 - Record

IO752 - Record — Adds records to the device's record list and allows remote PROFINET controllers to read and write these records

Library

Simulink Real-Time - Speedgoat

Description

This block adds records to the local PROFINET device's record list. Use one block for each record you want to define. Access the record's value using the block's input and output ports. On the network side, remote PROFINET controllers read and write the records via acyclic communication.

Caution

This block replaces the IO752 Record Read and Record Write blocks. Those blocks are obsolete. Do not define records in the Record Configuration parameter of the related Setup block when using the IO752 Record block.

Ports

Inputs
Data

The value that should be written to the local record. The port inherits the data type and the dimensions from the Init Value parameter. This port is just a buffer. The length to be written can be less than the port size and can be defined by the Length input port.

Data type: Fundamental data types from boolean to double are supported as well as dimensions from scalar values to vectors

Enable

The block writes data to the record as long as this input port is TRUE.

Best practice is to set the block's sample time to a higher rate (like 1 ms) and trigger the Enable input port at a lower rate. This allows event-based writing of the value as well as immediate updates of the output ports.

Data type: boolean

Length

The actual size of the data that should be written to the record, specified in number of bytes.

If enabled by the Extended Interface parameter, the port limits the size of the data to be written to the record. In this case, the block writes a subset of the signal connected with the Data input port.

If disabled, the entire signal connected with the Data input port will be written to the record.

If the data size that remote PROFINET controllers want to read exceeds the size last written, the device replies with the actual data size.

Data type: uint32

Outputs
Data

Outputs the current value of the record. The port inherits the data type and dimensions from the Init Value parameter. This port is just a buffer. Depending on the size of the data that was last written to the record, the port fills up the buffer with zeros. The Length output port outputs the actual size.

Data type: Fundamental data types from boolean to double are supported as well as dimensions from scalar values to vectors

Status

A rising or falling edge indicates a completed write operation. The record's value was either written by the block's input ports or by a write request from the remote PROFINET controller.

If this output does not change, the write operation is still in progress or the block is idle.

Data type: uint32

Length

The actual size of the data that was last written to the record. Defined in number of bytes. As remote PROFINET controllers are allowed to write less than the default size, the actual size can be less than the size of the Data output port.

Data type: uint32

Parameters

Module ID

This ID defines the link to the corresponding Setup block

API

The API of the module to which the record belongs. Valid values are between 0 and 0xFFFFFFFF.

Slot

The slot of the module to which the record belongs. Valid values are between 0 and 0xFFFF.

Sub-Slot

The sub-slot of the sub-module to which the record belongs. Valid values are between 0 and 0xFFFF.

Index

Enter the index of the record within the respective sub-slot. Corresponds to the XML attribute Index of the related ParameterRecordDataItem in the GSDML file. Valid values are between 0 and 0xFFFF

Init Value

The default value of the record. The value implicitly defines the size of the local record. The Data output port outputs this value until the first write request is received from the remote PROFINET controller. The other way round, the PROFINET controller reads this value as long as the record is not overwritten by the signal connected to the Data input port. The Init Value corresponds to the XML attribute Data of the related ParameterRecordDataItem in the GSDML file.

Data type: Fundamental data types from boolean to double are supported as well as dimensions from scalar values to vectors.

Operation

This parameter defines the local operation on the record's value. You can read or write the value, or do both. Write enables the input ports. Read enables the output ports.

Extended Interface

If selected, the block shows the Length input port, the Status output port and the Length output port. Otherwise, the ports are hidden.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.
