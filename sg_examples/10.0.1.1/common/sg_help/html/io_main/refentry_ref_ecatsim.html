EtherCAT SubDevice Emulator

EtherCAT SubDevice Emulator — Simulink driver blocks for the native EtherCAT SubDevice Emulator interface

Introduction

Simulink driver blocks for the EtherCAT SubDevice Emulator enable data to be exchanged with a remote EtherCAT main device. Support for the EtherCAT Emulator is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
