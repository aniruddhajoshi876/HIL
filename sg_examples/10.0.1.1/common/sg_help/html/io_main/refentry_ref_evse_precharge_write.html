EVSE - Pre-Charge Write

EVSE - Pre-Charge Write — Writes data to the EVSE board during the Pre-Charge state of the charge cycle.

Library

Simulink Real-Time - Speedgoat

Description

The EVSE Pre-Charge Write block writes data to the EVSE charging board during the Pre-Charge state of the charge cycle.

Ports

Inputs
Isolationstatus

Set the chargers isolation status following enumeration table "isolationLevelType" of ISO 15118-2.

  • 0: Invalid

  • 1: Valid

  • 2: Warning

  • 3: Fault

  • 4: No isolation monitoring device (IMD) present

Statuscode

Set the charger's status following enumeration table "DC_EVSEStatusCodeType" of ISO 15118-2.

  • 0: Not Ready

  • 1: Ready

  • 2: Shutdown

  • 3: Utility interrupt event

  • 4: Isolation monitoring active

  • 5: Emergency shutdown

  • 6: Malfunction

Present Voltage

Set the charger's present voltage communicated to the EV.

Parameters

Main Tab
Station ID

Defines the Station ID of the corresponding Setup block. Must range between 0 and 65535.

Connection ID

Defines the Connection ID of the corresponding Setup block. Must range between 0 and 65535.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Enable/Disable Signals Tab

Some settings, like min. and max. voltage limits, are already set by the Setup block but can be overwritten during the Parameter Discovery state of the charge if desired. However, unused signals that remain unconnected are set to zero. To avoid setting parameters to zero, unused signals should be unchecked here to disable the write operation.
