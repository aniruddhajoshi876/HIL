Analog IO33x-08 - Output v1

Analog IO33x-08 - Output v1 — This driver block is available for the IO33x-08 module only.

Library

Simulink Real-Time - Speedgoat

Description

This driver block is available for the IO33x-8 module only.

Your model can only contain one of these blocks for each I/O module in your target machine.

Ports

This block has as many inputs as defined by the channel vector.

Inputs
X (X is channel number)

The value to set the analog output X to. Type double.

Parameters

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Channel Vector

A vector of channels this driver block entity will access. You can specify channels in the range 1-N (N = the number of channels implemented in your specific configuration file defined in the Setup block). The width of this vector also defines the subsequent size of some of the following parameters if scalar expansion applies. With a single block, all the channels of the block are synchronized.

Update mode vector

Select how the update of each DAC channel should be done 0: Update will be done from the Simulink Model over PCI 1: Update will be done over inter-board SPI communication if used in a multiple IO3xx setup

SPI channel (1-8)

Select the SPI channel, with which the DAC update should be configured (for Update Mode "SPI" only).

Position in the SPI frame (1-8)

Select the position in the SPI frame, that is used to update the DAC channel (for Update Mode "SPI" only).

Initial Values

Define the initial signal level present on the outputs after the application has been downloaded. The values can be set individually by entering a vector: the value at a certain position in the Initial Values vector is applied to the channel as defined in the Active Channels vector. A scalar value applies to all the channels; for example, for individual values, type "[1 1.5 0 2.5]", and to set all channels to zero, type "0".

Reset to Initial Values

Define whether the initial values are also applied once the application has stopped. The behavior can be set individually for each channel using a vector. A scalar value applies to all the channels; for example, for individual values, type "[1 0 0 1]", and to set all channels to zero, type "0". "1" means use the Initial Value and "0" means keep the latest value.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
