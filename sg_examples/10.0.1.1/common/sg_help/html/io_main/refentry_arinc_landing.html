ARINC 429, ARINC 629 and AFDX

ARINC 429, ARINC 629 and AFDX — Speedgoat I/O modules for Communications Protocols

Introduction

ARINC 429, ARINC 629 and ARINC 664 Part 7 (AFDX) are data bus standards widely used in avionics.

Speedgoat provides a range of I/O modules for communicating with devices supporting these protocols, all of which come with Simulink driver blocks.

I/O modules

IO629 ARINC 629 I/O module with emulation of up to 240 Remote Terminals
IO682 Intelligent ARINC 429 I/O module featuring 2 to 16 RX channels, and 2 to 16 TX channels
IO781 AFDX (ARINC 664 Part 7) I/O module supporting the simulation of multiple ARINC 664 End Systems on a single I/O module
ARINC 825 Blockset for ARINC 825 with up to 4 independent channels
