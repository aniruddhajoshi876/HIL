BMTS Write

BMTS Write — Configure the BMTS Write block

Library

Simulink Real-Time - Speedgoat

Description

Note

This documentation refers to the Speedgoat Battery Management Testing Systems (BMTS) that are supported with MATLAB R2022a and later.

The BMTS Write block consists of a masked subsystem with a MATLAB App-based block mask. The subsystem is dynamically populated with a set of preconfigured EtherCAT Send blocks to send the data to the selected device. The list of devices is automatically loaded from the BMTS Setup block with the same EtherCAT Network Index.

Ports

This driver block has one input port.

Inputs
Data

The data port takes a Simulink bus signal, the structure of which depends on the selected device. The Simulink bus object and a template structure for initialization are created in the MATLAB workspace after the block has been configured. It is recommended to use a Bus Assignment block to set the values of individual signals contained in the bus signal.

Parameters

EtherCAT Network Index

The EtherCAT Network Index is a user-defined ID to associate the BMTS Write block with the corresponding BMTS Setup block. The value must be an integer between 0 and 11. When changing the network index, click the Reload device list button to load the list of devices from the BMTS Setup block.

EtherCAT Device

Selects the device to which the BMTS Write block will send data.

Sample Time

The sample time is displayed here, however, it must be configured in the corresponding BMTS Setup block. This is because the sample time for EtherCAT is set globally and written to the ENI (EtherCAT Network Information) file. Therefore, individual BMTS Write blocks must all use this globally configured sample time.
