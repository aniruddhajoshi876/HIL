CAN Message Utilities: E2E Profile 1 Protect

CAN Message Utilities: E2E Profile 1 Protect — Extracts a previously inserted counter value from CAN or CAN FD message payload and compares it against a reference counter.

Library

Simulink Real-Time - Speedgoat

Description

The E2E Profile 1 Protect block implements the transmitter-side logic of the AUTOSAR E2E Profile 1 specification. The block computes the Counter and the CRC over the message data and inserts them into the message. This ensures data integrity during transmission and allows the receiver to detect any corruption in the message contents. Data ID, Data ID Mode, Counter location and byte location are configurable.

For in-depth documentation about the E2E Profile 1 please refer to the relevant AUTOSAR documentation.

Ports

Which input and output ports are available depends on the configuration settings in the block mask:

Input
Input Port

This input port is always available and its datatype (either CAN_MESSAGE_BUS, CAN_FD_MESSAGE_BUS or a uint8 array with a maximum length of 256 bytes) is configured by the Protocol parameter in the block mask.

Outputs
Protected Output

This port outputs the E2E Profile 1 protected version of the Input signal. Its datatype (either CAN_MESSAGE_BUS, CAN_FD_MESSAGE_BUS or a uint8 array with a maximum length of 256 bytes) is configured by the Protocol parameter in the block mask.

Parameters

Counter Offset

Specifies the location where the Counter is inserted. The value is expressed in bits and is zero-based.

CRC Offset

Specifies the location where the CRC is inserted. The value is expressed in bits and is zero-based.

Data ID

Specifies the Data ID number used for CRC calculation. Data ID must be between 0 and 65535.

Data ID Mode

Specifies the way Data ID is included in the CRC calculation. Available options are BOTH, ALT and LOW. Refer to the relevant AUTOSAR documentation for a detailed explanation of these modes.
