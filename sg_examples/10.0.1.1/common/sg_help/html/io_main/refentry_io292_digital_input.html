IO292 - digital input

IO292 - digital input — Reads the IO292 digital inputs

Library

Simulink Real-Time - Speedgoat

Description

Your model can only contain one of these blocks for each I/O module in your target machine.

Ports

This driver block has no input ports. The number of output ports is determined by the number of digital input channels selected, and the Port Configuration setting.

The output ports can be configured in the following two ways:

1 port with a 24-element vector

One output port with a fixed width of 24 is used. The index of each array element is equivalent to the channel number. Each element has a value of either 0 (Low) or 1 (High). Array elements for channels that have not been configured as digital inputs remain 0.

1 port for each active input channel

For each channel configured as digital input, one port is added. Each port outputs a scalar with a value of either 0 (Low) or 1 (High).

Data Type

Select either Boolean or Double as output data type.

Parameters

The configuration details are all defined in the Setup block.

Module ID

The Module ID has two functions:

  • It defines the logical connection between the Setup block and its I/O blocks

  • It also informs the auto-search feature of the PCI Slot parameter. If only one I/O module of this type is installed, the Module ID must be set to 1. If n modules are installed, it must be in the range 1:n. Not all the I/O modules installed in the target machine need to be used. To see how each I/O module maps to a Module ID, use this Speedgoat API: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat")
Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Port Configuration

Select one of the two available port types.

Data Type

Select the data type of the block output signals.
