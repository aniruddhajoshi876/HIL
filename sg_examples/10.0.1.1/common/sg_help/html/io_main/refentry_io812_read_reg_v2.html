IO812 - Read register v2

IO812 - Read register v2 — Performs a read operation on a register in the ZMI4104 card.

Library

Simulink Real-Time - Speedgoat

Description

This driver block is for debugging purposes only and performs a 16-bit or 32-bit PCI read operation. Please refer to the Zygo User’s Manual for further information how to use.

Ports

This driver block has five input ports.

Input
Enable

If value is 1, the register read is enabled.

ZMI4104 ID

Select the ZMI4104C identifier, 1 or 2

Axis

Select the measurement axis 1,2, 3 or 4

PCI Access

Select PCI access mode - 0 for 16-bit read, 1 for 32-bit read

Register

Select the register offset (16-bit based) to read.

Parameters

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
