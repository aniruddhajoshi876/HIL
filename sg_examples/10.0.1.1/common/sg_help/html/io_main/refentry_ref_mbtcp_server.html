Modbus TCP Server

Modbus TCP Server — Simulink driver blocks for the native Modbus TCP Server interface

Introduction

Simulink driver blocks for Modbus TCP server enable data to be exchanged with an unlimited number of remote Modbus TCP clients. Support for Modbus TCP server is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
