IO629 - Submodule

IO629 - Submodule — Configure the IO629 sub-module

Library

Simulink Real-Time - Speedgoat

Description

Submodule driver block is used as reference to one of the ARINC 629 modules available in the hardware. The main bus settings can be set in this block's mask.

Ports

This driver block has no input or output ports.

Parameters

Subdevice ID

According to the hardware variant of the IO629 I/O module (IO629-2 or IO629-4) either two or four ARINC 629 modules are available. This value can be set to 1 or 2 for IO629-2 and 1,2,3,4 for IO629-4.

TI (Transmit Interval)

This parameter holds the transmit interval of the module. The value is expressed in microseconds in multiples of 500 microseconds.

SG (S ynchronization gap)

This parameter holds the synchronization gap of the module.It should be chosen to be longer than the maximum length Terminal Gap. Options are: SG of 16 (17.7 us), SG of 32 (33.7 us), SG of 64 (65.7 us), SG of 127 (127.7 us).

Interface

This parameter holds the module interface, either SIM (Serial Interface Module) or TTL.

Rx Only

When enabled, this will prevent any transmission from occurring. This setting shoud be used in combination with the Rx Only key switch on the back panel of the I/O module.
