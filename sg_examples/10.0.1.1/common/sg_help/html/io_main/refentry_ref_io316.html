IO316

IO316 — The IO316 is a configurable I/O module containing an FPGA with 45k of logic cells and 64 ESD protected TTL I/O lines

Introduction

Configurable I/O modules provide a flexible and cost-effective way to configure and reconfigure I/O and protocol functionalities for a set of code modules.

Configuration files, once purchased from Speedgoat, can be downloaded from the Speedgoat Customer Portal and also come with the following items:

  • Documentation: Comprehensive documentation including installation steps, descriptions of implemented functionality, pin mapping diagrams and explanations on how to get started with demo model examples

  • Simulink® Library: A Simulink library, including links to the main Speedgoat I/O Blockset, and which clearly shows the version of the driver blocks that match with your specific FPGA bitstream

  • Simulink demo model: A simple demo model illustrating how the implemented code module functionality is used, with loopback wirings wherever possible

Driver Blocks

Use the configurable I/O module Setup block to define the parameters for your I/O module. Based on the I/O and protocol functionalities implemented in your configuration file, a broad range of different driver blocks are supported.
