EV - Parameter Read

EV - Parameter Read — Reads data from the EV board during the Parameter Discovery state of the charge cycle.

Library

Simulink Real-Time - Speedgoat

Description

The EV Parameter Read block reads data from the EV charging board during the Parameter Discovery state of the charge cycle.

Ports

Outputs
SA-Schedule: ID

Tuple ID of the charging schedule created by the EVSE.

SA-Schedule: Start

Start time of the charging schedule in seconds from now.

SA-Schedule: Duration

Duration of the charging schedule in seconds.

SA-Schedule: PMax

The maximum amount of power the EVSE power outlet can deliver to the EV in the time interval of the schedule.

EVSE Max Voltage Limit

The maximum voltage limit of the EVSE in volts.

EVSE Max Current Limit

The maximum current limit of the EVSE in amperes.

EVSE Max Power Limit

The maximum power limit of the EVSE in watts.

EVSE Min Current Limit

The minimum current limit of the EVSE in amperes.

EVSE Min Voltage Limit

The minimum voltage limit of the EVSE in volts.

EVSE Current Regulation Tolerance

The current regulation tolerance of the EVSE in amperes.

EVSE Peak Current Ripple

The peak current ripple of the EVSE in amperes.

EVSE Energy to be Delivered

The amount of energy the EVSE intends to deliver in watt-hours.

EVSE Notification Max Delay

The maximum delay in seconds in which the EV has to react on a notification requested by the EVSE.

EVSE Notification

Enumerated notification following enumeration table "EVSENotificationType" of ISO 15118-2.

  • 0: None

  • 1: Stop charging

  • 2: Renegotiation

EVSE Isolationstatus

The chargers isolation status communicated by the EVSE, following enumeration table "isolationLevelType" of ISO 15118-2.

  • 0: Invalid

  • 1: Valid

  • 2: Warning

  • 3: Fault

  • 4: No isolation monitoring device (IMD) present

EVSE Statuscode

The charger's statuscode communicated by the EVSE, following enumeration table "DC_EVSEStatusCodeType" of ISO 15118-2.

  • 0: Not Ready

  • 1: Ready

  • 2: Shutdown

  • 3: Utility interrupt event

  • 4: Isolation monitoring active

  • 5: Emergency shutdown

  • 6: Malfunction

Parameters

Station ID

Defines the Station ID of the corresponding Setup block. Must range between 0 and 65535.

Connection ID

Defines the Connection ID of the corresponding Setup block. Must range between 0 and 65535.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
