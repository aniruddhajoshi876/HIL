IO672 - Bus Monitor

IO672 - Bus Monitor — The IO672 Bus Monitor (BM) block

Library

Simulink Real-Time - Speedgoat

Description

Use one block per channel to get status information. The block outputs all messages received since the last execution or up to the maximum defined number of messages. If more messages are available in the buffer, the block outputs the oldest messages read, while the newest ones remain in the buffer.

Ports

Outputs
MSG List

Received BM Message List, where the first element corresponds to the oldest message received.

Parameters

Channel

From the list of available channels on the board, choose channel 1, 2, 3, or 4. This channel is initialized for this command stream.

Maximum Number of Messages to Receive

Defines the size of the message list output. The message buffer must be large enough to store the maximum number of messages read from the board.

Note

This value must be equal to or smaller than the number specified in Number of monitor buffers to allocate from the IO672 Initialize block.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
