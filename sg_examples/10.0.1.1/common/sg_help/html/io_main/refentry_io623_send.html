IO623 - Send

IO623 - Send — Sends FlexRay frames

Library

Simulink Real-Time - Speedgoat

Description

This block allows FlexRay frames to be transmitted and can be placed in your model as many times as required.

Ports

Inputs
CCX (X is the communication controller number)

Payload of the FlexRay frame to send. This must be a vector with the width of the configured payload length in 16-bit words.

Data Type: uint16

Parameters

The configuration details are all defined in the Setup block.

Module ID

This ID defines the link to the corresponding Setup block

Communication Controller

Set the communication controller (CC)/bus interface to which to send the FlexRay frames. Only frames configured in the CHI file that have been selected in the Setup block can be sent.

Select Frame to Send

Click this button to obtain a list of all available FlexRay frames to send.

The content of this list depends on the CHI file that has been selected in the Setup block and the chosen CC above.

Selected Frame

Contains information about the selected FlexRay frame to send. This field cannot be edited and is only for information purposes.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
