CAN Database Parser Read

CAN Database Parser Read — Reads CAN (HS) and CAN FD messages from one channel

Library

Simulink Real-Time - Speedgoat

Description

The CAN DB Parser Read block consists of a masked subsystem, which adds an additional functionality layer to the existing CAN Read block. The subsystem is dynamically populated with a set of preconfigured CAN Unpack or CAN FD Unpack blocks, the corresponding CAN Read blocks, preconfigured output ports, and the interconnecting lines. The CAN DB Parser Read block mask allows users to select which messages of a *.dbc file should be received.

As an alternative to configuring the CAN DB Parser Read block using the application, the DB Parser Block Config class can be used to perform the process programmatically.

The CAN DB Parser Read block executes according to the settings in the corresponding CAN Setup block. The execution primarily depends on whether the operation mode is set to CAN (HS) or CAN FD. It is the user's responsibility to ensure that the operation mode selected in the CAN Setup block matches the operation mode defined in the *.dbc file in use.

The CAN DB Parser Read block cannot be edited when linked to a custom library, as it contains instance-specific data that cannot be shared across links. The block remains editable within the library itself: changes made there will be reflected in all linked instances. Additionally, the block cannot be used within subsystem models, as these are not supported.

Ports

The number and type of input ports depends on the setting of the Input Type parameter.

Parameters

Configure CAN I/O Module
CAN I/O Module

Selects the CAN I/O module with which this driver block communicates. The list is populated according to the CAN Setup blocks in the model.

Channel Number

Selects the CAN channel with which this driver block communicates.

Configure CAN Bus
Bus Type

Shows whether the operation mode used for this block is set to CAN (HS) or CAN FD. This parameter is configured automatically according to the corresponding setting in the Setup block and cannot be changed by the user.

Output Type

Configure the output type of the block; two options are available:

  • Signals

    An output port is created for each signal to transmit.

  • Single Bus

    When selecting this option, the output port is a single bus, containing a set of message buses with the same structure as described for the Bus per Messages setting.

Configure Sample Time
Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Configure CAN Parsing

Database
CANdb file

Select the database file from which to choose the desired signals to receive. The Messages table is dynamically populated based on the selected entry of this list. This list is populated through the CAN Database Manager. For further information about the CAN Database Manager, please refer to the usage notes

Messages
Enable all

Allows users to enable or disable all available messages in one click.

Add/Remove Selected

After selecting multiple messages in the table (Ctrl + left-click), all these messages can be simultaneously enabled or disabled.

IDs in hex

In the Messages table, IDs are displayed in decimal form by default. By enabling this command, the IDs can be displayed in hexadecimal format.

Signals

The Signals table shows the signals related to the last enabled/disabled message. No actions are available for this table.
