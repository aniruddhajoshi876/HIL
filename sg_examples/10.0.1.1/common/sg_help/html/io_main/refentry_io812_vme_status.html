IO812 - VME Status

IO812 - VME Status — I/O module status

Library

Simulink Real-Time - Speedgoat

Description

This driver block has one output port defining the status of the PCIe link between the PCI-VME bus adapters.

Ports

This driver block has one output port.

Output Port
Status

This output value indicates the following errors. For more information refer to the ALTHEA User Guide.

  • 1 - VME Bus Time OUT Error (Only while onboard BTO logic is active). If this Error is triggered, restarting the VME Bus will set the bit back to zero

  • 2 - VME Error Flag - Error detected. When this bit is set and a VME BERR is detected, the registered parameter is related to the first error occurrence. This status flag is also connected to the VME ITC unit, and signifies that an Interrupt can be issued

  • 3 - VME Interrupt Pending status flag

  • 4 - BERR condition generated

Parameters

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
