IO141

IO141 — Fast sampling 16-bit analog input and output module

Introduction

The IO141 I/O module is a 16-bit analog and digital module providing 16 single-ended or 8 differential analog input channels, 4 simultaneous updated single-ended analog output channels and 8 digital LVTTL/TTL I/O lines.

  • Analog input channels featuring:

    • 2 input groups with 4 differential or 8 single-ended inputs each

    • Selection of differential or single-ended mode per input group (not per channel)

    • Pseudo-simultaneous sampling

    • Differential mode: Voltage ranges of ±0.64 V, ±1.28 V, ±2.56 V, ±5.12 V, ±10.24 V, ±20.48 V, and ±24.576 V (individual setting for each channel)

    • Single-ended mode: Voltage ranges of ±0.64 V, ±1.28 V, ±2.56 V, ±5.12 V, ±10.24 V, and ±12.288 V (individual setting for each channel)

    • Maximum sample rate from 100 kS/s to 800 kS/s, depending on the number of active channels per input group

    • Frame-based autonomous data transfer (DMA)

  • 4 analog output channels featuring:

    • Single-ended outputs

    • Simultaneous update

    • Voltage ranges of 0–5 V, 0–6 V, 0–10 V, 0–12 V, ±5 V, ±6 V, ±10 V, and ±12 V (individual setting for each channel)

    • Current ranges of 4–20 mA, 0–20 mA, and 0–24 mA (individual setting for each channel)

    • Settling time 24 μs

    • Frame-based autonomous data transfer (DMA)

  • 8 digital I/O channels featuring:

    • Output driver LVTTL 3.3 V (5 V output selectable - only for high-impedance loads)

    • Input driver 5 V tolerant

    • Configurable debounce filter

    • ESD protection

Note

This driver version does not yet support multi-board synchronization and temperature compensation.
