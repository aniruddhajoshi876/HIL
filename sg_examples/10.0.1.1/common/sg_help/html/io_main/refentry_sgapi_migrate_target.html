speedgoat.migrateTarget

speedgoat.migrateTarget — Open the Speedgoat tool to migrate a Speedgoat real-time target machine

Description

This Speedgoat API function opens the Speedgoat Migration Tool, which allows you to migrate your Speedgoat real-time target machine's software for use with the current MATLAB release. Further information and instructions can be found on the Software Migration help page.

Examples

Open the Speedgoat Migration Tool:

speedgoat.migrateTarget
