IO116

IO116 — 16-bit analog module with 8 current loop inputs, 4 current loop outputs

Introduction

The IO116 I/O module provides both voltage and current analog input/output capability in a single industry-standard I/O module. The analog current range can be either 0-20 mA or 4-20 mA (software selectable).

The analog inputs can be configured to work either as eight differential voltage inputs, 16 single-ended voltage inputs, or as eight differential, terminated current-loop inputs.

The four analog output channels provide both voltage and current loop outputs.

Additionally the module offers a 16-bit digital port with 8 TTL input lines and 8 TTL output lines.

Warning

This I/O module has an automatic calibration feature. During the calibration process various signals may be present at the output pins.
