I/O Pin Functions

Input port Description
TxD Data transmission output.
RxD Data reception input.
TxC Output of internally generated clock.
RxC Input for externally applied clock.
RTS Request To Send Output. Activated when the Rx FIFO is almost full, which can be configured in the Setup block.
CTS Clear To Send Input.
GND Each channel's ground reference pin connects to the chassis of the target machine through a 100 Ohm resistor.
AuxC This bidirectional I/O pin has no function assigned in this version of the driver.
DCD The Data Carrier Detect pin is a bidirectional I/O pin that could be used for enabling data reception. It has no function assigned in this version of the driver and is configured as input.
