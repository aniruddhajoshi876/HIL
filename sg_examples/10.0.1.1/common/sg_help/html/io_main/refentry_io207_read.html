IO207 - Read

IO207 - Read — Reads the IO207 digital inputs

Library

Simulink Real-Time - Speedgoat

Description

Your model can only contain one or two of these blocks for each I/O module in your target machine.

Ports

This driver block has n output ports, where n is the number of selected digital input channels. The output ports can be set to 4 different types:

  • 32 or 64 ports of type double: 32 or 64 output ports of type double are shown. Each port is a scalar with a value of either 0.0 (low) or 1.0 (high).

  • 32 or 64 ports of type boolean: 32 or 64 output ports of type boolean are shown. Each port is a scalar with a value of either 0 (low) or 1 (high).

  • 1 port with 32 or 64 element vector of type double: One output port of type double is shown. This port has a width of 32 or 64 with each element having a value of either 0.0 (low) or 1.0 (high).

  • 1 port with 32 or 64 element vector of type boolean: One output port of type boolean is shown. This port has a width of 32 or 64 with each element having a value of either 0 (low) or 1 (high).

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel Group

Select either Front or Rear as appropriate.

Port Type

Select one of the four available port types.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
