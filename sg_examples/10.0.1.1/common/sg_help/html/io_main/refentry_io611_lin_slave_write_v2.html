IO611 - LIN Slave Write v2

IO611 - LIN Slave Write v2 — Write to the Transmit Buffers of the LIN Slave

Library

Simulink Real-Time - Speedgoat

Description

This driver block allows LIN messages to be transmitted. The LIN message information (LIN version, ID, DLC) can be set in the block mask.

A single write block is required for each LIN message.

The "LIN Slave Write" block has an Update Buffer size of 64 messages. Each message index (0-63) represents the Protected Identifier of the corresponding message. An update of a single message overwrites the old value. Consequently, only the latest message is available.

The Update Buffer is not a Send Queue like the one for the LIN Master. The messages are directly taken from the Update Buffer and sent out exclusively when requested by the Master device.

Ports

Inputs
Data

The number of bytes is defined in the block mask with the parameter DLC. Data Type: uint8

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Send message with channel

Choose the LIN channel to which this driver block should be connected.

Message Type

Currently only the message type RAW is supported.

Show Enable Response Input

If this option is checked, an additional input port is created, which allows response messages to be enabled/disabled for the selected ID during runtime.

LIN version

Select the LIN version:

  • LIN 1.X representing versions 1.1, 1.2 and 1.3 uses Classic Checksum.

  • LIN 2.X representing versions 2.0, 2.1 and 2.2 uses Enhanced Checksum except for IDs 60 and 61.

Identifier

Message ID of the LIN message without parity protection. Valid values are in the range 0 through 63.

Caution

LIN specifies the Protected ID (PID) to be a 8-bit value, where bits 7 and 8 contain parity sums over the other bits. The ID therefore consists of bits 1 through 6.

DLC

Identifies the length of the LIN message data array (Data Length Code). The value can be chosen in the range of 1 through 8.

Caution

LIN version 1.1 defines the DLC as a function of the ID (0-31: 2; 32-47: 4; 48-63: 8).

Default message data

These values are written to the LIN message buffer of the slave. The array must have the same length as the DLC. To create a default array that corresponds to the DLC use "[]" as the value and press Apply. A default array is then created.

Note

In the LIN slave message buffers, the data arrays of all LIN messages are set to zero (default). If a master requests a LIN message from the slave before the global sender could update the message buffers, the slave responds to the master header with zeros. With the "Default message data" parameter, the data array of the corresponding message can be set to user-defined values. If a master now requests a LIN message, the slave responds to the master header with the user defined values until the global sender has updated the message buffers.
