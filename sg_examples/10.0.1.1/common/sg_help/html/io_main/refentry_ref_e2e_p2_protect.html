CAN Message Utilities: E2E Profile 2 Protect

CAN Message Utilities: E2E Profile 2 Protect — Applies AUTOSAR E2E Profile 2 Protection mechanism to an array of bytes

Library

Simulink Real-Time - Speedgoat

Description

The E2E Profile 2 Protect block implements the transmitter-side logic of the AUTOSAR E2E Profile 2 specification. The block inserts a 4-bit sequence counter and computes a CRC over the message data, including a configurable Data ID.

For in-depth documentation about the E2E Profile 2, please refer to the AUTOSAR documentation.

Ports

Which input and output ports are available depends on the configuration settings in the block mask:

Input
Input Port

This input port is always available and its datatype (either CAN_MESSAGE_BUS, CAN_FD_MESSAGE_BUS or a uint8 array with a maximum length of 256 bytes) is configured by the Protocol parameter in the block mask.

Data ID List

This input port can be enabled with the Data ID List from Input checkbox in the mask. Data ID List input port expects an array of 16 elements of data type uint8.

Outputs
Protected Output

This port outputs the E2E Profile 2 protected version of the Input signal. Its datatype (either CAN_MESSAGE_BUS, CAN_FD_MESSAGE_BUS or a uint8 array with a maximum length of 256 bytes) is configured by the Protocol parameter in the block mask.

Parameters

Data ID List from Input

If enabled, adds a Data ID List input port to provide the Data ID List from the Simulink® model.

Data ID List

If Data ID List from Input checkbox is disabled, the 16 element-long Data ID List can be configured with this parameter.
