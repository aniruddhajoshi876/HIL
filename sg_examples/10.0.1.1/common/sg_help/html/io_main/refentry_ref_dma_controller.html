DMA Controller

DMA Controller — Measurement of timing with Optimize Data Transfer enabled

Introduction

The DMA Controller block allows you to measure the actual time taken for a complete sample step when using Optimize Data Transfer. When a model is running with optimized data transfer, the maximum achievable sample time depends on the task execution time (TET) and the time for the data transfers between the configurable I/O module and the Simulink Real-Time application. Refer to the usage notes below for a detailed explanation.
