EV - Isolation Write

EV - Isolation Write — Writes data to the EV board during the Isolation state of the charge cycle.

Library

Simulink Real-Time - Speedgoat

Description

The EV Isolation Write block writes data to the EV charging board during the Isolation state of the charge cycle.

Ports

Inputs
Ready

Indicates if the EV is ready to charge generally.

  • 0: not ready

  • 1: ready

Errorcode

Errorcode following enumeration table "DC_EVErrorCodeType" ISO 15118-2:

  • 0: EV_NO_ERROR

  • 1: EV_FAILED_RESS_TEMPERATURE_INHIBIT

  • 2: EV_FAILED_EV_SHIFT_POSITION

  • 3: EV_FAILED_CHARGER_CONNECTOR_LOCK_FAULT

  • 4: EV_FAILED_EVRESS_MALFUNCTION

  • 5: EV_FAILED_CHARGING_CURRENTDIFFERENTIAL

  • 6: EV_FAILED_CHARGING_VOLTAGE_OUT_OF_RANGE

  • 7: EV_RESERVED_A

  • 8: EV_RESERVED_B

  • 9: EV_RESERVED_C

  • 10: EV_FAILED_CHARGING_SYSTEM_INCOMPATIBILITY

  • 11: EV_NO_DATA

RESS SOC

Current state of charge (SoC) of the EV's rechargeable energy storage system (RESS).

Parameters

Main Tab
Station ID

Defines the Station ID of the corresponding Setup block. Must range between 0 and 65535.

Connection ID

Defines the Connection ID of the corresponding Setup block. Must range between 0 and 65535.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Enable/Disable Signals Tab

Some settings, like min. and max. voltage limits, are already set by the Setup block but can be overwritten during the Parameter Discovery state of the charge if desired. However, unused signals that remain unconnected are set to zero. To avoid setting parameters to zero, unused signals should be unchecked here to disable the write operation.

The following signals can be disabled:

  • Errorcode
