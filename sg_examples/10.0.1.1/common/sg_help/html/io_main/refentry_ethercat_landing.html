EtherCAT — Speedgoat I/O modules for EtherCAT

Introduction

Speedgoat provides support for EtherCAT communication. While EtherCAT Main Device and EtherCAT SubDevice Emulator are supported on generic Ethernet interfaces, EtherCAT Subordinate Device requires a dedicated I/O module (see table below).

Refer to the Speedgoat Ethernet Interfaces documentation to learn how an interface can be configured for EtherCAT Main Device and EtherCAT SubDevice Emulator. Additional general information on EtherCAT Main Device is available in the MathWorks web documentation. For the local MathWorks help, enter the following code in the MATLAB® command window:

eval('helpview(fullfile(docroot,''slrealtime'',''ethercat.html''))')
