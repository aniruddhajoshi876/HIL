IO781 - Setup

IO781 - Setup — Configure the IO781 I/O module

Library

Simulink Real-Time - Speedgoat

Description

Your model can contain only one Setup block for each I/O module in your target machine.

Ports

This driver block has no input or output ports.

Parameters

Module ID

Given that a target machine can contain more than one I/O module, this parameter is used by the other driver blocks to identify a specific module. Select a unique number (1-10) for each of your modules. If your target machine only contains one I/O module, leave the default value (1).

Configuration file

Specify the configuration file that you exported from the Flight Simulyzer. Use the absolute path name of the .adc file or only the file name, if the configuration file is in your current working folder.
