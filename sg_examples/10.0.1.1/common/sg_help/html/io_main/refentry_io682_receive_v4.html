IO682 - Receive v4

IO682 - Receive v4 — Receives ARINC 429 messages

Library

Simulink® Real-Time™ - Speedgoat

Description

This driver block allows ARINC 429 messages to be read. Only one Receive block per IO682 I/O module and per channel can be placed in your model.

Ports

Outputs
Cnt

The number of messages received.

Msg

Data read from the receive buffer. The width of its output is equal to the maximum number of messages to return.

Time

Timestamp from the messages received. The width of its output is equal to the maximum number of messages to return.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel

Defines from which receive buffer the messages will be read.

Max Number of Messages to Return

Defines the maximum number of messages to read per sample time. Valid values are between 1 and 1000.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Provide Timestamps

Select whether the timestamp for each message received should be available at the time output port.
