IO611 - LIN Slave Write

IO611 - LIN Slave Write — Write to the Transmit Buffers of the LIN Slave

Library

Simulink Real-Time - Speedgoat

Description

Write to the Transmit Buffers of the LIN Slave.

Ports

All the input ports of this block are vectors with as many elements as values are configured to be updated per sample hit. Except the number of elements of the data input port is 8 times the number of configured messages.

Inputs
Prot.ID

The LIN identifier (ID). Range 0 to 63.

Data Types:uint8

Checksum

Checksum version to use:

  • 0: Classic Checksum (LIN 1.1, LIN 1.2, LIN 1.3)

  • 1: Enhanced Checksum (LIN 2.0, LIN 2.1, LIN 2.2)

Data Types:uint8

Data Len

Data length code (DLC). Range 0 to 8.

Data Types:uint8

Data

The new data. The LIN protocol allows for messages with up to eight data bytes. If N values in the buffer are configured to be updated per sample hit, this vector will simply be sized N * 8.

Data Types:uint8

Parameters

Module ID

Specifies the ID of the IO61X module this driver block should be connected to. It must correspond to the module ID of the according setup block. Check the setup block help for more details.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. It can also be set to -1 for inherited sample time. The units are in seconds.

Send Message with Channel

Choose the LIN channel to which this driver block should be connected.

Number of LIN Messages

Configures how many values in the buffer to update per sample hit. This parameter directly sets the input port width. Range is between 1 and 50.
