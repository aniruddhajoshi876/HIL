IO781 Usage Notes

IO781 Usage Notes — Usage information about the I/O module

AFDX ES Configuration

To configure the AFDX module, an .adc configuration file must be generated. The configuration file is generated using Flight Simulyzer: a software application provided by Avionics Interface technologies. The Flight Simulyzer software can be used to manually configure the AFDX network or import XML configuration files for more complex network structures.

Getting Flight Simulyzer

To download Flight Simulyzer, you must register (free of charge) on the Avionics Interface Technologies website (https://aviftech.com/). Once you are logged in, browse to: https://aviftech.com/ait_documents/flight-simulyzer-f/ and download Flight Simulyer for ARINC 664 (v4.10.x and higher).

Flight Simulyzer provides two main features: read/write of configuration files (adc and xml) and traffic simulation. The traffic simulation capability is not required to use the IO781 I/O module.

Flight Simulyzer (v4.10.x and higher) can be used to configure AFDX networks free of charge and without a license.

Flight Simulyzer provides a good introduction to creating, importing and exporting AFDX End System configuration files.
