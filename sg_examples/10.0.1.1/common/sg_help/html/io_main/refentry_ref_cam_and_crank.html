Cam and Crank

Cam and Crank — The cam and crank driver blocks provide simulation and decoding of camshaft and crankshaft signals.

Introduction

Speedgoat provides various code modules using the digital I/O of configurable I/O modules to simulate or decode camshafts and crankshafts:

  • Crank Encoder

  • Cam Encoder

  • Crank Decoder

  • Cam Decoder

  • Crank Event Capture

  • Crank Decoder Event

These modules are complemented by the following code modules using analog I/O:

  • Variable Reluctance Sensor

  • Knock Generator
