IO812 - Write register

IO812 - Write register — Performs a write operation on a register in the ZMI4104 card.

Library

Simulink Real-Time - Speedgoat

Description

This driver block is for debugging purposes only and performs a 16-bit or 32-bit PCI write operation. Please refer to the Zygo User’s Manual for further information how to use.

Ports

This driver block has three input ports.

Input
Enable

If value is 1, the register write is enabled.

Register

Select the register offset (16-bit based) to write.

Value

Value to write at the specified register, either 16-bit or 32-bit size.

Parameters

Block setup Tab
ZMI4104C identifier

Select the identifier for the ZMI card identity with 1 for ZMI card one and 2 for ZMI card two.

Measurement axis

Select the axis for the measurement (1 to 4)

PCI access

Select the either 16-bit or 32-bit write

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
