Introduction

MQ Telemetry Transport (MQTT) is an open communication protocol mainly used for machine to machine communication in IoT networks. The protocol is based on TCP/IP and follows a publish-subscribe architecture. A client (Publisher) sends data for a specific topic to the broker, which passes the data to the clients (subscribers) that subscribed to that topic. MQTT allows fast and efficient data transfer as it has a small protocol header and transmission does not require periodic requests. Speedgoat provides a native interface for MQTT, which is supported with onboard Ethernet interfaces and plug-in I/O modules. The MQTT protocol stack runs on the target machine's CPU. Simulink driver blocks for client operation are available.
