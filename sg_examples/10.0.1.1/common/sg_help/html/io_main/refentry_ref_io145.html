IO145

IO145 — Fast sampling 16-bit analog input and output module

Introduction

The IO145 I/O module is a 16-bit analog and digital module providing 8 analog current input channels and 16 single-ended or 8 differential analog voltage input channels, 8 simultaneous updated combined voltage or current outputs channels and 8 digital LVTTL/TTL I/O lines.

  • Analog current input channels featuring:

    • 2 current input groupts with 4 differential inputs each

    • Pseudo-simultaneous sampling

    • Current range of ±25 mA

    • Maximum sample rate from 100 kS/s to 800 kS/s, depending on the number of active channels per input group

    • Frame-based autonomous data transfer (DMA)

  • Analog voltage input channels featuring:

    • 2 input groups with 4 differential or 8 single-ended inputs each

    • Selection of differential or single-ended mode per input group (not per channel)

    • Pseudo-simultaneous sampling

    • Differential mode: Voltage ranges of ±10 V, ±20 V, ±40 V, ±40 V, ±80 V, and ±96 V (individual setting for each channel)

    • Single-ended mode: Voltage ranges of ±10 V, ±20 V, ±40 V, and ±48 V (individual setting for each channel)

    • Maximum sample rate from 100 kS/s to 800 kS/s, depending on the number of active channels per input group

    • Frame-based autonomous data transfer (DMA)

  • 8 analog output channels featuring:

    • Single-ended outputs

    • Simultaneous update

    • Voltage ranges of 0–5 V, 0–6 V, 0–10 V, 0–12 V, ±5 V, ±6 V, ±10 V, and ±12 V (individual setting for each channel)

    • Current ranges of 4–20 mA, 0–20 mA, and 0–24 mA (individual setting for each channel)

    • Settling time 24 μs

    • Frame-based autonomous data transfer (DMA)

  • 8 digital I/O channels featuring:

    • Output driver LVTTL 3.3 V (5 V output selectable - only for high-impedance loads)

    • Input driver 5 V tolerant

    • Configurable debounce filter

    • ESD protection

Note

This driver version does not yet support multi-board synchronization and temperature compensation.
