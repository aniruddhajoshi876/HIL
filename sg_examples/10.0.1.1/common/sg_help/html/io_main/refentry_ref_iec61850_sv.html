IEC 61850 Sampled Values

IEC 61850 Sampled Values — Simulink driver blocks for the native IEC 61850 Sampled Values interface

Introduction

By publishing multicast Ethernet messages with a Sampled Values (SV) Publisher, a SV Subscriber can listen to a defined MAC address for receiving data. Support for the IEC 61850 SV is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
