OPC UA Server — Simulink driver blocks for OPC UA server

Introduction

Simulink driver blocks for OPC UA server enable data to be exchanged with multiple remote OPC UA clients. Support for OPC UA server is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
