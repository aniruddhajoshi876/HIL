IO424 - Setup

IO424 - Setup — Configure the IO424 LVDT/RVDT/Resolver/Synchro measurement block

Library

Simulink Real-Time - Speedgoat

Description

Your model can contain only one Setup block for each I/O module in your target machine.

The Setup block dialog box allows all the supported I/O types of this module to be configured and therefore impacts on the other driver blocks of the IO424.

Ports

This driver block has no input or output ports.

Parameters

Main Tab
Module ID

The Module ID has two functions:

  • It defines the logical connection between the Setup block and its I/O blocks

  • It also informs the auto-search feature of the PCI Slot parameter. If only one I/O module of this type is installed, the Module ID must be set to 1. If n modules are installed, it must be in the range 1:n. Not all the I/O modules installed in the target machine need to be used. To see how each I/O module maps to a Module ID, use this Speedgoat API: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat")
Module Type

Indicates if this IO424 module is the version with or without support for Synchro type sensors. If the option "IO424-RS (with Synchro)" is selected, the "Synchro Tab" will appear, and the "Channel Configuration" option for channel 3-4 will change.

PCI Slot (-1: auto-search)

There are two approaches for mapping this block to a specific I/O module installed in your target machine. All modules of the same type must be configured using the same method.

  • Auto-Search: with the default value -1 the I/O module will be automatically located in the target machine. If you have multiple modules of the same kind, the Module ID defines which module is associated with this block. To see how each I/O module maps to a Module ID, use this Speedgoat API: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat")

  • Explicit Addressing: to explicitly define the logical address of the I/O module in the target machine, you can provide the PCI bus and slot numbers as a vector: [bus, slot]. To determine these numbers, run the following command in the MATLAB command window: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat", "Advanced", true)

    Note that the PCI address can change whenever an I/O module is added or removed – usually, auto-search is the best option.

Channel Configuration

Select the sensor type for each channel.

IO424-R (Channels 1-4):

  • Disabled

  • Resolver

  • LVDT/RVDT Differential (4-wire)

  • LVDT/RVDT Ratiometric (6-wire)

IO424-RS (Channels 1-2):

  • Disabled

  • Resolver

  • LVDT/RVDT Differential (4-wire)

  • LVDT/RVDT Ratiometric (6-wire)

IO424-RS (Channels 3-4):

  • Disabled

  • Synchro

Resolver Tab
Position Output unit of measurement

Select the Resolver read block's unit of measurement of the position value. Available options:

  • Radians

  • Degrees

  • Minutes

Combined Data Register Ch1 and Ch2

To use this option, channel 1 and 2 must be set to Resolver.

This option enables to read the Position (and Status) of both channels in a single access. This is useful in multiturn resolvers, where precise parallel reading is necessary.

Combined Data Register Ch3 and Ch4

Same as the previous option, but for channel 3 and 4; only available for the IO424-R.

Input Range Settings

Select the Input Range of the specific channel. Choose a range that optimally matches the input signal to maximize resolution. Only channels configured for Resolver operation will be displayed.

Synchro Tab
Position Output unit of measurement

Select the Synchro read block's unit of measurement for the position value. Available options:

  • Radians

  • Degrees

  • Minutes

Combined Data Register Ch3 and Ch4

To use this option, channel 3 and 4 must be set to Synchro.

This option enables to read the Position (and Status) of both channels in a single access.

Input Range Settings

Select the Input Range of the specific channel. Choose a range that optimally matches the input signal to maximize resolution. Only channels configured for Synchro operation will be displayed.

LVDT/RVDT Tab
Combined Data Register Ch1 and Ch2

To use this option channel 1 and 2 must be set to LVDT/RVDT.

This option enables to read the Stroke (and Status) of both channels in a single access.

Combined Data Register Ch3 and Ch4

Same as the previous option, but for channel 3 and 4; only available for the IO424-R.

Input Range Settings

Select the Input Range of the specific channel. Choose a range that optimally matches the input signal to maximize resolution. Only channels configured for LVDT/RVDT operation will be displayed.

Excitation Output Tab

In this tab, the controls for the Excitation output will appear for the channels with Resolver or LVDT/RVDT configuration.

Enable

This checkbox will enable the Excitation output.

Excitation Voltage [Vrms]

Select a voltage in the range 0-12 Vrms.

Excitation Frequency [Hz]

Select a frequency in the range 1-20 kHz.
