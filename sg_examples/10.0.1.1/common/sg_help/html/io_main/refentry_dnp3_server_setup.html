DNP3 - Server Setup

DNP3 - Server Setup — Configures the DNP3 server software stack

Library

Simulink Real-Time - Speedgoat

Description

The Setup block configures the DNP3 server protocol stack, opens the ports for incoming connection requests and enables the Point blocks to exchange data on the network.

Ports

This driver block has no input or output ports.

Parameters

Tab: General
Server ID

This is the DNP3 address of the server. DNP3 addresses must be unique in a network and range between 0 to 65519.

IP Address

Enter the IP address of the DNP3 server. This step does not assign the IP address to an Ethernet interface. Instead, it binds the Setup block to an IP address which was previously configured in the Ethernet Configuration Tool. Refer to the DNP3 usage notes for further information.

You can define multiple servers acting on the same IP address but different TCP ports. Insert the number of required Setup blocks in the model and apply the same IP address but different TCP ports. Specify a unique Server ID for each Setup block.

Furthermore, you can assign additional IP addresses to the same Ethernet interface by using IP aliasing. These addresses must be in the same subnet. Refer to the DNP3 usage notes for further information.

TCP Port

The TCP port the server listens on for connection requests from the client. The default port is 20000. For a custom port address, select between the range 0 and 65535. The reserved ports should not be used.

https://en.wikipedia.org/wiki/List_of_TCP_and_UDP_port_numbers

Analog Deadband

Refers to analog points only.

Defines the absolute threshold that the change of an analog point value must exceed in order to trigger an event. Default deadband is 0 (every change triggers an event).

Data type: single

Device Attributes

Defines the attributes in DNP3 group 0. Must be a 2-by-n cell array. The first element represents the data type of the attribute, the second element represents the value. In addition to fundamental data types, group 0 also supports char. The maximum number of attributes is 256. The variation of an attribute results from its position in the cell array. The first attribute is assigned to variation number 0, the last one to 255.

Example: {'uint32',1234;'char','Speedgoat'} creates two device attributes. The serial number 1234 has data type uint32 and can be read by the client with variation number 0. The manufacturer name Speedgoat is a string and can be read with variation number 1.

Tab: Points

This group of parameters sizes the DNP3 point and event groups.

Binary Input Points

Defines the number of points in groups 1 and 2.

Binary Input Events

Defines the number of events for each point in group 2 (event history).

Double-Binary Input Points

Defines the number of points in groups 3 and 4.

Double-Binary Input Events

Defines the number of events for each point in group 4 (event history).

Counter Input Points

Defines the number of points in groups 20, 21, 22 and 23.

Counter Input Events

Defines the number of events for each point in groups 22 and 23 (event history).

Analog Input Points

Defines the number of points in groups 30, 31, 32 and 33.

Analog Input Events

Defines the number of events for each point in groups 32 and 33 (event history).

Binary Output Points

Defines the number of points in groups 10, 11, 12 and 13.

Binary Output Events

Defines the number of events for each point in groups 12 and 13 (event history).

Analog Output Points

Defines the number of points in groups 40, 41, 42 and 43.

Analog Output Events

Defines the number of events for each point in groups 42 and 43 (event history).
