IO101 - Digital output

IO101 - Digital output — Writes the IO101 digital outputs

Library

Simulink Real-Time - Speedgoat

Description

To write to the digital outputs exactly one of these blocks must be added to your model for each module of this type in your target machine.

Ports

This driver block has n scalar input ports of type double where n is the number of selected digital output channels.

Inputs
X (X is the digital output channel number)

The value to set digital output channel X. Type double. Possible values:

  • 0 - TTL low

  • 1 - TTL high

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel Group

Select whether to access the lower channels (digital lines 1-8) or the upper channels (digital lines 9-16).

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
