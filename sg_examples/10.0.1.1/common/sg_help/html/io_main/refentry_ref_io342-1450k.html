IO342-1450k

IO342-1450k — The IO342-1450k is a FPGA I/O module with 1450k of logic cells and up to 2 FMC slots with your choice of FMCs installed

Introduction

Simulink-Programmable FPGA I/O modules are designed in close partnership with MathWorks® to ensure seamless integration with HDL Coder™ for automatic HDL code generation, Simulink Real-Time™ and many other MathWorks products. Simulink-Programmable FPGA I/O modules can be combined with a vast range of code modules for off-the-shelf I/O and protocol functionalities, and scaled to your specific requirements.

Integration into the HDL Coder™ workflow is achieved using a HDL Coder Integration Package, which comes with comprehensive documentation, as well as a bundle of demo model examples illustrating how to use the I/O interfaces and the additional base functionality such as DMA, interrupt, polling mode and more.

Note

Further information on the IO342-1450k I/O module is also available in the HDL Coder help.
