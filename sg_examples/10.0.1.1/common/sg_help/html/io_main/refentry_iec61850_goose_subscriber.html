IEC 61850 - GOOSE Subscriber

IEC 61850 - GOOSE Subscriber — Reads published GOOSE data through MAC addressing.

Library

Simulink Real-Time - Speedgoat

Description

This block is used to read data that has been published to the network using a destination MAC address. Your model can contain multiple IEC 61850 GOOSE subscriber blocks and requires at least one IEC 61850 Client or Server license.

Ports

Inputs

This block does not have any input ports.

Outputs
Output

The subscriber will read messages from the defined Destination MAC Address and output them with the type selected in Message Data Type. The array length is defined by the Width of Output Port parameter.

Use Byte Unpack blocks to convert to signed values or floating-point numbers. You can unpack a vector of type int8 and length 8 to one double value.

Parameters

Ethernet Port

Define from which local Ethernet port GOOSE messages should be read. The internal Ethernet interfaces of Speedgoat target machines have for example 'ETH1' as an available port.

Message Data Type

Select one of the data types listed in the dropdown list:

  • Int8

    1-byte signed integer.

  • Double

    8-byte floating point.

  • Quality

    4-byte unsigned integer.

  • Boolean

    1 bit.

Output Port Width

Set the length of the output port vector.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Get Local Interface MAC Address

By clicking this button the MAC address of the defined Ethernet interface will be put into the edit field below.

Destination MAC Address

Define the multicast/broadcast MAC address of the GOOSE message. For the purpose of broadcasting use ff:ff:ff:ff:ff:ff.

GOOSE App ID

The GOOSE app ID will be used to filter the messages from the given MAC address.
