IO758 — POWERLINK Controlled Node I/O module

Introduction

The IO758 is a configurable POWERLINK Controlled Node I/O module. The solution is part of the IO64X/IO75X I/O module family, which provides support for a wide range of industrial protocols. The IO758 module acts as one POWERLINK Controlled Node exclusively.
