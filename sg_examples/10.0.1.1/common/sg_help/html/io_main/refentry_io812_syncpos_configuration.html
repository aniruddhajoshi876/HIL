IO812 - Configuration

IO812 - Configuration — Configures and syncs one ZMI4104 card.

Library

Simulink Real-Time - Speedgoat

Description

This driver block allows to configure and syncronize exactly one ZMI4104C card. Therefore if two cards are installed, a total of two ZMI4104 SyncPos Configuration driver blocks are required.

Ports

This driver block has five input ports:

Output Ports
ZMI4104 Adress

To be connected with the respective output port of the VME setup driver block.

Init/Reset Axis n

If this value is set to 1, the respective axis is initialized during startup. This value can be set for each of the 4 axis of one ZMI4104 card.

Parameters

Board Number

Insert the board number for the identification of the ZMI4104 card.

The four tabs of the configuration parameter dialog box contain configuration settings for each axis.

Axis n Tab
Digital filtering: Kv value

Defines the Kv value for digital filtering. Please refer to the Zygo User’s Manual for further information.

Digital filtering: Kp value

Defines the Kp value for digital filtering. Please refer to the Zygo User’s Manual for further information.

Note

Additional parameters can be added by Speedgoat to this driver block as required: initialization of such parameters is performed by the drivers.
