Jumper Settings

Setting the pull up voltage to 5V by jumper J1, a 5V weakly voltage can be driven. To maintain a proper 5V CMOS high-level, the external load (leakage) current should not exceed 250µA (only high impedance inputs can be driven).

J1 Jumper Position Pull Up Voltage
1 – 2 3.3V (default)
2 – 3 5V
