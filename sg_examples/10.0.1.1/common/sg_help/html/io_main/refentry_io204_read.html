IO204 - Read

IO204 - Read — Reads the IO204 digital inputs

Library

Simulink Real-Time - Speedgoat

Description

To read the digital inputs, exactly one of these blocks must be added to your model for each module of this type in your target machine.

Ports

This driver block has no input ports. The output ports can be set to 5 different types:

16 ports of type double

16 output ports of type double are shown. Each port is a scalar with a value of either 0.0 (Low) or 1.0 (High).

16 ports of type boolean

16 output ports of type boolean are shown. Each port is a scalar with a value of either 0 (Low) or 1 (High).

1 port with 16 element vector of type double

One output port of type double is shown. The port has a width of 16 with each element having a value of either 0.0 (Low) or 1.0 (High).

1 port with 16 element vector of type boolean

One output port of type boolean is shown. The port has a width of 16 with each element having a value of either 0 (Low) or 1 (High).

1 port with scalar of type uint32

One output port of type uint32 is shown. The port is a scalar containing all 16 channels as a single uint32 value.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Port Type

Select one of the five available port types.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
