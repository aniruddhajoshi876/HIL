IO672 - Encode BC Message

IO672 - Encode BC Message — Fills each message for the timestep during which the message should be sent

Library

Simulink Real-Time - Speedgoat

Description

This block fills each message for the timestep during which the message should be sent.

The Create BC Message List block allocates an empty list of message buffers in Simulink Real-Time memory. Use the Encode BC Message block to fill these messages.

Ports

Inputs
MSG List

BC Message List.

Data

Data to be transmitted to the remote terminal, if R direction is selected (BC → RT).

Outputs
MSG List

BC Message List.

Parameters

Message number

The number of the message to encode. Each BC message needs to use a unique message number. This is the place in the list to fill with this message.

Remote Terminal address 1 (Receive if RT-RT)

From the list, choose a Remote Terminal address 1.

Sub address 1 (Receive if RT-RT)

Sub address 1 Setting this parameter to Send (0) mode command or Send (31) mode command disables the Message word count parameter.

Remote Terminal address 2 (Transmit if RT-RT)

Remote Terminal address 2. This is not used if the Direction is R (BC->RT) or T (RT->BC).

Sub address 2 (Transmit if RT-RT)

Remote Terminal sub address 2. This is not used if the Direction is R (BC->RT) or T (RT->BC).

Mode command

If the Sub address 1 is 0 or 31, from the list, choose a mode command.

Message word count

The number of uint16 words to send or receive.

Direction

The encode direction. Choose from:

  • R (BC->RT)

  • T (RT->BC)

  • RT->RT

Inter message gap to next message (usec)

The minimum amount of time, in microseconds, between messages.

Output bus

The bus that this message will be sent on.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
