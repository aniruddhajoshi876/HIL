IO17x — Thermocouple, resistive sensors and strain gauge measurement modules

Introduction

The Thermo / Strain Measurement IO171 and IO172 I/O modules can measure any kind of ungrounded thermocouples, resistive sensors like RTD and thermistors, and strain gauges. The IO171 provides 16 independent measurement channels, the IO172 provides 6 independent measurement channels. Each channel consists of a differential analog input and a differential sensor excitation output.
