EVSE - Stop Read

EVSE - Stop Read — Reads data from the EVSE board during the Stop state of the charge cycle.

Library

Simulink Real-Time - Speedgoat

Description

The EVSE Stop Read block reads data from the EVSE charging board during the Stop state of the charge cycle.

Ports

Outputs
EV Stop Progress

Provides the EV's information if the charging process shall either be terminated or paused. Following enumeration table "chargingSessionType" of ISO15118-2.

  • 0: Terminate

  • 1: Pause

Parameters

Station ID

Defines the Station ID of the corresponding Setup block. Must range between 0 and 65535.

Connection ID

Defines the Connection ID of the corresponding Setup block. Must range between 0 and 65535.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
