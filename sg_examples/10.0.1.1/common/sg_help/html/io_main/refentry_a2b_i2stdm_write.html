A2B - I2S/TDM Write

A2B - I2S/TDM Write — Write values to the A2B bus

Library

Simulink Real-Time - Speedgoat

Description

The A2B I2S/TDM Write block allows you to write TDM data to the selected A2B Interface.

Ports

This driver block has n intput ports of type uint32, where n is twice the number of the selected amount of TDM channels, as the physical A2B unit uses two TDM lines per selected channel. Each input port contains the data of one TDM slot.

Inputs
X (X is the TDM slot number)

The value of TDM slot X. Type uint32.

The input width of all the ports is defined by the Frame Size parameter.

Parameters

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

A2B Interface ID

This parameter selects the physical A2B Interface on the front connector of the -40 I/O interface extension to which TDM data is written.

Frame Size

This parameter defines the number of A2B frames per sample step. The samples are available at the input ports in a vector size equal to the value defined in the Frame Size field.

The parameter is only informative and cannot be modified. The parameter value is propagated from the corresponding A2B Setup block.

TDM Mode

This parameter defines the number of slots per A2B frame. Every TDM slot is represented as an input port of this block. Since there are two interleaved TDM interfaces per physical A2B node, the number of input ports is twice the selected TDM Mode.

This parameter is only informative and cannot be modified. The value is defined by the corresponding node configuration file, selected in the A2B Setup block.

TDM Size [Bits]

This parameter defines the number of bits per slot in the TDM interface. Only the lower TDM Size [Bits] of the input port will be valid.

The parameter is only informative and cannot be modified. The value is defined by the corresponding node configuration file, selected in the A2B Setup block.

A2B Data Size [Bits]

This parameter defines the number of bits per slot in the A2B stream.

This parameter can only be configured when the selected node is configured as a subordinate node. The value must match the A2B data size of the main node that will be connected to this subordinate node.

If the selected node is configured as a main node, the parameter is only informative and cannot be modified. In this case the value is defined by the corresponding node configuration file, selected in the A2B Setup block.

Sample Time [s]

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time.

Note

If this block is synchronized to the A2B bus using Interrupts, set the parameter value to -1 for inherited sample time.
