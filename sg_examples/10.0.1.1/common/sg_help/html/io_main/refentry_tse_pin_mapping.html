TSE Pin Mapping

TSE Pin Mapping — Reference information about the I/O module connectors

Communication

PortDescription
ETH1EtherCAT in: connect to the target machine or the previous device of the chain
ETH2EtherCAT out: connect to the next device of the chain

Power Supply and Interlock

PinDescription
1Interlock: connect, e.g., to a rack door switch
2Interlock: connect, e.g., to a rack door switch
348 V+: connect to power supply unit
448 V-: connect to power supply unit
5Earth Terminal: must be connected to the protective earth (PE)

TSE Connectors

PinDescription
1TEMP-: Negative temperature sensor output pin. Connect to the BMS.
2TEMP+: Positive temperature sensor output pin. Connect to the BMS.
3TEMP Sense-: Negative temperature sensor output pin for the sensing line. Connect to the BMS.
4TEMP Sense+: Positive temperature sensor output pin for the sensing line. Connect to the BMS.
