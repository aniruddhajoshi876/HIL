IO907/IO908 - Write

IO907/IO908 - Write — Writes the shared memory

Library

Simulink Real-Time - Speedgoat

Description

Before you begin to configure this block, ensure that you have a predefined shared memory partition structure (refer to the Usage Notes). The Write block requires this structure to define how Simulink signal values are mapped in the shared memory. It also uses this structure to determine the total size and address of the shared memory.

Ports

Inputs
Data

Data to write to the module according to the partition structure.

Outputs
Status

Board status byte with the following bits:

  • 0: Own Data — The return of the data packet has been detected. This indicates that the link is intact

  • 1: Bad Data — Invalid data or data loss detected

  • 2: Rx Signal Detect — Light is detected on the receiver

  • 3: Latched Sync Loss — Loss of a valid signal detected

  • 4: Latched Rx FIFO Almost Full — Rx FIFO is operating at the maximum acceptable rate

  • 5: Latched Rx FIFO Full — Rx FIFO is full. Indicates a fault condition due to a board malfunction

  • 6: Tx FIFO Almost Full — Indicates that the Tx FIFO is almost full

  • 7: Tx FIFO Empty — Indicates that the Tx FIFO is empty

Parameters

Module Type

Select the type of your I/O Module installed in your target machine.

Module ID

This ID defines the link to the corresponding Setup block

Partition Struct

Enter the name of the predefined shared memory partition structure. The block uses this structure to specify how Simulink signal values are mapped in the shared memory.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Board Status Port

Select this check box to monitor the board status.

Enable DMA

Use DMA to transmit data to the shared memory.
