FIU Pin Mapping

FIU Pin Mapping — Reference information about the I/O module connectors

Communication

PortDescription
ETH1EtherCAT in: connect to the target machine or the previous device of the chain
ETH2EtherCAT out: connect to the next device of the chain

Power Supply and Interlock

PinDescription
1Interlock: connect, e.g., to a rack door switch
2Interlock: connect, e.g., to a rack door switch
348 V+: connect to power supply unit
448 V-: connect to power supply unit
5Earth Terminal: must be connected to the protective earth (PE)

FIU Connectors

PinDescription
1BAT- out: Negative fault insertion output pin for cell voltage which can be used to connect cells in series.
2BAT+ out: Positive fault insertion output pin for cell voltage which can be used to connect cells in series.
3BMS-: Negative fault insertion output pin for cell voltage which can be used to connect to the CMU of a BMS (Device Under Test).
4BMS+: Positive fault insertion output pin for cell voltage which can be used to connect to the CMU of a BMS (Device Under Test).
5BAT+ in: Positive fault insertion input pin for cell voltage. Connect to the BCE.
6BAT- in: Negative fault insertion input pin for cell voltage. Connect to the BCE.
7Sense+: Positive fault insertion input pin for the sensing line. Connect to the BCE.
8Sense-: Negative fault insertion input pin for the sensing line. Connect to the BCE.
