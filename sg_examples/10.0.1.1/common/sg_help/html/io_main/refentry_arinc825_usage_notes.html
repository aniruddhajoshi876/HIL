Scheduled Messages Configuration File

The configuration file must contain a header row, followed by the data values. The file types supported are: .csv and .xls. The file below shows how the header must look and indicates the data required.

Runtime License

ARINC 825 blocks require a runtime license installed on the target machine. Please refer to the Runtime Licensing help.
