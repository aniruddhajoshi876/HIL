IO602/IO603/IO691 - LIN Write

IO602/IO603/IO691 - LIN Write — Send messages over LIN

Library

Simulink Real-Time - Speedgoat

Description

Note

LIN is currently only available for the IO603 I/O module.

This LIN Read driver block is part of the generic block library for the IO602-2, IO602-4, IO603, and IO691 I/O Modules.

This block allows LIN messages to be transmitted. The message information (LIN version, ID, DLC (Data Length Code)) can be set in the block mask.

For each LIN message, a single write block is required.

Ports

Inputs
Data

The number of bytes is defined in the block mask with the parameter DLC. When using the LIN Pack block, the parameter DLC must always be set to 8. For more information on using the LIN Pack block, refer to the usage notes of this I/O module.

Data Type: uint8

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel Number

Choose the LIN channel to which this driver block should be connected.

LIN Node Type

Displays the channel mode (Disabled, Slave, Master) that has been set in the CAN and LIN Setup block for the selected Channel Number.

Message Type

Currently only the message type RAW is supported.

Show Enable Response Input

If this option is checked, an additional input port is created, which allows response messages to be enabled/disabled for the selected ID during runtime.

Identifier

Message ID of the LIN message without parity protection. Valid values are in the range 0 through 63.

Caution

LIN specifies the Protected ID (PID) to be a 8-bit value, where bits 7 and 8 contain parity sums over the other bits. The ID therefore consists of bits 1 through 6.

DLC

Identifies the length of the LIN message data array (Data Length Code). The value can be chosen in the range of 1 through 8.

Caution

LIN version 1.1 defines the DLC as a function of the ID (0-31: 2; 32-47: 4; 48-63: 8).

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
