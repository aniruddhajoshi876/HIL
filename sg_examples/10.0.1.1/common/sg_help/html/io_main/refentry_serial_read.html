Serial - Read

Serial - Read — Reads the serial ports

Library

Simulink Real-Time - Speedgoat

Description

This block is part of the Speedgoat Serial driver block set for the Speedgoat Serial modules IO50X and IO581. The Serial Read block reads characters from the I/O module FIFO in the UART.

It then outputs those characters as the low-order byte of an unsigned 32-bit integer vector. This output vector is large enough to hold the maximum number of characters that the FIFO can hold.

Ports

Outputs
Count

Amount of received bytes.

Data

Data output signal.

Block Parameters

Module Type

Select the type of your I/O Module installed in your target machine.

Module ID

This ID defines the link to the corresponding Setup block

Channel

This parameter specifies the channel from which this block reads the data.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Flush HW FIFO on startup

Select this check box to flush the FIFO when the device starts up.

Enable Legacy Mode

This checkbox can be used to enable/disable the legacy mode of the Serial Read block. If this mode is enabled, the Data output contains a vector where the first element of the vector specifies the number of data elements in the remainder of the vector.
