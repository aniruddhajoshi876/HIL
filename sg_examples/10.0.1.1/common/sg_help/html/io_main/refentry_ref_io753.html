IO753 — Modbus TCP Client I/O module

Introduction

The IO753 is a configurable Modbus TCP Client I/O module. The solution is part of the IO64X/IO75X I/O module family which provides support for a wide range of industrial protocols. The IO753 module acts as one Modbus TCP Client exclusively.
