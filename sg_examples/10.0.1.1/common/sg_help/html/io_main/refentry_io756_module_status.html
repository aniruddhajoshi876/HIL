IO756 - Module Status

IO756 - Module Status — Reads the current module status

Library

Simulink Real-Time - Speedgoat

Description

This block is used to monitor the temperature of the I/O module.

Ports

Outputs
FPGA Temperature

FPGA temperature in °C. Type double. This port is enabled or disabled by the Read FPGA Temperature parameter in the dialog box of this block.

Board Temperature

Board temperature in °C. Type double. This port is enabled or disabled by the Read Board Temperature parameter in the dialog box of this block.

Parameters

Module ID

This ID defines the link to the corresponding Setup block.

Sample Time [s]

Defines the base sample time at which this driver block gets its sample hit. It can also be set to -1 for inherited sample time. The units are in seconds.

Read FPGA Temperature

When this parameter is checked, an output port labeled FPGA is available.

Read Board Temperature

When this parameter is checked, an output port labeled Board is available.
