Cam and Crank - Cam Decoder v1

Cam and Crank - Cam Decoder v1 — The cam decoder acquires a camshaft signal (generated from a cam encoder) and decodes the start position and the camshaft tooth size.

Library

Simulink® Real-Time™ - Speedgoat

Description

The cam decoder acquires a camshaft signal (generated from a cam encoder) and decodes the start position and the camshaft tooth size.

Ports

The Simulink block has two output ports:

Outputs
Cam tooth offset

Displays the cam tooth offset in degrees.

Cam tooth size

Displays the cam tooth size in degrees.

Parameters

Tab: Module setup
Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Channel Vector

A vector of channels this driver block entity will access. You can specify channels in the range 1-N (N = the number of channels implemented in your specific configuration file defined in the Setup block). The width of this vector also defines the subsequent size of some of the following parameters if scalar expansion applies. With a single block, all the channels of the block are synchronized.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Tab: Cam Decoder
Crank master vector (read only)

The corresponding crank decoder master. This parameter is read-only, and therefore only for information purpose. The crank decoder master is predefined during the pin layout.

Number of teeth vector (read only)

This parameter defines the number of teeth defined in the crank decoder master. This parameter is read-only, and therefor only for information purpose. The number of teeth vector is defined in the crank decoder mask.
