IO750 - Receive v2

IO750 - Receive v2 — Receives cyclic data from the EtherCAT network

Library

Simulink Real-Time - Speedgoat

Description

This block is used to read the process data objects the subordinate device receives from the EtherCAT main device. Your model must contain one Receive v2 block for each I/O module in your target machine.

Caution

This block is only supported by MATLAB from R2019b.

Ports

Inputs

This block does not have any input ports.

Outputs

Depending on the value of the Port Type parameter, this block will have different port setups:

One output port of data type uint8

The Port Type parameter is set to Byte Vector.

The port has no label. The number of elements results from the total length of the Rx PDO mapping table in the related Setup block. Please consider the byte padding which is described in the Setup block Help documentation.

Multiple output ports of different data types

The Port Type parameter is set to Separate Signals.

There is one port for each signal defined in the Rx PDO mapping table in the related Setup block. Padding bits are not output. The port label consists of the PDO name and the signal name of the related Rx PDO mapping row.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Port Type

  • Byte Vector: The block has only one port of data type uint8 where all the related PDOs are packed in consecutively

  • Separate Signals: The block has multiple ports. There is one port for each PDO signal

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.

Retrieve PDO Configuration

Retrieves the Rx PDO configuration from the related Setup block and updates the output ports.
