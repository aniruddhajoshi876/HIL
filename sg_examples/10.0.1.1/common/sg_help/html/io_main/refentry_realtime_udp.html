Real-Time UDP

Introduction

The real-time Universal Datagram Protocol (UDP) is supported on all Ethernet interfaces. Refer to the Speedgoat Ethernet Interfaces documentation as well as the examples below.

For additional information on real-time UDP, please consult the MathWorks web documentation. For the local MathWorks help, enter the following code in the MATLAB® command window:

eval('helpview(fullfile(docroot,''slrealtime'', ''real-time-udp.html''))')
