IO511

IO511 — The IO511 I/O module is a serial module supporting the SDLC and HDLC protocols

Introduction

The IO511 I/O module provides 4 fully independent full-duplex serial ports supporting the SDLC and HDLC synchronous protocols.

The buffer size is 512 bytes per direction for each channel.
