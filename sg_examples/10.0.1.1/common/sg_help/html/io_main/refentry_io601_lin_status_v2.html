IO601 - LIN Status v2

IO601 - LIN Status v2 — This block is used to read status information from the LIN channel

Library

Simulink Real-Time - Speedgoat

Description

This block can be used to get the current status of a LIN channel. The link to the corresponding LIN module can be set in the block mask. The status information is updated every 128ms by the LIN controller on the IO601 module.

Ports

Outputs
Role

LIN operating mode:

  • 0: Slave

  • 1: Master

Data Type:uint32

Bus load

Bus load in [%]. Data Type:uint32

Baud rate

The currently configured baud rate in [bits/s]. Data Type:uint32

Status

LIN status:

  • 0: No error

  • 1: Receive queue overflow (Already one or more messages lost. The module must be re-initialized to reset the status.)

  • 16: LIN controller is still in init mode

Data Type:uint32

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Enable Role

Enables the output port for role information.

Enable Busload

Enables the output port for busload information.

Enable Baud rate

Enables the output port for baud rate information.

Enable Status

Enables the output port for status information.
