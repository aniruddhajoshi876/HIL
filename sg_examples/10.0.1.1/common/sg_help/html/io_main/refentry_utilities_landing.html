Utilities — Speedgoat utilities blocks

Utilities Blocks

Speedgoat offers the following utilities blocks:

  • Read MAC address

  • Read CPU temperature

  • Interrupt Setup

  • Read serial number

  • Read target time

  • Get memory info

  • Get disk space
