IO629 - Remote Terminal

IO629 - Remote Terminal — Simulate an ARINC629 remote terminal unit

Library

Simulink Real-Time - Speedgoat

Description

Remote Terminals can transmit on the ARINC 629 databus. The configuration of Remote Terminal parameters is partially done in the block mask and partially with a .csv file containing the XPP information.

Ports

This block provides only input ports. The number and size of the input ports is defined in the XPP .csv cofiguration file.

Parameters

Submodule ID

This parameter holds the reference to the corresponding Submodule block.

Block Sample Time

This parameter defines the base sample time at which this driver block gets its sample hit. It can also be set to -1 for inherited sample time. The units are in seconds.

Remote Terminal ID

This parameter defines the ID of the Simulink block.

Terminal Gap

This parameter holds the Remote Terminal's Terminal gap. Remote Terminals should be assigned a unique number N from 1 to 125. Several Remote Terminals should not have the same number N. The TG length of time in microseconds is N + 1.6875.

Channel ID

This parameter holds the channel ID.

Mode

This parameter defines either the Block or Independent transmission mode. The XPP format must be defined accordingly (no control is effectuated by the driver).

XPP CSV

This parameter holds the path to the csv file. The browse button might be used to select the file.
