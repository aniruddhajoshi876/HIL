Analog IO32x - Input v1

Analog IO32x - Input v1 — This driver block is available for the IO322 and IO323 modules only.

Library

Simulink Real-Time - Speedgoat

Description

This driver block is available for the IO322/IO323 I/O modules only.

Your model can only contain one of these blocks for each I/O module in your target machine.

Ports

This block has as many outputs as defined by the Channel vector parameter, see Dialog fields.

Outputs
X (X is channel number)

The value read from analog input X. Type double.

Parameters

The IO32x I/O module provides 4 simultaneous ADC with 8x16-bit sequential channels each. Every ADC on the I/O module can be configured with its channel vector, its Range, its Input coupling mode and its trigger mode.

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Channel Vector

A vector of channels this driver block entity will access. You can specify channels in the range 1-N (N = the number of channels implemented in your specific configuration file defined in the Setup block). The width of this vector also defines the subsequent size of some of the following parameters if scalar expansion applies. With a single block, all the channels of the block are synchronized.

The channel vector must start with channel one and contain consecutive channels only.

Range

The Range of the Input channels can be different for every ADC on the I/O module. Please refer to the IO322/IO323 pin mapping section. Please note, that the selected voltage range is a differential voltage which is the maximum range of each ADC. The maximum input voltage range per pin, which can be measured by the ADC is ±12.288 V. For better accuracy, small voltages can be amplified - this parameter is used to indicate the expected input voltage range:

  • ± 24.576 [V] (differential only)

  • ± 20.48 [V] (differential only)

  • ± 10.24 [V]

  • ± 5.12 [V]

  • ± 2.56 [V]

  • ± 1.28 [V]

  • ± 0.56 [V]

Input coupling

The Input coupling can be different for every ADC on the I/O module. Either Single-ended or Differential. Please refer to the IO322/IO323 pin mapping section. Single-ended: For single-ended channels the reference of each input is Ground. This configuration provides the maximum number of input channels. Every ADC provides a maximum of 8 channels Differential: For differential channels each input channel has a dedicated associated reference level channel according to the IO322/IO323 pin mapping. Every ADC provides a maximum of 4 channels

Trigger mode

This parameter defines if the model initiates the sampling. When Initiator is selected, the "ADC trigger" physical pin becomes an output which propagates this signal. When Target is selected, the sampling is triggered by an external source and the driver is then configured as target. In this case the "ADC trigger" physical pin becomes an input used to read a trigger signal. The trigger input is high-level sensitive.
