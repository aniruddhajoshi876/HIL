Ethernet Interfaces

Introduction

Speedgoat real-time target machines provide one or more additional general-purpose Ethernet interfaces. This onboard I/O connectivity can be used for communication protocols, such as UDP, PTP, or EtherCAT Main Device.

Driver Blocks

Drivers for the Ethernet controllers are provided and maintained by MathWorks. They are available in the Simulink Real-Time driver library and can also be accessed via the Speedgoat I/O Blockset: speedgoatlib.

Supported Ethernet Protocols

  • Real-Time UDP: Supported by all Ethernet interfaces, including the one used as Host Link.

  • TCP: Supported by all Ethernet interfaces, including the one used as Host Link.

  • XCP Master or Slave: Supported by all Ethernet interfaces, including the one used as Host Link.

  • EtherCAT Main Device: Supported by all Ethernet interfaces, except the one used as Host Link and the IO716. Refer to the Ethernet Configuration Tool.

  • PTP IEEE 1588: Only supported on interfaces with an I210 controller. It can also be used as Host Link. Note that PTP does not support Model Triggering.

  • Raw-Ethernet: Supported with R2022a and later.

Note

On the ETH1 interface of the Pulse real-time target machine, EtherCAT Main Device communication is limited to a sample time of 1 ms.
