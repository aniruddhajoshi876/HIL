A2B - Setup

A2B - Setup — Configure the A2B bus

Library

Simulink Real-Time - Speedgoat

Description

The A2B Setup driver block configures the A2B bus on the -40 I/O interface extension.

Ports

This driver block has no input or output ports.

Parameters

Main Tab
Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Interface Settings

Select the mode or disable the specified interface.

Note

The number of interfaces displayed depends on the number of I/O interface extensions (-40) activated in the FPGA setup block.

Audio Clock

Set the audio clock to either 44.1 kHz or 48 kHz for the A2B network. Make sure you use the same setting in the configuration file.

Note

In case several nodes are used as main node, the Audio Clock must be the same for all nodes.

Frame Size

Specify the frame size for the TDM data.

A2Bx Tab
Network Configuration File

Specify the path of the configuration file (.dat) to set up the A2B network. Click the Browse button to easily find your file or enter the file name manually. The nework configuration file only needs to be set in case the corresponding A2B node is used as a main node.

Node Configuration File

Specify the path of the node configuration file in order to configure the corresponding A2B interface. Click the Browse button to easily find your file or enter the file name manually. By clicking the Update button, the whole configuration file is parsed again.
