IO424

IO424 — The IO424 is an LVDT/RVDT/Resolver/(Synchro) to digital converter I/O module

Introduction

The IO424 is a 4-channel, 16-bit, LVDT/RVDT/Resolver/(Synchro, depending on the configuration) converter I/O module. This module only has read capabilities, but can generate the excitation reference signal for Resolver and LVDT/RVDT.

Two configurations are available:

ChannelIO424-RIO424-RS
1 Resolver / LVDT(RVDT)Resolver / LVDT(RVDT)
2 Resolver / LVDT(RVDT)Resolver / LVDT(RVDT)
3 Resolver / LVDT(RVDT)Synchro
4 Resolver / LVDT(RVDT)Synchro

Converter channels featuring:

  • Sensor Input:

    • Resolver/LVDT/RVDT: 0-12 Vrms

    • Synchro: 0-28 Vrms

  • Excitation Input:

    • Resolver/LVDT/RVDT: 0-12 Vrms, 1-20 kHz

    • Synchro: 0-28 Vrms, 0.4-20 kHz

  • Excitation Output: 0-12 Vrms, 1-20 kHz, up to 100 mA

  • Resolution:

    • Angle/Stroke: 16-bit

    • Velocity (Resolver): 14-bit

  • Tracking Rate: 1/4 Excitation frequency

  • Accuracy:

    • Resolver Angle: Up to 1.5 arcmin

    • Resolver Velocity: Up to ±0.5 %

    • LVDT/RVDT: Up to ±0.06 %

    • Synchro: Up to 4 arcmin
