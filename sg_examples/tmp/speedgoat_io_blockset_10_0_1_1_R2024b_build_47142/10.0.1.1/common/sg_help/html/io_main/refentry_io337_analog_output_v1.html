Analog IO337-650k - Analog Output v1

Analog IO337-650k - Analog Output v1 — This driver block is available for the IO337-650k.

Library

Simulink Real-Time - Speedgoat

Description

The number of Analog output v1 blocks in your model must match the number of IO337-650k I/O modules installed in your target machine.

Ports

This driver block has n scalar input ports of type double or single, where n is the number of analog output channels selected. Each port (signal) accepts the analog value in volts to be output.

Inputs
X (X is the analog channel number)

The value to be output from analog channel X in volts. The data type is double or single.

Note

The IO337 Analog output block supports single- or double-precision data types as inputs (all inputs must be of the same type). While double-precision data types offer better accuracy, single-precision data types can decrease task-execution time.

Parameters

The configuration details are all defined in the IO337-650k Analog Setup v1 block.

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
