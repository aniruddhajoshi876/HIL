Serial Onboard

Serial Onboard — The Serial Onboard are driver blocks for real-time target machines supporting RS232/422/485 protocols

OnBoard Serial Runtime license

Some functionalities require a runtime license. Refer to the Runtime Licensing page for additional information.

Licensed features for the Pulse real-time target machine are as follows:

  • RS422/RS485

  • Custom baud rates in the declared range. Without a license, only a list of standard baud rates in the declared range is available.
