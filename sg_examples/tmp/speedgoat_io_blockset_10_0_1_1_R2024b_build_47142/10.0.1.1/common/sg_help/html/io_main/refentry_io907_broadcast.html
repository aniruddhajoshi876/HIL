IO907/IO908 - Broadcast

IO907/IO908 - Broadcast — Generates a network interrupt

Library

Simulink Real-Time - Speedgoat

Description

The Broadcast driver block generates a network interrupt that other boards in the shared memory network can detect.

Ports

Inputs
En

This input port is a Boolean input that can enable or disable the transmission of a network interrupt. For continuous interrupts. connect this input port to a Constant block with a Boolean value of true (1). If you want to enable interrupts only part of the time, you can use another kind of input, such as a pulse generator.

Data

This input port allows you to transmit a data value (uint32) with the interrupt.

Parameters

Module Type

Select the type of your I/O Module installed in your target machine.

Module ID

This ID defines the link to the corresponding Setup block

TargetNode (-1: Global)

Enter the node ID of the node to which to broadcast the interrupt. Enter -1 to broadcast the interrupt to the nodes in the shared memory network. You cannot broadcast the interrupt to another subset of nodes.

Interrupt Number

Enter the shared IRQ number. This value is the special interrupt number that two boards use between each other for synchronization (refer to the Usage Notes). This value must match the value of X in a line like the following, which you can specify for the receiving end of the shared memory network:

node.Interface.Interrupts.PendingIntX
Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
