CAN Message Utilities blocks

CAN Message Utilities blocks — CRC and Counter insert and validation blocks for CAN and CAN FD messages.

Introduction

The CAN Message Utilities driver blocks are used to insert, extract, and validate CRC or Counter values within a CAN or CAN-FD message payload. These functionalities are typically used in the implementation of AUTOSAR E2E protection profiles.

Driver Blocks

  • Counter Insert

  • Counter Validation

  • CRC Insert

  • CRC Validation
