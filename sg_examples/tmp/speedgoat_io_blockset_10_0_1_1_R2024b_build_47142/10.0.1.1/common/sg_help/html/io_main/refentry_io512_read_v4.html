IO512 - HDLC/SDLC Read v4

IO512 - HDLC/SDLC Read v4 — Reads the serial ports

Library

Simulink Real-Time - Speedgoat

Description

This block reads characters from the I/O module FIFO. Use one block per enabled channel.

Ports

Outputs
Count

Amount of received bytes.

Data

Data output signal.

Block Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel

This parameter specifies the channel from which the block reads the data.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
