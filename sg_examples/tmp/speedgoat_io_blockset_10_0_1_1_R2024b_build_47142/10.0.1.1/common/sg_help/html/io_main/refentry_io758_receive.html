IO758 - Receive

IO758 - Receive — Receives cyclic data from the POWERLINK managing node

Library

Simulink Real-Time - Speedgoat

Description

This block is used to receive data from the POWERLINK managing node connected with the IO758 module.

Your model can contain only one Receive block for each I/O module in your target machine.

Ports

Outputs

One vector of data type UINT8 which the block reads from the input data area of the dual-port memory. This area contains data which has been received from the POWERLINK managing node. Use Byte Unpacking blocks to extract specific data. The Number of Bytes parameter sets the length of this vector.

Type: scalar | vector

Data Type: uint8

Inputs

This block does not have any input ports.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Port Type

Always select 1 port with n element vector of type uint8

Number of Bytes

This parameter defines the length of the output port and thus the number of bytes to be read from the module's input data area (RX). Refer to the usage notes to learn how to use this parameter.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.
