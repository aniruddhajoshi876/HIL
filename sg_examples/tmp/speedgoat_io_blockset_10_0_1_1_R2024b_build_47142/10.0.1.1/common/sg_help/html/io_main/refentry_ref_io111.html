IO111

IO111 — Fast 16-bit analog module with 16 single-ended analog output channels

Introduction

This I/O module is a dedicated analog output module with a resolution of 16 bits. Each of its 16 output channels has its dedicated D/A converter with an update time of 3µs. The output coupling of the module is single-ended for all channels. The output range of each channel can be selected individually.

The IO111 uses Quad-DAC (Q-DAC) devices. Each Q-DAC device provides four D/A channels, internally called A, B, C and D.
