OPC UA

OPC UA — Speedgoat driver blocks for OPC UA

Introduction

OPC UA is an Ethernet communication protocol based on a client-server architecture. Every information in the server is represented by nodes of different node classes like objects, variables and methods. Depending on the node class, the node has different attributes such as name, value and unit. Nodes can be derived from other node definitions, they can have references to one another and they are part of a node tree whose structure is given by the information model used. Clients connect to servers to read and write nodes, call methods, request historical data, check alarms, or transfer a file. Speedgoat provides a native interface for OPC UA which is supported with the onboard Ethernet interfaces and I/O modules. The OPC UA protocol stack runs on the target machine's CPU. Simulink driver blocks for client and server operation are available.
