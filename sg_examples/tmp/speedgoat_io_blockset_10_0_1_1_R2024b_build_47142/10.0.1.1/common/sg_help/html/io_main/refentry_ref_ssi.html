SSI

SSI — Synchronous Serial Interface (SSI) is a widely used serial interface standard for industrial applications between a master and a slave

Introduction

Speedgoat provides three SSI code modules for the configurable I/O modules:

  • SSIM - SSI master (also SSI2 Codechamp)

  • SSIS - SSI slave

  • SSI Sniffer
