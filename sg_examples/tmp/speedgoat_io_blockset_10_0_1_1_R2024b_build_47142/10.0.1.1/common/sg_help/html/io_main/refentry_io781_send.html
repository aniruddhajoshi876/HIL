IO781 - Send

IO781 - Send — Writes to an A653 Comm (Queuing type or Sampling type) port

Library

Simulink Real-Time - Speedgoat

Description

IO781 AFDX Send block is used to write to an A653 Comm (Queuing type or Sampling type) port.

Ports

Inputs
Data

Data to send. The port width must be set in the block mask. Data type is uint8.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Port ID

ID of the A653 Tx Comm port. This value must be set according to the configuration designed with Flight Simulyzer and stored in the .adc file. If this field refers to a non-existing port in the ES configuration, a fatal error will occur, causing a target machine crash. Be aware, this ID is not the UDP port ID but rather the ID of the port configuration in the .adc file.

Message Length

Defines the output port width (in bytes).
