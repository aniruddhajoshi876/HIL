-21 Pin Mapping — Reference information about the I/O module connector

Description

The -21 I/O interface extension converts the rear I/O lines from LVCMOS to 3.3 V/5 V TTL and makes them accessible from the front of the enclosure. The -21 extension provides 56 TTL I/O lines. The I/O lines are distributed in 7 groups of 8 lines. All 8 lines of a group must have the same direction and pull resistor configuration. The pull resistors of the 7 I/O port groups can be configured using the mask of the Setup block.
