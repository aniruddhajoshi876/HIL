BiSS

BiSS — BiSS is a digital interface for sensors and actuators. BiSS is hardware compatible to the industrial standard SSI but offers additional features and options

Introduction

Speedgoat provides three BiSS code modules for the configurable I/O modules:

  • BiSS Sniffer - Can be used to monitor the data stream of an existing BiSS communication setup

  • BiSS Decoder - Implementation of a BiSS Decoder (master) module to establish communication with a BiSS encoder

  • BiSS Encoder - Implementing of a BiSS Encoder (slave) module to establish communication with a BiSS master
