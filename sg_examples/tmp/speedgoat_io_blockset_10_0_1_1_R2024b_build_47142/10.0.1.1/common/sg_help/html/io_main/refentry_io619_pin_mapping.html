Both ports are internally connected together (internal loopback).

Note

Termination is not included. Use a 120 Ω resistor between the positive and negative data lines to terminate the lines. This applies only for the ESD version.

Important

All nodes on the same bus segment must be of the same type (ESD or EMD).
