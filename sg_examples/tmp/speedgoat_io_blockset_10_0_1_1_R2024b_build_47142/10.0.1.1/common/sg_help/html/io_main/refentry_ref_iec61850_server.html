IEC 61850 Server

IEC 61850 Server — Simulink driver blocks for the native IEC 61850 Server interface

Introduction

Simulink driver blocks for the IEC 61850 Server enable data to be exchanged with multiple remote IEC 61850 Clients. Support for the IEC 61850 Server is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
