IO642 - Send v2

IO642 - Send v2 — Transmits cyclic data to the PROFIBUS master

Library

Simulink Real-Time - Speedgoat

Description

This block is used to transmit data to the PROFIBUS master connected with the IO642 module.

Your model can contain only one Send block for each I/O module in your target machine.

Ports

Inputs

One vector of data type UINT8 which the block writes to the output data area of the dual-port memory. This area contains data which is sent to the PROFIBUS master. Use Byte Packing blocks to assemble the vector from specific data. The Number of Bytes parameter sets the length of this vector.

Type: scalar | vector

Data Type: uint8

Outputs

This block does not have any output ports.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Number of Bytes

This parameter defines the length of the input port and thus the number of bytes to be written to the module's output data area (TX). The total amount of data the slave sends to the master is determined by the number and type of PROFIBUS data modules configured in the master configuration tool. Refer to the usage notes for examples.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.
