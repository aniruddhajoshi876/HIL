Pulse I/O

Pulse I/O — The Pulse I/O provides configurable I/O functionality in combination with I/O interface extensions

Note

The information on this page applies to MATLAB R2025a and later.

Introduction

Configurable I/O modules provide a flexible and cost-effective way to configure and reconfigure I/O and protocol functionalities for a set of code modules.

Configuration files, once purchased from Speedgoat, can be downloaded from the Speedgoat Customer Portal and also come with the following items:

  • Documentation: Comprehensive documentation including installation steps, descriptions of implemented functionality, pin mapping diagrams and explanations on how to get started with demo model examples

  • Simulink® Library: A Simulink library, including links to the main Speedgoat I/O Blockset, and which clearly shows the version of the driver blocks that match with your specific FPGA bitstream

  • Simulink demo model: A simple demo model illustrating how the implemented code module functionality is used, with loopback wirings wherever possible

Driver Blocks

Use the configurable I/O Setup block to define the parameters for your Pulse I/O. Based on the I/O and protocol functionalities implemented in your configuration file, a broad range of different driver blocks are supported.

Configuration Files

The Speedgoat I/O Blockset includes configuration files for all possible hardware configurations with up to two I/O interface extensions. The configuration files implement the DIO functionality on every available digital pin, and the analog functionality on every available analog pin. Depending on the hardware setup, the corresponding configuration file must be selected in the drop-down list of the Setup block.
