IO672 - Decode BC Status

IO672 - Decode BC Status — Extracts status from Decode BC Message block

Library

Simulink Real-Time - Speedgoat

Description

This block extracts individual status bits from the status output of the Decode BC Message block.

Ports

Inputs
Status

BC Status Message.

Outputs
Status Bit

Extracted status bits.

Parameters

Status to read

The status to read. The Decode BC Status block extracts individual status bits from the status output of the Decode BC Message block.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
