IO642 — Configurable PROFIBUS DP Slave I/O module

Introduction

The IO642 and the IO642-32 are configurable PROFIBUS Slave I/O modules. They belong to the IO64X/IO75X I/O module family, which provides support for a wide range of industrial protocols. The IO642 module acts as one PROFIBUS Slave exclusively, whereas the IO642-32 simulates up to 32 PROFIBUS Slave nodes. The IO642 driver blocks can be used with the IO642 module as well as with the IO642-32 module.
