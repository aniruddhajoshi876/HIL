EVSE - Setup

EVSE - Setup — Configures one EVSE charging board

Library

Simulink Real-Time - Speedgoat

Description

The EVSE Setup block configures one EVSE charging board, establishing the MQTT connection to the EV Charging box using the configured IP address and allows to configure some static base parameters of the system. However, these parameters can still be overwritten in later stages of the charge cycle if needed.

Ports

This driver block has no input or output ports.

Parameters

The two tabs of the setup parameter dialog box contain the configuration settings for the EVSE charging board.

Main Tab
Station ID

The Station ID is used to assign Setup, Read and Write blocks to a particular MQTT client station. Station IDs range between 0 to 65535 and must be unique along all Setup blocks in a model. You can define multiple clients by placing a Setup block with a unique Station ID for each client.

Connection ID

The Connection ID is used to assign Publish and Subscribe blocks to a particular client-broker connection. Connection IDs range between 0 to 65535 and must be unique along all Connections blocks of the client (these blocks have the same Station ID).

Client Identifier

The Client Identifier represents the MQTT client in the local network and must be unique along all clients in that network. The parameter is a character array with a length limit of 256.

Local IP Address

Enter the IP address of the MQTT client. This step does not assign the IP address to an Ethernet interface; instead, it binds the Setup block to an IP address, which was previously configured in the Ethernet Configuration Tool. Refer to the MQTT usage notes for further information.

Sample Time

Defines the base sample time at which data is exchanged with the EV charging board. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Remote TCP Port

Enter the TCP port the remote MQTT broker is listening on for connection requests. The default value is 1883.

Remote IP Address

Enter the IP address of the EV charging board.

Charging Configuration Parameters Tab
Max. Voltage Limit [V]

Specify the maximum voltage limit of the EVSE station in volts.

Max. Current Limit [A]

Specify the maximum current limit of the EVSE station in amperes.

Min. Current Limit [A]

Specify the minimum current limit of the EVSE station in amperes.

Max. Power Limit [W]

Specify the maximum power limit of the EVSE station in watts.

Min. Voltage Limit [V]

Specify the minimum voltage limit of the EVSE station in volts.

Current Regulation Tolerance

Specify the current regulation tolerance of the EVSE station in percentages (0-100).

Peak Current Ripple

Specify the peak current ripple of the EVSE station in amperes.
