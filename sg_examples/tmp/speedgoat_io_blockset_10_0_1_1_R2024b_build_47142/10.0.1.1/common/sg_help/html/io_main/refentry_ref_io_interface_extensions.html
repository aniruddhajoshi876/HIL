I/O Interface Extensions

The I/O interface extensions can be used to extend the I/O of the configurable I/O modules with different I/O standards, analog functionality and others. Depending on the I/O module, there can be up to two I/O interface extensions installed.

  • -21: Converts the rear I/O lines from LVCMOS to 3.3 V/5 V TTL, and makes them accessible from the front of the enclosure

  • -22: Converts the rear I/O lines from LVCMOS to RS422, RS485, and 3.3 V/5 V TTL and makes them accessible from the front of the enclosure

  • -24: Makes use of the LVCMOS rear I/O lines to interface with two Resolver-to-Digital Converters. Converts some of the rear I/O lines from LVCMOS to RS422, RS485, and 3.3 V/5 V TTL and makes them accessible from the front of the enclosure

  • -40: Provides two A2B nodes of type AD2433, and makes them accessible from the front of the enclosure

  • -120: Provides the following analog functionality:

    • 16 x 16-bit analog inputs up to 1.5 MSPS sampling rate

    • 16 x 16-bit analog outputs up to 10 MSPS update rate

Note

Further information on the I/O interface extensions is also available in the HDL Coder help.
