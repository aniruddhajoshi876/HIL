-120 I/O Interface Extension

-120 I/O Interface Extension — 16 x 16-bit ADCs up to 1.5 MSPS sampling rate, 16 x 16-bit DACs up to 10 MSPS update rate

Introduction

The IO3xx-120 I/O interface extension provides the following analog functionality:

  • 16 x 16-bit analog inputs up to 1.5 MSPS sampling rate with simultaneous sampling

  • 16 x 16-bit analog outputs up to 10 MSPS update rate

The Analog setup, Analog input, and Analog output driver blocks are described in more detail in the following sections.
