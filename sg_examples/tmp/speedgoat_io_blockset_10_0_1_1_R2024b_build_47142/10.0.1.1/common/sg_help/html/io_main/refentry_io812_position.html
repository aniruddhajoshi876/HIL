IO812 - Position

IO812 - Position — Position of one axis from one ZMI4104 card.

Library

Simulink Real-Time - Speedgoat

Description

The output of this driver block contains Position of one measurement axis.

Ports

This driver block has at least one output port (Position). In addition output ports for velocity and time measurements can be configured.

Outputs Port
Position

Contains the value for position of the selected axis.

Velocity

In case the Velocity measurement box in the mask is checked, the block has a corresponding velocity output.

Time

In case the Time measurement box in the mask is checked, the block has a corresponding time output.

Parameters

Block setup Tab
ZMI4104C identifier

Select the identifier for the ZMI card identity with 1 for ZMI card one and 2 for ZMI card two.

Measurement axis

Select the axis for the measurement (1 to 4)

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Measurment Tab
Velocity measurement

Adds one output port to measure the velocity. This measurement requires one 32-bit PCI read.

Time measurement

Adds one output port to measure time. This measurement requires one 32-bit PCI read.
