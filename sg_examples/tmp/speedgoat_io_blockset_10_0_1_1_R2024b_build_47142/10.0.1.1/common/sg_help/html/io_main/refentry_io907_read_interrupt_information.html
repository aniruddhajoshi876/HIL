IO907/IO908 - Read Interrupt Information

IO907/IO908 - Read Interrupt Information — Reads the network interrupt

Library

Simulink Real-Time - Speedgoat

Description

The Read Interrupt Information driver block outputs the information bound to network interrupts that other boards in the shared memory network emitted. Use the Speedgoat IO907/IO908 preserve interrupt messages interrupt to read this information. If this information is not required, simply use the Speedgoat IO907/IO908 interrupt — the Read Interrupt block is not needed.

Ports

Outputs
Data

This output port carries the data value (uint32) associated with the interrupt.

ID

This output port carries the ID of the node which emitted the interrupt.

Status

This output port is true (1) when the value defined for the Interrupt Number has been received.

Parameters

Module Type

Select the type of your I/O Module installed in your target machine.

Module ID

This ID defines the link to the corresponding Setup block

Interrupt Number

Enter the shared IRQ number. This value is the special interrupt number that two boards use between each other for synchronization (refer to the Usage Notes). This value must match the value of X in a line like the following, which you can specify for the receiving end of the shared memory network.

node.Interface.Interrupts.PendingIntX
Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
