IO131

IO131 — Fast simultaneous sampling 16-bit isolated analog input and output module

Introduction

The IO131 I/O module provides 16 isolated 16-bit simultaneous sampling analog input channels and 8 isolated 16-bit simultaneous update analog output channels.

  • 16 analog input channels featuring:

    • True differential coupling

    • Isolated channels

    • Successive-approximation (SAR) conversion

    • Simultaneous sampling

    • Voltage ranges of ±5 V, ±10 V (applies to all inputs)

    • Maximum sample rate: 200 kS/s

    • Frame based autonomous data transfer (DMA) possible

  • 8 analog output channels featuring:

    • Single ended coupling

    • Isolated channels

    • Simultaneous update

    • Voltage ranges of 0–5 V, 0–10 V, ±5 V, ±10 V (applies to all outputs)

    • Maximum conversion rate: 100 kS/s

    • Frame based autonomous data transfer (DMA) possible
