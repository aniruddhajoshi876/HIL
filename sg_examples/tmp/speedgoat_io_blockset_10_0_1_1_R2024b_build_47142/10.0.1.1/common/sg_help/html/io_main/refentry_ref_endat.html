EnDat

EnDat — The EnDat interface is a digital, bidirectional interface for encoders. It is capable of transmitting position values from incremental and absolute encoders

Introduction

Speedgoat provides three EnDat code modules for the configurable I/O modules:

  • EnDat Sniffer - Can be used to monitor the data stream of an existing EnDat communication setup

  • EnDat Decoder - Implementation of an EnDat Decoder (master) module to establish communication with an EnDat encoder

  • EnDat Encoder - Implementing of an EnDat Encoder (slave) module to establish communication with an EnDat master
