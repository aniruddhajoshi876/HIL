ARINC 825 - Setup

ARINC 825 - Setup — This block is used to configure the ARINC 825 I/O module

Library

Simulink Real-Time - Speedgoat

Description

Your model can contain only one Setup block for each I/O module in your target machine.

Ports

This driver block has no input or output ports.

Parameters

Tab: Main
Module Type

Select the type of your I/O Module installed in your target machine.

Module ID

The Module ID has two functions:

  • It defines the logical connection between the Setup block and its I/O blocks

  • It also informs the auto-search feature of the PCI Slot parameter. If only one I/O module of this type is installed, the Module ID must be set to 1. If n modules are installed, it must be in the range 1:n. Not all the I/O modules installed in the target machine need to be used. To see how each I/O module maps to a Module ID, use this Speedgoat API: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat")
PCI Slot (-1: auto-search)

There are two approaches for mapping this block to a specific I/O module installed in your target machine. All modules of the same type must be configured using the same method.

  • Auto-Search: with the default value -1 the I/O module will be automatically located in the target machine. If you have multiple modules of the same kind, the Module ID defines which module is associated with this block. To see how each I/O module maps to a Module ID, use this Speedgoat API: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat")

  • Explicit Addressing: to explicitly define the logical address of the I/O module in the target machine, you can provide the PCI bus and slot numbers as a vector: [bus, slot]. To determine these numbers, run the following command in the MATLAB command window: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat", "Advanced", true)

    Note that the PCI address can change whenever an I/O module is added or removed – usually, auto-search is the best option.

Channel [1, 2, 3, 4]

Select the protocol mode or disable the specified channel.

Note

The number of displayed channels depends on the selected Module Type.

Use Disabled Channels with CAN Blocks

This option allows you to use disabled channels with the CAN blocks. A CAN Setup block with the same Module ID must be used to initialize the channels to be used with the CAN blocks.

Tab: Channel Config
Nominal Baud Rate

Select a baud rate from the drop-down menu. If you cannot find the value you require, select Custom to enable the bit timing parameter.

[BRP, SJW, TSEG1, TSEG2]

If the Custom option has been selected with the Nominal Baud Rate parameter, this parameter is used to configure the bit timing. The [BRP, SJW, TSEG1, TSEG2] parameter is a vector with the following elements:

  • Bit Rate Prescaler (BRP)

  • Synchronization Jump Width (SJW)

  • Time Segment 1 (TSEG1)

  • Time Segment 2 (TSEG2)

The clock rate of the CAN controller is 80 MHz. For additional information refer to can-wiki, info.

Data Baud Rate

Select a baud rate from the drop-down menu. If you cannot find the value you require, select Custom to enable the bit timing parameter.

[BRP, SJW, TSEG1, TSEG2]

The principle is the same as for Nominal Baud Rate. The BRP of Nominal Baud Rate and Data Baud Rate must be identical for the same channel of the same I/O module as they share the same prescaler.

Tab: Scheduled Messages
Mode

Select whether the scheduled messages should be configured manully or by a configuration file.

Minor Time Frame Ticks

Specify the number of clock ticks for the Minor Time Frame Interval. The base clock of the I/O module is 80 MHz.

Schedule Messages

Schedule messages manually by clicking the Schedule Messages button. The table can be left empty so that no messages are scheduled.

Configuration File

Specify the path of the configuration file. Click the Browse button to easily find your file or enter it manually. By clicking the Refresh Data button, the whole configuration file is parsed again. The scheduled messages can be saved by clicking the Save Configuration button when using the manual configuration mode.

For more information about the configuration file, see: Scheduled Messages Configuration File.
