IO512 - HDLC/SDLC Write v4

IO512 - HDLC/SDLC Write v4 — Writes to the serial ports

Library

Simulink Real-Time - Speedgoat

Description

This block writes data to the I/O module FIFO. Use one block per enabled channel.

Ports

Inputs
Count

Amount of bytes to be transmitted.

Data

Data input signal.

Block Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel

This parameter specifies the channel to which the block writes the data.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
