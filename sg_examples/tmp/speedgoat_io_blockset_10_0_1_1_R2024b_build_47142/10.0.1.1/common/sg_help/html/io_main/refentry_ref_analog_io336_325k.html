Analog IO336-325k

Analog IO336-325k — 16 x 16-bit ADCs up to 1.5 MSPS sampling rate, 8 x 16-bit DACs up to 10 MSPS update rate

Introduction

The IO336-325k I/O module provides the following analog functionality:

  • 16 x 16-bit ADCs up to 1.5 MSPS sampling rate with simultaneous sampling

  • 8 x 16-bit DACs up to 10 MSPS update rate
