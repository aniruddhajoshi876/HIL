Modbus RTU Client

Modbus RTU Client — Simulink driver blocks for the native Modbus RTU Client interface

Introduction

Simulink driver blocks for Modbus RTU Client enable data to be exchanged with remote Modbus RTU Servers. Support for Modbus RTU Client is provided with plug-in serial I/O modules.
