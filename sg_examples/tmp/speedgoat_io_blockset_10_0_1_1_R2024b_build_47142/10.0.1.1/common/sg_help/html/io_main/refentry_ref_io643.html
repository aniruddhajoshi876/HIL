IO643 — Configurable CANopen Master I/O module

Introduction

The IO643 is a configurable CANopen Master I/O module. The solution is part of the IO64X/IO75X I/O module family which provides support for a wide range of industrial protocols. The IO643 module acts as one CANopen Master exclusively.
