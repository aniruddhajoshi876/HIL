Introduction

The Precision Time Protocol (PTP) is only supported on Ethernet interfaces based on the I210 controller. Refer to the Speedgoat Ethernet Interfaces documentation.

For additional information on PTP, please consult the MathWorks web documentation. For the local MathWorks help, enter the following code in the MATLAB® command window:

eval('helpview(fullfile(docroot,''slrealtime'', ''precision-time-protocol.html''))')

To obtain a list of all Ethernet interfaces available on your Speedgoat real-time target machine, refer to the Speedgoat API documentation.
