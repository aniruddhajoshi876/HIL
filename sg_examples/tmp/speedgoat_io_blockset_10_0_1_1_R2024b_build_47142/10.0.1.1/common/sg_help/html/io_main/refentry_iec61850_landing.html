IEC 61850 — Speedgoat driver blocks for IEC 61850

Introduction

IEC 61850 is an international standard defining Ethernet communication protocols for electrical substations based on a client-server or multicast architecture. The Speedgoat I/O Blockset supports three protocols: Manufacturing Message Specification (MMS), Generic Object Oriented Substation Event (GOOSE) and Sampled Values (SV). The MMS protocol uses TCP/IP for SCADA-to-IED (Intelligent Electronic Device) communication, to exchange surveillance values and general information about a substation, such as continuous data reports, or to send control commands to manually operate protection relays, for example. GOOSE is a fast and reliable protocol used mainly for IED-to-IED communication. The SV protocol is used to mostly transmit analog values in digital format, for example, AC analog currents and voltages. GOOSE and SV are published as a multicast Ethernet message. Speedgoat provides a native interface and a range of plug-in Ethernet modules for IEC 61850 communication, all of which come with Simulink driver blocks.
