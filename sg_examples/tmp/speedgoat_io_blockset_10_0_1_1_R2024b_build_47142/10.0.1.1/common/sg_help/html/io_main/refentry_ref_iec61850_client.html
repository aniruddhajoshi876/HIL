IEC 61850 Client

IEC 61850 Client — Simulink driver blocks for the native IEC 61850 Client interface

Introduction

Simulink driver blocks for the IEC 61850 Client enable data to be exchanged with multiple remote IEC 61850 Servers. Support for the IEC 61850 Client is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
