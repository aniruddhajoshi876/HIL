IO614 - LIN Slave Read v2

IO614 - LIN Slave Read v2 — Read messages from the LIN channel

Library

Simulink Real-Time - Speedgoat

Description

This driver block allows LIN messages to be read. The LIN message information (LIN version, ID, DLC) can be set in the block mask.

The buffer size is 20 messages per channel, so depending on the selected baud rate and the "LIN Slave Read" block sample times, it is important to not let the input buffer overflow.

For each LIN message a single read block is required.

Ports

Outputs
State

Message status:

  • 1: New message received

  • 0: No new message received

  • -1: Error ("Data" output holds the corresponding error code)

Data Type:int32

Msg Type

Message Type:

  • 0: Dataframe message

  • 2: Error message

  • 3: Wakeup message

If the message type is "Error message", the error code is written to the "Data" output.Data Type:uint32

Data Overrun

Buffer Overflow:

  • 0: No overflow

  • 1: Receive queue overflow (already one or more messages lost)

Data Type:uint32

Timestamp

The timestamp for receipt of the LIN message. The resolution is 1µs, so in order to get a double value in seconds, the block output must be converted to double and multiplied by 1e-6. This 1µs resolution is given by the hardware implementation of the IO61X modules. The time is reset to zero at each model start. Data Type:uint32

Data

The number of bytes is defined in the block mask with the parameter DLC. Data Type:uint8

If an error message has been received, Data[0] and Data[1] holds the error code. The following error codes are possible:

  • 0: no error

  • 1: bit error

  • 2: checksum error

  • 3: parity error

  • 4: no answer from slave

  • 5: Sync break error

  • 6: Inconsistent sync break field

  • 7: More data expected

  • 8: Timeout after start of sync break field

  • 9: Timeout after sync break field

  • 10: Timeout after sync field

  • 11: Slave didn't start

  • 12: LIN parameter error

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Receive message with channel

Choose the LIN channel to which this driver block should be connected.

Enable update state

Enables the output port for the message state.

Enable Message Type

Enables the output port for the message type.

Enable Data Overrun

Enables the output port for data overrun information.

Enable Timestamp

Enables the output port for the Timestamp.

Message Type

Currently only the message type RAW is supported.

LIN version

Select the LIN version:

  • LIN 1.X representing versions 1.1, 1.2 and 1.3 uses Classic Checksum.

  • LIN 2.X representing versions 2.0, 2.1 and 2.2 uses Enhanced Checksum except for IDs 60 and 61.

Identifier

Message ID of the LIN message without parity protection. Valid values are in the range 0 through 63.

Caution

LIN specifies the Protected ID (PID) to be a 8-bit value, where bits 7 and 8 contain parity sums over the other bits. The ID therefore consists of bits 1 through 6.

DLC

Identifies the length of the LIN message data array (Data Length Code). The value can be chosen in the range of 1 through 8.

Caution

LIN version 1.1 defines the DLC as a function of the ID (0-31: 2; 32-47: 4; 48-63: 8).
