IO17x - Setup

IO17x - Setup — Configure the IO17x Setup block

Library

Simulink Real-Time - Speedgoat

Description

Your model can contain only one Setup block for each I/O module in your target machine.

Ports

This driver block has no input or output ports.

Block Parameters

Main Tab
Module Type

Select the type of your I/O Module installed in your target machine. The IO171 offers 16 individually-configurable channels, the IO172 offers 6 individually-configurable channels.

Module ID

The Module ID has two functions:

  • It defines the logical connection between the Setup block and its I/O blocks

  • It also informs the auto-search feature of the PCI Slot parameter. If only one I/O module of this type is installed, the Module ID must be set to 1. If n modules are installed, it must be in the range 1:n. Not all the I/O modules installed in the target machine need to be used. To see how each I/O module maps to a Module ID, use this Speedgoat API: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat")
PCI Slot (-1: auto-search)

There are two approaches for mapping this block to a specific I/O module installed in your target machine. All modules of the same type must be configured using the same method.

  • Auto-Search: with the default value -1 the I/O module will be automatically located in the target machine. If you have multiple modules of the same kind, the Module ID defines which module is associated with this block. To see how each I/O module maps to a Module ID, use this Speedgoat API: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat")

  • Explicit Addressing: to explicitly define the logical address of the I/O module in the target machine, you can provide the PCI bus and slot numbers as a vector: [bus, slot]. To determine these numbers, run the following command in the MATLAB command window: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat", "Advanced", true)

    Note that the PCI address can change whenever an I/O module is added or removed – usually, auto-search is the best option.

Channel Tabs
Enable

Enable/Disable Channels.

Sensor Type

Selects which look-up table to load for the corresponding channel. Available options are: Thermocouple type B, Thermocouple type E, Thermocouple type J, Thermocouple type K, Thermocouple type N, Thermocouple type T, Thermocouple type S, Thermocouple type R, RTD PT100, RTD PT500, RTD PT1000, RTD NI100, RTD NI500, RTD NI1000, Custom. Use a custom table for strain gauges and for other sensors that are not predefined. Refer to the usage notes for additional information.

Is Thermocouple

When checked, this enables the Cold Junction Compensation drop down. This check box is only enabled when the Custom option is selected in the Sensor Type drop down.

Cold Junction Compensation

If the channel is configured as a thermocouple (either a factory or a custom thermocouple), this drop down will allow you to select the cold junction compensation sensor. Available options are: Analog channel X, External Sensor, On board Sensor. Refer to the usage notes for additional information.

Configuration File

This field is only enabled when the Custom option is selected in the Sensor type drop down. It will allow you to select the .hex configuration file generated with the TableBuilder app.

Open Table Builder App

This button is only visible when the Custom option is selected in the Sensor type drop down. It allows you to launch the IO17x Table Builder application, to load, edit, and save .hex configurations for custom sensors, and import lookup tables from .csv files.
