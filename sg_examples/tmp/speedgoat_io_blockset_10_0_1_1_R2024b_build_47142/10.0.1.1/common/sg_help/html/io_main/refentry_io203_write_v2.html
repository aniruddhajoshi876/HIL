IO203 - Write v2

IO203 - Write v2 — Writes the IO203 digital outputs

Library

Simulink Real-Time - Speedgoat

Description

The Write block is used to update the state of the output channels defined in the Setup block.

For each IO203 module, only one Write block is permitted.

Ports

This driver block has no output ports. The number of input ports is determined by the IO203 Setup block configuration and the Port Configuration setting of the IO203 Write block. The channel configurations are transmitted by the Setup block; the Write block does not automatically request these configurations. If the Setup block is configured before the Write block is added to the model, the Setup block must be re-initialized (by changing a setting and clicking Apply, or by updating the model) in order to update the new Write block.

The input ports can be configured in the following two ways:

1 port with a 64-element vector

One input port with a fixed width of 64 is used. The index of each array element is equivalent to the channel number. Array elements for channels which have not been configured as digital outputs have no effect. Each element should have a value of either 0 (Low) or 1 (High). Other values can also be used, in which case a threshold of 0.5 is used to determine if the output state is Low (< 0.5) or High (>= 0.5).

1 port for each active output channel

For each channel configured as digital output, one port is added to the IO203 Write block. Each port should have a value of either 0 (Low) or 1 (High). Other values can also be used, in which case a threshold of 0.5 is used to determine if the output state is Low (< 0.5) or High (>= 0.5).

Supported Data Types: boolean, double, single, int8/16/32, uint8/16/32

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Port Configuration

Select one of the two available port types.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Show Write Ports Indices

This part of the mask shows which channels are selected to be output. Modifying this field will not influence the configuration.
