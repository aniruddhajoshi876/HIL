PWM - Generation v3

PWM - Generation v3 — Pulse width modulation is a modulation technique used to encode a message into a pulsing signal

Library

Simulink Real-Time - Speedgoat

Description

The PWM (Pulse Width Modulation) code module provides the following functionality:

  • Symmetric, asymmetric, single-phase, and multi-phase PWM generation

  • Frequency-modulated pulse trains

To synchronize more than one PWM generation channel (e.g., for multi-phase (H-bridge) applications), the same driver block must be used to access all of the PWM channels. This is the only way to ensure that the PWM cycles run exactly in parallel (phase-locked).

Ports

Depending on which input ports are enabled in the dialog fields of the PWM generation driver block, this driver block has up to 6 input ports and contains no output ports. The possible input ports are:

Inputs
A

The A On compare value. This port is only active when the PWM pattern is symmetric (centered on half the period). A Off will be computed by the driver to ensure the symmetric PWM generation.

B

The B On compare value. This port is only active when the PWM pattern is symmetric (centered on half the period). B Off will be computed by the driver to ensure the symmetric PWM generation.

A On

The A On compare value. This port is only active when the PWM pattern is asymmetric.

A Off

The A Off compare value. This port is only active when the PWM pattern is asymmetric.

B On

The B On compare value. This port is only active when the PWM pattern is asymmetric.

B Off

The B Off compare value. This port is only active when the PWM pattern is asymmetric.

All input ports are of data type double. The widths of the input ports have to be equal to the number of PWM channels as defined in dialog field parameter "channel vector" of this driver block. Each element can be in the range from 1 to 2^32-1.

Note: It is the responsibility of the user of the block to make sure that the A-compare, B-compare, and Period-compare values are in proper relation to each other.

Parameters

Tab: Module setup
Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Channel Vector

A vector of channels this driver block entity will access. You can specify channels in the range 1-N (N = the number of channels implemented in your specific configuration file defined in the Setup block). The width of this vector also defines the subsequent size of some of the following parameters if scalar expansion applies. With a single block, all the channels of the block are synchronized.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Tab: PWM generation
PWM pattern

The type of PWM signal. There are two possibilities:

  • PWM is symmetric and centered on half the period

In this case only A On and B On are configurable. The driver will calculate A Off and B Off to keep the generation symmetric.

  • PWM is asymmetric

In this case A On and B On, and A Off and B Off are freely configurable.

PWM period vector

A vector of PWM period values in FPGA ticks. The width of this vector must be equal to the width of the Channel vector parameter.

Polarity of PWM A output

The PWM A output behavior between A On and A Off. By default: PWM A is high between A On and A Off, but PWM A can be configured to be low between A On and A Off. This parameter is useful when A and B must be complementary.

Polarity of PWM B output

The PWM B output behavior between B On and B Off. By default: PWM B is high between B On and B Off, but PWM B can be configured to be low between B On and B Off. This parameter is useful when A and B must be complementary.

Polarity of PWM Trigger output

Defines if a trigger is high (default) or low during trigger generation. This parameter may be required if external hardware such as analog inputs of the IO106 have a different (low) polarity.

Trigger source

Defines the condition when a trigger signal is emitted. Possible conditions are:

  • PWM A On

  • PWM A Off

  • PWM A On and PWM A Off

  • PWM B On

  • PWM B Off

  • PWM B On and PWM B Off

  • Period starts

  • Half the period

  • Period starts and half the period

Trigger pulse length vector

The duration of a trigger pulse. Possible values are between 1 and 255. The width of this vector must be equal to the width of the channel vector parameter.

AB-output protection

This protection is used to prevent A and B being active at the same time. Protection can be configured to be:

  • Disabled: A and B can be high at the same moment

  • A is forced off when B is on

  • B is forced off when A is on

  • Both A and B are disabled when A and B should be high at the same moment.

PWM update

By default, PWM parameters are updated with the given value each time a period starts. If required, PWM update can also be configured to update at the start of the period and/or at halfway through the period.

Tab: Offline state
PWM output A is

Defines the PWM A output parameter value loaded before the model starts or when it's stopped.

PWM output B is

Defines the PWM B output parameter value loaded before the model starts or when it's stopped.

Note

The FPGA clock frequency and the corresponding time of a tick can be found in the Setup block.
