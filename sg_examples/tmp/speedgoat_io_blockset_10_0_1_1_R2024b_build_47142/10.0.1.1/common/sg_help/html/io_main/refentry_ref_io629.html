IO629

IO629 — ARINC 629 I/O module with emulation of up to 240 Remote Terminals

Introduction

The IO629 I/O module can emulate up to 120 per module remote terminals (RT) per ARINC 629 module and is available in 2 or 4 ARINC 629 module options.

Supported C Compilers

This driver currently supports only Visual Studio 2012.
