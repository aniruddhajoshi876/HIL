Serial — Speedgoat serial I/O modules

Introduction

Speedgoat provide dedicated I/O modules and code modules running on configurable I/O modules to enable communication between a real-time target machine and devices using the following serial protocols:

  • RS232, RS422, RS485

  • SDLC and HDLC

  • I2C

  • SPI

I/O Modules

IO50X/IO581 The IO50X/IO581 I/O modules are serial modules supporting RS232/422/485 protocols
IO511 The IO511 I/O module is a serial module supporting the SDLC and HDLC protocols
IO512 The IO512 I/O module is a serial module supporting the SDLC and HDLC protocols

Code Modules

SPI SPI master, slave and sniffer code modules for configurable I/O modules
I2C I2C master and slave code modules for configurable I/O modules
Serial The Serial (UART) driver blocks enable serial communications on configurable I/O modules

Onboard

Serial Onboard The Serial Onboard are driver blocks for real-time target machines supporting RS232/422/485 protocols
