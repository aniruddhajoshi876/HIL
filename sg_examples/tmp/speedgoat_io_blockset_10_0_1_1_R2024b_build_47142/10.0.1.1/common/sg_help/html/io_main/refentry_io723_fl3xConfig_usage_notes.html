IO723 FL3X Config Usage Notes — Usage information about the I/O module

RBS Configuration Workflow

The following steps must be executed in the FL3X Config software:

  1. Create new Project

  2. Select Hardware (PCIe3) and FPGA image (0xE0: 2x CAN & 2x 100BaseT1 or 0xE4: 2x 100BaseT1 & 2x 1000BaseT1)

  3. Configure HwComLight Server

  4. Add database and link to port

  5. Select real and simulated ECUs

  6. Add frames to receive (Frame Receive User Function)

  7. Configure build options (project settings)

  8. Build project

Execute the following steps in your Simulink® model:

  1. Link the RBS project to the IO723 in the corresponding setup block

  2. Select and map the signals and services for reading and writing

Note

The documentation related to the FL3X config software can be found in the respective installation folder. The software can be downloaded here: FL3X Config
