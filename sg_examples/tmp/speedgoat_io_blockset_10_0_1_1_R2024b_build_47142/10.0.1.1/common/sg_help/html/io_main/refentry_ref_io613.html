IO613

IO613 — Intelligent CAN module with 2x CAN channels configurable as CAN FD or high-speed CAN

Introduction

The IO613 offers two CAN channels. Each channel can be configured individually to one of the following two operating modes:

  • CAN FD

  • High-speed CAN

The channels are located on two DB9 - connectors. For a description of the pinout, refer to the I/O pin mapping section.
