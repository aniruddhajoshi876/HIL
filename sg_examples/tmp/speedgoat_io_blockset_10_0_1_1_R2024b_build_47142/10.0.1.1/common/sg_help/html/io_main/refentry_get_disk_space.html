Get disk space

Get disk space

Library

Simulink Real-Time - Speedgoat/Utilities

Description

This block gets the current amount of disk space available to and used by the application in bytes and percentage.

Supported Target Machines

This block supports all Speedgoat real-time target machines.

Ports

Outputs
Free

The current amount of disk space available to the application in bytes [double]

Free (%)

The current amount of disk space available to the application in percentage [double]

Used

The current amount of disk space used by the application in bytes [double]

Used (%)

The current amount of disk space used by the application in percentage [double]

Parameters

Output Port selection

The Get disk space block provides up to 4 selectable output ports:

  • Free (bytes)

  • Free (%)

  • Used (bytes)

  • Used (%)

Sample time

Defines the base sample time at which this driver block gets its sample hit. This parameter can be set to a minimum sample time of 0.25s. The units are in seconds.
