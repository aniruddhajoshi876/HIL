IO105

IO105 — Fast 16-bit analog module with 64/32 multiplexed analog input channels

Introduction

IO105-64/32 variant

This simultaneous sampling I/O module implements 64 single-ended or 32 differential input channels. Each channel has a dedicated A/D converter resulting in very low sampling and conversion times.

IO105-32/16 variant

This simultaneous sampling I/O module implements 32 single-ended or 16 differential input channels. Each channel has a dedicated A/D converter resulting in very low sampling and conversion times.

Warning

This I/O module has an automatic calibration feature. During the calibration process various signals may be present at the output pins.
