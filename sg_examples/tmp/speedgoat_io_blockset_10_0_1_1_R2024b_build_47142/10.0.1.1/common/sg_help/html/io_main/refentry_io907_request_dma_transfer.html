IO907/IO908 - Request DMA Transfer

IO907/IO908 - Request DMA Transfer — Requests a DMA transfer

Library

Simulink Real-Time - Speedgoat

Description

Initiates a DMA read operation to transfer data from the shared memory to Simulink. An interrupt is triggered when the data transmisson has completed.

Ports

This driver block has no input or output ports

Parameters

Module Type

Select the type of your I/O Module installed in your target machine.

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
