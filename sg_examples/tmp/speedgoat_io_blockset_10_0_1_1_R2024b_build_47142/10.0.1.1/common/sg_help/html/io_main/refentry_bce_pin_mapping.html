BCE Pin Mapping

BCE Pin Mapping — Reference information about the I/O module connectors

Communication

PortDescription
ETH1EtherCAT in: connect to the target machine or the previous device of the chain
ETH2EtherCAT out: connect to the next device of the chain

Power Supply and Interlock

PinDescription
1Interlock: connect, e.g., to a rack door switch
2Interlock: connect, e.g., to a rack door switch
348 V+: connect to power supply unit
448 V-: connect to power supply unit
5Earth Terminal: must be connected to the protective earth (PE)

Battery Cell Connectors

PinDescription
1BAT+: Positive cell output voltage pin. Bidirectional current flow is supported to allow emulation of battery charging and discharging.
2BAT-: Negative cell output voltage pin. Bidirectional current flow is supported to allow emulation of battery charging and discharging.
3Sense+: Positive sensing input pin.
4Sense-: Negative sensing input pin.
