Configuration Files

Introduction

Speedgoat offers configuration files for all configurable I/O modules. The configuration files comprise a wide range of standard interfaces and protocols (also known as code modules).

There are two ways to obtain a configuration file:

  • A customized configuration file, individually created for your application. You select a configurable I/O module fitting your needs, and define the functionalities and the number of channels, as well as the pin-mapping.

  • The I/O configuration package (web help) is Speedgoat's off-the-shelf solution and is available for multiple I/O modules. The functionalities are pre-defined and fixed, but optimized for certain applications. The packages include a configuration file for rapid control prototyping (RCP), hardware-in-the-loop (HIL) testing and communication applications.

Functionalities

The following table lists the interfaces and protocols supported by Speedgoat configuration files.

A2B A2B
Analog Analog-to-digital (ADC) and digital-to-analog (DAC)
BiSS BiSS is a digital interface for sensors and actuators. BiSS is hardware compatible to the industrial standard SSI but offers additional features and options
Cam and Crank The cam and crank driver blocks provide simulation and decoding of camshaft and crankshaft signals.
CMU Emulation Emulation of real cell measurement units
Digital Digital lines representing a logical state
Dma Controller Measurement of timing with Optimize Data Transfer enabled
Dshot The Dshot driver blocks transmits and receives Dshot messages.
EnDat The EnDat interface is a digital, bidirectional interface for encoders. It is capable of transmitting position values from incremental and absolute encoders
I2C I2C master and slave code modules for configurable I/O modules
Interrupt The CoS (Change of State) interrupt driver block allows a change of state on an input of a configurable I/O module in order to trigger the Simulink model.
PWM Pulse Width Modulation is a modulation technique used to encode a message into a pulsing signal
Pulse Counter The pulse counter driver blocks counts the edges of an input signal.
Quadrature Quadrature encoding uses two phase-shifted signals to detect position and direction of rotation
Resolver The Resolver driver blocks are used to emulate and measure the functionality of a resolver.
SENT The SENT driver blocks provides transmission and reception of SENT SAE J2716 messages.
Serial The Serial (UART) driver blocks enable serial communications on configurable I/O modules
SPI SPI master, slave and sniffer code modules for configurable I/O modules
SSI Synchronous Serial Interface (SSI) is a widely used serial interface standard for industrial applications between a master and a slave
