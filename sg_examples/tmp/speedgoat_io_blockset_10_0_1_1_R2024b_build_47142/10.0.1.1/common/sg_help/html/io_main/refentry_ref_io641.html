IO641 — Configurable PROFIBUS DP Master I/O module

Introduction

The IO641 is a configurable PROFIBUS Master I/O module. The solution is part of the IO64X/IO75X I/O module family which provides support for a wide range of industrial protocols. The IO641 module acts as one PROFIBUS Master exclusively.
