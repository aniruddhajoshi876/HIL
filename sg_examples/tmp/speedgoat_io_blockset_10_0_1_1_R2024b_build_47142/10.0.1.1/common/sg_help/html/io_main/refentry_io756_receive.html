IO756 - Receive

IO756 - Receive — Receives cyclic data from the EtherNet/IP scanner

Library

Simulink Real-Time - Speedgoat

Description

This block is used to receive data from the EtherNet/IP scanner connected with the IO756 module.

Your model can contain only one Receive block for each I/O module in your target machine.

Ports

Outputs

In conjunction with the IO756 Setup v1 block, the Receive block outputs the data of the sole output assembly defined in the Setup block mask. In conjunction with the IO756 Setup v2 block, the output differs. If Simple Mode is selected for the Setup block's Configuration Mode parameter, the Receive block outputs the data of the sole output assembly. With Extended Mode, the block outputs the data of all output and configuration assemblies defined.

Simple Mode

One vector of data type UINT8, which holds the data of the sole output assembly. This assembly contains data that has been received from the EtherNet/IP scanner. Use Byte Unpacking blocks to extract specific data. The Number of Bytes parameter sets the length of this vector.

Extended Mode

The block shows one output port for each output and configuration assembly defined in the corresponding Setup block. Each port is a vector of data type UINT8, which holds the data of the specific assembly. This data has been received from the EtherNet/IP scanner.

Inputs

This block does not have any input ports.

Parameters

Depending on the version of the corresponding Setup block, some parameters might be invisible.

Module ID

This ID defines the link to the corresponding Setup block

Port Type

Always select 1 port with n element vector of type uint8

Number of Bytes

This parameter defines the length of the output port and thus the number of bytes to be read from the output assembly.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.

Retrieve Configuration

Retrieves the assembly configuration from the related Setup block and updates the output ports.
