IO619 Usage Notes — Usage information about the I/O module

General

To use the I/O module as a bus administrator, a configuration file containing the timing information of each port is required. A second configuration file can be used to automatically configure the Process Data block depending on the selected device.

The file types supported are: .csv and .xls. The configuration file must contain a header row, followed by the data values. Refer to the files below to see how the headers must look and which data is required.

Bus Administrator Configuration File

To properly configure an I/O module as a bus administrator, a configuration file with the following data is required:

PortNamePortAddressPortSizePortCycleTimeSlot
Port_10x0018320
Port_20x01016640
Port_30x10032128100

PortAddress must be a hexadecimal value. PortSize must be specified in bytes and must not exceed 32. PortCycleTime must be a multiple of 1 ms, and must not exceed 1024 ms. Slot can be a value between 0 and 1023.

For each device, at least one port and one variable must be specified. To make the configuration file more readable, cells used only to fill gaps can be left empty. A new device/port is detected as soon as the value of DeviceName/PortName changes or is no longer empty.

The DeviceAddress and PortAddress must be hexadecimal values. PortDirection can either be "Source" or "Sink". PortCycleTime must be a multiple of 1 ms, and must not exceed 1024 ms. PortSize must be specified in bytes and must not exceed 32. VariableOffset and VariableSize must be values in bits.
