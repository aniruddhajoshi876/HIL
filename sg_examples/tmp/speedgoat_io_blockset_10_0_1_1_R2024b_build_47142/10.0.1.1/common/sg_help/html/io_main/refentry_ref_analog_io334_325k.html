Analog IO334-325k

Analog IO334-325k — 16 x 16-bit ADCs up to 5 MSPS sampling rate, 16 x 16-bit DACs up to 10 MSPS update rate

Introduction

The IO334-325k I/O module provides the following analog functionality:

  • 16 x 16-bit ADCs up to 5 MSPS sampling rate with simultaneous sampling

  • 16 x 16-bit DACs up to 10 MSPS update rate
