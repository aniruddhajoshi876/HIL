IO101 - Digital input

IO101 - Digital input — Reads the IO101 digital inputs

Library

Simulink Real-Time - Speedgoat

Description

To read the digital inputs exactly one of these blocks must be added to your model for each module of this type in your target machine.

Ports

This driver block has n scalar output ports of type double where n is the number of selected digital input channels. Each port (signal) returns the read digital value.

Outputs
X (X is the digital input channel number)

The value from digital input channel X. Type double. Possible values:

  • 0 - TTL low

  • 1 - TTL high

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel group

Select whether to access the lower channels (digital lines 1-8) or the upper channels (digital lines 9-16).

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
