MSCP Write

MSCP Write — Configure the MSCP Write block

Library

Simulink® Real-Time™ - Speedgoat

Description

The MSCP Write block allows the user to write data to an MSCP. One MSCP Write block handles the data of one MSCP device and only works in combination with an MSCP Setup block.

Ports

This driver block has one input port.

Inputs
Data

The data port takes a Simulink® bus signal, the structure of which depends on the selected device's slot/module configuration. The Simulink bus object and a template structure for initialization are created in the MATLAB® workspace after the block has been configured. It is recommended to use a Bus Assignment block to set the values of individual signals contained in the bus signal.

Parameters

Sample Time

The Sample Time is displayed here; however, it must be configured in the corresponding MSCP Setup block, this is because the sample time for the EtherCAT communication is set globally.

Network Index

The Network Index is a user-defined ID to associate the MSCP Write block with the corresponding MSCP Setup block. The value must be an integer between 0 and 11. When changing the network index, click the Reload Device List button to load the list of devices from the MSCP Setup block.

Device

Selects the Device to which the MSCP Write block will send data.
