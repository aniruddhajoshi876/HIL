IO191 - Analog input

IO191 - Analog input — Reads the IO191 analog inputs

Library

Simulink Real-Time - Speedgoat

Description

Your model can only contain one of these blocks for each I/O module in your target machine.

Ports

This driver block has n double-type scalar output ports, where n is the number of selected analog input channels. Each port (signal) returns the analog value in volts.

If DMA is disabled, then the port width is 1. If DMA is enabled, then the width of the output port is equal to the frame size and each element of this vector contains one sample, where the value at position 1 was taken first.

Outputs
X (X is the analog channel number)

The value from analog channel X in volts.

Data Type: double

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Note For DMA operation, the Sample Time is the time between frame completions. The value depends on the Frame Size, the number of Active Channels, and the ADC Rate. In the Setup block, Analog Inputs tab, when Enable DMA is selected, Sample Time displays its value.
