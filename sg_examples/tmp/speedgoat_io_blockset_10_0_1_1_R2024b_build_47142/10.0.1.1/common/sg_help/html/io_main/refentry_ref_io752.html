IO752 — Configurable PROFINET Device I/O module

Introduction

The IO752 and the IO752-32 are configurable PROFINET Device I/O modules. They belong to the IO64X/IO75X I/O module family, which provides support for a wide range of industrial protocols. The IO752 module acts as one PROFINET Device exclusively, whereas the IO752-32 simulates up to 32 PROFINET Device nodes. The IO752 driver blocks can be used with the IO752 module as well as with the IO752-32 module.
