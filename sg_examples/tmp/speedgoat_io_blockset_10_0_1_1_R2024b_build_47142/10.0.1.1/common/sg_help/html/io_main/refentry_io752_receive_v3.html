IO752 - Receive v3

IO752 - Receive v3 — Outputs the cyclic data received from the remote PROFINET controller.

Library

Simulink Real-Time - Speedgoat

Description

This block outputs the cyclic data the I/O module receives from the remote PROFINET controller. For acyclic communication, use Record blocks.

Your model can contain only one Receive block for each I/O module in your target machine.

Ports

Outputs

The block outputs the output data items of the sub-modules defined in the Data Module Configuration parameter of the corresponding Setup block. The number, types and dimensions of the output ports depend on the mask parameters. The block has either:

  • one port for each data item

  • one port for each sub-module

  • one port for each module, or

  • one port in total that outputs the entire output data of the device

Inputs

This block does not have any input ports.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.

Output Level

Defines the granularity of the data output. There are 4 options:

  • Data Item: Each port represents one data item and inherits its type and length from the Data Module Configuration parameter of the corresponding Setup block

  • Sub-Module: Each port represents one sub-module. The data items of the sub-module are packed in a vector of data type uint8

  • Module: Each port represents one module. The data items of the module's sub-modules are packed in a vector of data type uint8

  • Device: One port outputs the entire output data of the device as a vector of data type uint8

Use Byte Unpacking blocks to extract data items from byte vectors.

Group Data Items as Vector

Places the data items of a sub-module into a vector. This reduces the number of ports and therefore improves usability. All data items must be scalar and must have the same type. If the sub-module has at least one data item of another data type, the parameter has no impact and the block creates a port for every single data item.

Port Label Elements

Shows or hides specific elements of the output port label. The elements available include the module name, the sub-module name and the name of the data item. The resulting port label also depends on the Output Level parameter as you cannot show the sub-module name if the output level is module, for example.
