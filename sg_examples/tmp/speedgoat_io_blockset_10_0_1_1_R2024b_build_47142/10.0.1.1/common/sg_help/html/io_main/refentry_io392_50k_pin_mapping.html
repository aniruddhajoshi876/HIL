Note

0 V is internally connected to the ground of the target machine. 5 V are supplied by the real-time target machine, which is capable of providing 1 A continuous current. For more information, refer to the real-time target machine User Manual.

The digital ground pins are also connected to the ground of the target machine through the I/O module. If an external sensor is supplied by the 5 V of the target, the ground of the sensor must be connected to the 0 V pin and not the I/O ground. This must be done to minimize current flow through the I/O module and protect the I/O module in case of a short circuit.
