Cam and Crank - Crank Decoder Event v1

Cam and Crank - Crank Decoder Event v1 — The crank decoder event generates a pulse signal depending on the crank decoder signal.

Library

Simulink® Real-Time™ - Speedgoat

Description

The crank decoder event generates a pulse signal depending on the crank decoder signal.

Ports

This driver block has no ports:

Parameters

Tab: Module setup
Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Channel Vector

A vector of channels this driver block entity will access. You can specify channels in the range 1-N (N = the number of channels implemented in your specific configuration file defined in the Setup block). The width of this vector also defines the subsequent size of some of the following parameters if scalar expansion applies. With a single block, all the channels of the block are synchronized.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Tab: Crank Decoder Event
Event pulse position vector (deg)

This parameter specifies the event pulse position between 0° and 720°. The units are in degrees (°). This angle has to coincide with a crank tooth start angle. e.g., for a crank profile with 18 teeth and 2 missing teeth, possible event pulse position angles are multiples of 360/18 = 20 degrees.

Event pulse duration vector (s)

This parameter defines the duration of the event pulse duration in seconds.

Crank master vector (read only)

The corresponding crank decoder master. This parameter is read-only, and therefor only for information purpose. The crank decoder master is predefined during the pin layout.

Number of teeth vector (read only)

This parameter defines the number of teeth defined in the crank decoder master. This parameter is read-only, and therefor only for information purpose. The number of teeth vector is defined in the crank decoder mask.

Number of missing tooth/teeth vector (read only)

This parameter defines the number of missing tooth/teeth defined in the crank decoder master. This parameter is read-only, and therefor only for information purpose. The number of missing tooth/teeth vector is defined in the crank decoder mask.

Note

Values expressed in seconds will be rounded to the FPGA resolution. For instance, if FPGA base clock is equal to 75[MHz], then the resolution is 13.33[ns].
