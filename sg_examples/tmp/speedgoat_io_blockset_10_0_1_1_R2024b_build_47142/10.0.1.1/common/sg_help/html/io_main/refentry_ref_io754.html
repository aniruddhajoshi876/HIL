IO754 — Modbus TCP Server I/O module

Introduction

The IO754 and the IO754-32 are configurable Modbus TCP Server I/O modules. They belong to the IO64X/IO75X I/O module family, which provides support for a wide range of industrial protocols. The IO754 module acts as one Modbus TCP Server exclusively, whereas the IO754-32 simulates up to 32 Modbus TCP Server nodes. The IO754 driver blocks can be used with the IO754 module as well as with the IO754-32 module.
