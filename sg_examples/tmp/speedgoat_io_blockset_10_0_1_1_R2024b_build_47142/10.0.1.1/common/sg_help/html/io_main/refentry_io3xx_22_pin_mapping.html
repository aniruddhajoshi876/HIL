-22 Pin Mapping — Reference information about the I/O module connector

Description

The -22 I/O interface extension converts the rear I/O lines from LVCMOS to RS422, RS485 and 3.3 V/5 V TTL and makes them accessible from the front of the enclosure. The -22 extension provides 16 differential I/O lines with RS422/485-compatible transceivers and 24 TTL I/O lines. The TTL I/O lines are distributed in 3 groups of 8 lines. All 8 lines of a group must have the same direction and pull resistor configuration. The pull resistors of the 3 I/O port groups can be configured using the mask of the Setup block.
