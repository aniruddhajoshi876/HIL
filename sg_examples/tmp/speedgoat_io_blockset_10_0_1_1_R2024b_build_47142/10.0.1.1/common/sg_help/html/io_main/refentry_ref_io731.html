IO731 — Time Sensitive Networking I/O Module

Introduction

Supported Ethernet Protocols:

  • Real-time UDP

  • TCP/IP

  • gPTP (IEEE 802.1AS)

  • Raw Ethernet (MATLAB R2022a and later)

Drivers for the Ethernet controllers are provided and maintained by MathWorks. They are available in the Simulink Real-Time driver library, and can also be accessed via the Speedgoat I/O Blockset by running the following command in the MATLAB command window: 

speedgoatlib

The supported TSN standards are:

IEEE 802.1ASTiming and Synchronization
IEEE 802.1QbvEnhancements for Scheduled Traffic
IEEE 802.1Qav Forwarding and Queuing Enhancements for Time-Sensitive Streams
IEEE 802.1QccEnhancements for Stream Reservation Protocol
IEEE 802.1QciPer-Stream Filtering and Policing
IEEE 802.1CBFrame Replication and Elimination for Reliability
