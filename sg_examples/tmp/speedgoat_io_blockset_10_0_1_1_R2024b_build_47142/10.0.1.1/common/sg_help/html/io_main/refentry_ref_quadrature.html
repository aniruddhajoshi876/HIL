Quadrature

Quadrature — Quadrature encoding uses two phase-shifted signals to detect position and direction of rotation

Introduction

Speedgoat provides two Quadrature code modules for the IO3xx configurable I/O module:

  • QAD - Quadrature decoding

  • QAE - Quadrature encoding
