Introduction

The Universal Measurement and Calibration Protocol (XCP) is supported on all Ethernet interfaces. Refer to the Speedgoat Ethernet Interfaces documentation.

For additional information on XCP, please consult the MathWorks web documentation. For the local MathWorks help, enter the following code in the MATLAB® command window:

eval('helpview(fullfile(docroot,''slrealtime'', ''xcp.html''))')
