CMU - ADBMS6832_33 v1

CMU - ADBMS6832_33 v1 — The driver block provides the simulation functionality for an ADBMS6832_33 CMU emulation

Library

Simulink Real-Time - Speedgoat

Description

The ADBMS6832_33 driver block provides functionality for emulation of Battery Cell Measurement Unit (CMU) chips from Analog Devices, namely ADBMS6832 and ADBMS6833. The block provides the cell-, GPIO-, and other voltages to the emulation unit. The block can also read the present configuration contents of the emulation unit. The ADBMS6832_33 CMU can be daisy chained, in which the block has access to all individual ADBMS6832_33 devices in such a daisy chain. The maximum amount of ADBMS6832_33 emulation devices is 64 and is given by the configuration file of the used I/O Board. It is possible that a configuration file contains multiple daisy chains of ADBMS6832_33 devices. Each daisy chain contains the same number of ADBMS6832_33 devices.

Ports

One block can control multiple ADBMS6832_33 CMU devices only if they are connected in a daisy chain. Each individual chain requires a separate driver block. The width of all the inputs and outputs depends on the number of values per single CMU and the length of the chain.

For example, there are 18 cell-voltages for each ADBMS6832_33 CMU. If a chain with 4 of those devices is controlled by the block, then the input for the cell voltages becomes 2-dimensional (dimension1: cell voltage 1 to 18, dimension2: CMU device 1 to 4 within the chain). The Chain Selection parameter selects the chain, the parameter Available Chain Length indicates the length of the daisy chain.

Inputs
Cell Voltages [V]

This port sets the cell voltage of each of the 18 cells on each of the ADBMS6832_33 CMU device contained in the daisy chain. This input therefore is 2 dimensional (dimension1: cell voltage 1 to 18 on each CMU, dimension2: each CMU device within the chain).

S Voltages [V]

This port is only visible if the parameter Dynamic S Voltages in the tab Voltages Configuration is set. This port sets the S-voltage of each of the 18 cells on each of the ADBMS6832_33 CMU devices contained in the daisy chain. This input therefore is 2 dimensional (dimension1: S-voltage 1 to 18 on each CMU, dimension2: each CMU device within the chain).

GPIO Voltages [V]

This port is only visible if the parameter Dynamic GPIO Voltages in the tab Voltages Configuration is set. This port sets the GPIO voltage of each of the 12 GPIO on each of the ADBMS6832_33 CMU devices contained in the daisy chain. This input therefore is 2 dimensional (dimension1: GPIO voltage 1 to 12 on each CMU, dimension2: each CMU device within the chain).

System Voltages [V] (VRFE2, VD, VA, VRES, VMV)

This port is only visible if the parameter Dynamic System Voltages in the tab Voltages Configuration is set. This port sets the system voltages (VREF2, VD, VA, VRES, VMV) on each of the ADBMS6832_33 CMU devices contained in the daisy chain. This input therefore is 2 dimensional (dimension1: system voltage 1 to 5 on each CMU, dimension2: each CMU device within the chain).

Sum of Cell Voltages [V]

This port is only visible if the parameter Dynamic Sum of Cells in the tab Voltages Configuration is set. This port sets the sum of all cell voltages on each of the ADBMS6832_33 CMU devices contained in the daisy chain. This input therefore is 1 dimensional (dimension1: sum of all cell voltages for each CMU device within the chain).

Temperature [°C]

This port is only visible if the parameter Dynamic Temperature in the tab Voltages Configuration is set. This port sets the temperature on each of the ADBMS6832_33 CMU devices contained in the daisy chain. This input therefore is 1 dimensional (dimension1: temperature for each CMU device within the chain).

Outputs
Parameter Read

The ADBMS6832_33 contains several parameters that are stored in registers. The registers are organized in 8-bit values. In the tab Parameter (read) Configuration dedicated registers are selectable to activate them as outputs. A separate output port for each of the selected parameter will be added to the driver block. Any selected parameter always contains two 8-bit value registers that are concatenated to a 16-bit unsigned integer value. Each of these outputs is 1 dimensional (dimension1: parameter for each CMU device within the chain).

Diagnostics

In the tab Diagnostics, several diagnostics are selectable. Separate output ports for each of the selected diagnostics will be added to the driver block. Each of these outputs are 1 dimensional (dimension1: parameter for each CMU device within the chain).

  • Last Received Command: Adds 2 ports: The last received command on the CMU / the corresponding CRC value.

  • Command Counters: Adds 2 ports: The number of received commands / the number of commands containing a CRC error.

  • ADC status of redundant AUX: Adds 4 ports: The present states of the ADC on the ADBMS6832_33 measuring the redundant AUX channels.

  • ADC status of AUX: Adds 4 ports: The present states of the ADC on the ADBMS6832_33 measuring the AUX channels.

  • ADC status of S Voltage: Adds 4 ports: The present states of the ADC on the ADBMS6832_33 measuring the S-Voltages.

  • ADC status of Cell Voltage: Adds 4 ports: The present states of the ADC on the ADBMS6832_33 measuring the Cell-Voltages.

  • Core State: Adds 2 ports: Indicates whether the ADBMS6832_33 CMU power core is currently in sleep / standby / another state.

  • Communication State: Adds 2 ports: Indicates whether the ADBMS6832_33 CMU communication core (ISOspi State) is currently in idle / ready state.

Parameters

Tab: Module Setup
Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Chain Selection

To select the ADBMS6832_33 CMU chain of this driver block. This driver block can only be assigned to one chain. If your configuration file contains several chains of ADBMS6832_33 CMUs, several driver block instantiations are necessary.

Available Chain Length

This parameter indicates the length of the chain; that is, how many ADBMS6832_33 CMUs are included in the selected chain. This parameter is read only.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Tab: Voltages Configuration
Dynamic S Voltages

When set, the input port S Voltages [V] is added to the block and the S-Voltages can be set dynamically during runtime.

When not set, the block does not contain an input port for the S-Voltages. In this case, the S-Voltages are the same as the Cell-Voltages on the input port Cell Voltages [V].

Same as Cell Voltages

This parameter is read only and indicates that the S Voltages are the same as the Cell Voltages if Dynamic S Voltages is off; when Dynamic S Voltages is set, this indication Same as Cell Voltages disappears.

Dynamic GPIO Voltages

When set, the input port GPIO Voltages [V] is added to the block and the GPIO Voltages can be set dynamically during runtime.

When not set, the GPIO voltages can be set with the parameter GPIO Voltages (GPIO1 to GPIO12) Vector. In this case, the GPIO Voltages will be static during runtime.

GPIO Voltages (GPIO1 to GPIO12) Vector

This parameter is only visible when Dynamic GPIO Voltages is not set.

The parameter is 2 dimensional (dimension1: GPIO voltage 1 to 12 on each CMU, dimension2: each CMU device within the chain). If a parameter with only 1 column is defined, the set GPIO voltages will be the same on all CMUs. If a parameter with only 1 row is defined, all GPIO voltages will be the same on each CMU. The missing values will be set to 0 if this parameter is set to a 2 dimensional value but either the number of rows is smaller than the available 12 GPIO voltages or the number of columns is smaller than the number of available CMUs in the chain.

Dynamic System Voltages

When set, the input port System Voltages [V] (VRFE2, VD, VA, VRES, VMV) is added to the block and the system voltages can be set dynamically during runtime.

When not set, the system voltages can be set with the parameter System Voltages (VRFE2, VD, VA, VRES, VMV) Vector. In this case, the system voltages will be static during runtime.

System Voltages (VRFE2, VD, VA, VRES, VMV) Vector

This parameter is only visible when Dynamic System Voltages is not set.

The parameter is 2 dimensional (dimension1: system voltage 1 to 5 on each CMU, dimension2: each CMU device within the chain). If a parameter with only 1 column is defined, the set system voltages will be the same on all CMUs. If a parameter with only 1 row is defined, all system voltages will be the same on each CMU. If this parameter is set to a 2-dimensional value and either the number of rows is smaller than the 5 available system voltages or the number of columns is smaller than the number of available CMUs in the chain, then the missing values will be set to 0.

Dynamic Sum Of Cells

When set, the input port Sum of Cell Voltages [V] is added to the block and can be set dynamically during runtime.

When not set, the block does not contain an input port for the Sum of Cell Voltages. In this case, the Sum of Cell Voltages are calculated from the driver using the input port Cell Voltages [V].

Calculated

This parameter is read only and indicates that the Sum of Cell Voltages is calculated if Dynamic S Voltages is off. When Dynamic Sum of Cells is set, this indication Calculated disappears.

Dynamic Temperature

When set, the input port Temperature [°C] is added to the block and can be set dynamically during runtime.

When not set, the block does not contain an input port for the Temperature. In this case, the Sum of Cell Voltages are calculated from the driver using the input port Cell Voltages [V].

Temperature Vector

This parameter is only visible when Dynamic Temperature is not set.

The parameter can be either scalar or a 1-dimensional vector. When scalar, the value is used for all CMUs in the chain; when vector, each element defines the temperature for each individual CMU in the chain.

Tab: Parameter (write) Configuration
Configure Serial ID

When this parameter is set, the 48-bit serial ID of the ADBMS6832_33 can be set; when not set, the serial ID is configured to 0.

Serial ID Vector

This parameter is only visible when Configure Serial ID is set.

When scalar, the value is used for all CMUs in the chain; when vector, each element defines the serial ID for each individual CMU in the chain.

Configure Revision

When this parameter is set, the 4-bit Revision of the ADBMS6832_33 can be set; when not set, the Revision is configured to 0.

Revision Vector

This parameter is only visible when Configure Revision is set.

When scalar, the value is used for all CMUs in the chain; when vector, each element defines the Revision for each individual CMU in the chain.

Filter Width [FPGA Ticks]

The first and the last CMU of the ADBMS8632_33 daisy chain can be accessed by an SPI Slave interface. All SPI input signals (CS, SCK, MOSI) pass a glitch filter. Signal glitches (positive and negative) with a smaller number of FPGA ticks than defined by the Filter Width [FPGA Ticks] parameter do not pass. This parameter is scalar and therefore applied equal on both SPI Slave interfaces.

Note

Set the glitch filter width as low as possible since this parameter also increases the latency of the MISO signal in relation to the SCK signal on the SPI slave.

Especially in the case where an SPI <-> ISOspi physical converter will be added to the SPI interface (in hardware), the latency between the SCK and the MISO signal should be as low as possible.

Effective Filter Width [s]

This parameter is read only and indicates the effective time width of the filter.

Tab: Parameter (read) Configuration
Note

The ADBMS6832_33 CMU consists of several register groups, each group contains six 8-bit registers. See the ADBMS6832_33 datasheet for details.

The ADBMS6832_33 allows reading the content of those registers. In most cases, two 8-bit registers are concatenated to a 16-bit value, with the lower 8-bit representing the register with the lower number.

Each selection of a register will add a corresponding output signal port on the driver. These outputs will be vectors, with each element representing the registers of the corresponding CMU in the chain.

Configuration Register Group A

Each of the Configuration Register GroupA can be made available as an output port on the driver by enabling the corresponding Register 5 and 4, Register 3 and 2 and/or Register 1 and 0.

Configuration Register Group B

Each of the Configuration Register GroupB can be made available as an output port on the driver by enabling the corresponding Register 5 and 4, Register 3 and 2 and/or Register 1 and 0.

COMM Register Group

Each of the Communication Register Group can be made available as an output port on the driver by enabling the corresponding Register 5 and 4, Register 3 and 2 and/or Register 1 and 0.

PWM Register A

Each of the PWM Register GroupA can be made available as an output port on the driver by enabling the corresponding Register 5 and 4, Register 3 and 2 and/or Register 1 and 0.

PWM Register B

Each of the PWM Register GroupB can be made available as an output port on the driver by enabling the corresponding Register 5 and 4, Register 3 and 2 and/or Register 1 and 0.

Status Register Group B

The ADBMS6832_33 CMU unit evaluates the digital GPI inputs related on the GPIO values. They can be made available as an output port of the driver by enabling GPI.

Tab: Diagnostics
Last Received Command

When this parameter is set, the output signal ports Last Received Command and Last Received Command CRC will be added to the driver block. These will be vector signals, with each element indicating the last received command and its corresponding CRC checksum for each CMU in the chain.

Command Counters

When this parameter is set, the output signal ports Command Counter and Command CRC Error Counter will be added to the driver block. These will be vector signals, with each element indicating the number of received commands and the number of received commands that contained a CRC Checksum error for each CMU in the chain.

ADC status of redundant AUX

When this parameter is set, the output signal ports ADC Redundant AUX active, ADC Redundant AUX soak, ADC Redundant AUX refon and ADC Redundant AUX idle will be added to the driver block. These will be vector signals, with each element indicating the present state of the redundant Auxiliary ADC for each CMU in the chain.

ADC status of AUX

When this parameter is set, the output signal ports ADC AUX active, ADC AUX soak, ADC AUX refon and ADC AUX idle will be added to the driver block. These will be vector signals, with each element indicating the present state of the Auxiliary ADC for each CMU in the chain.

ADC Status of S Voltage

When this parameter is set, the output signal ports ADC S active, ADC S wait for ADC Cell, ADC S refon and ADC S idle will be added to the driver block. These will be vector signals, with each element indicating the present state of the S ADC for each CMU in the chain.

ADC Status of Cell Voltage

When this parameter is set, the output signal ports ADC Cell active, ADC Cell refon and ADC S idle will be added to the driver block. These will be vector signals, with each element indicating the present state of the Cell ADC for each CMU in the chain.

Core State

When this parameter is set, the output signal ports Core State Sleep and Core State Standby will be added to the driver block. These will be vector signals, with each element indicating the present ADBMS6832_33 core state for each CMU in the chain.

Communication State

When this parameter is set, the output signal ports Comm State Ready and Comm State Standby will be added to the driver block. These will be vector signals, with each element indicating the present ADBMS6832_33 communication state for each CMU in the chain.
