Analog IO334-325k - Analog Output v1

Analog IO334-325k - Analog Output v1 — This driver block is available for the IO334-325k.

Library

Simulink Real-Time - Speedgoat

Description

Your model can only contain one such driver block per IO334-325k installed in your target machine.

Ports

This driver block has n scalar input ports of type double where n is the number of selected analog output channels. Each port (signal) accepts the analog value in volts to be output.

Inputs
X (X is the analog channel number)

The value to be output from analog channel X in volts. Type double.

Parameters

The configuration details are all defined in the IO334-325k Analog Setup v1 block.

Configurable I/O Module ID

This parameter associates a code module block with a configurable I/O module setup block. Set this value to match the Module ID defined in the setup block of the required configurable I/O module.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
