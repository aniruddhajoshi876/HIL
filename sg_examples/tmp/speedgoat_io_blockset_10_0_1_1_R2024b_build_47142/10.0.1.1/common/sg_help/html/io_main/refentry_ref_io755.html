IO755 — Configurable EtherNet/IP Scanner I/O module

Introduction

The IO755 is a configurable EtherNet/IP Scanner I/O module. The solution is part of the IO64X/IO75X I/O module family which provides support for a wide range of industrial protocols. The IO755 module acts as one EtherNet/IP Scanner exclusively.
