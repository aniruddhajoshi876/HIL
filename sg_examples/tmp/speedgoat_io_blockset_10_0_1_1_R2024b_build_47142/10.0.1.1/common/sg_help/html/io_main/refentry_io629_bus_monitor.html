IO629 - Bus Monitor

IO629 - Bus Monitor — Monitors the bus data traffic

Library

Simulink Real-Time - Speedgoat

Description

The Bus Monitor Simulink driver block allows the reception of the traffic on the ARINC 629 databus. A single Bus Monitor Block can be instantiated per ARINC 629 submodule.

An example for the configuration of the Bus Monitor Driver Block can be found here: IO629 Usage Notes

Ports

Inputs
Timestamp

Array of datarecords timestamp. Type double.

Size

Array of datawords size. Type double.

Data

Matrix containing the datawords received. Type uint16.

Data size and ordering is further explained here: IO629 Usage Notes

Parameters

Submodule ID

This parameter holds the reference to the Submodule block.

Mode

This parameter holds the acquisition mode. In the current driver version it is fixed to string mode (a time tag for every data string).

Block Sample Time

This parameter defines the base sample time at which this driver block gets its sample hit. It can also be set to -1 for inherited sample time. The units are in seconds.

Num of wordstrings to read

This parameter is used to define the width of the output port arrays.

Max wordstring size

This parameter is used to define the 2nd dimension of the Data output port matrix.
