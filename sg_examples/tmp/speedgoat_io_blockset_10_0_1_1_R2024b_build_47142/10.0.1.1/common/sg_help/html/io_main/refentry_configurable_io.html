Configurable I/O

Introduction

Pulse I/O (see Note) and configurable I/O modules are suitable for high-frequency I/O connectivity and industrial protocols, but with closed-loop sample rates below 20 kHz.

Speedgoat offers configuration files for all configurable I/O. The configuration files comprise a wide range of standard interfaces and protocols (also known as code modules).

Getting Started

If you are new to configuration files or configurable I/O modules, refer to the Getting Started section.

I/O Interface Extensions

For most configurable I/O modules, the number of I/O available can be extended by using one or two I/O interface extensions. Users can choose from various I/O interface extensions that support different I/O standards, as well as analog and other functionalities.

ModuleDescription
-21Converts the rear I/O lines from LVCMOS to 3.3 V/5 V TTL and makes them accessible from the front of the enclosure
-22Converts the rear I/O lines from LVCMOS to RS422, RS485 and 3.3 V/5 V TTL and makes them accessible from the front of the enclosure
-24Makes use of the LVCMOS rear I/O lines to interface with two resolver-to-digital converters. Converts some of the rear I/O lines from LVCMOS to RS422, RS485 and 3.3 V/5 V TTL and makes them accessible from the front of the enclosure
-120Provides the following analog functionality: 16 x 16-bit, 1.5 Gbps analog inputs, 16 x 16-bit analog outputs with <1 μs settling time
