Serial Onboard - Setup

Serial Onboard - Setup — Setup of parameters for serial onboard ports

Library

Simulink Real-Time - Speedgoat

Description

This block is part of the Serial driver blockset for real-time target machines supporting the RS232, RS422 and RS485 protocols. Each model for a target machine must contain exactly one Setup block.

The Setup block dialog box allows you to specify and configure all available onboard ports of a supported real-time target machine. This block therefore has an impact on the other driver blocks (Serial Onboard Write and Serial Onboard Read). The number of available ports may vary depending on the generation of the real-time target machine. As a result, the ports shown in the Setup block may not reflect the actual hardware configuration.

Ports

This driver block has no input or output ports.

Block Parameters

Main Tab
Machine Type

Select the type of your real-time target machine.

Port Setup

Configuration of the transceiver for each port. This parameter defines the physical layer of the serial protocol.

Each real-time target machine has a specific configuration. Refer to the Serial Onboard introduction page for more information.

The options are:

  • RS232

  • RS485 Half-Duplex

  • RS422/RS485 Full-Duplex

Port Setup Tab
Enable Custom Baud Rate

Switches the baud rate selection from a dropdown menu to a text field, where any baud rate in the declared range can be chosen. An onboard serial runtime license is required to use this feature.

Note

This parameter is only available when Pulse is chosen as the Machine Type.

Custom Baud Rate

Select a baud rate from the declared range. An onboard serial runtime license is required to use this feature.

Note

This parameter is only available when Pulse is chosen as the Machine Type.

Also, the actual baud rate will always be within 1 % of the selected baud rate.

Baud Rate

Select the baud rate from a list of standard baud rates. The declared range varies between target machines.

Parity

Parity is a method for detecting errors during transmission. Options are:

  • None

  • Even

  • Odd

  • Mark

  • Space

Data Bits

The number of data bits for each character. Options are: 5, 6, 7 or 8.

Stop Bits

The number of stop bits sent at the end of every character. Options are: 1 or 2.

Transmit Software FIFO Size

The size of the software FIFO used to buffer transmitted characters.

Receive Software FIFO Size

The size of the software FIFO to buffer characters between interrupt service and periodic execution.

Enable auto RTS/CTS

Use the RTS/CTS pins for flow control.[1]


[1] Only available for RS232 serial protocol
