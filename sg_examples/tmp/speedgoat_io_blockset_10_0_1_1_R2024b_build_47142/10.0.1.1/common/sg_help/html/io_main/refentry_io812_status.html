IO812 - Status

IO812 - Status — Status of the ZMI4104 card..

Library

Simulink Real-Time - Speedgoat

Description

This driver block has one output port indicating the status of the ZMI4104C card:

Ports

This driver block has one 20-bit output.

Output Port
Errors

Contains the 20 bits of the VME Error Status 0 register and the 4 lowest bit of the VME Interrupt Enable 1 register. See description at the end of this section.

Parameters

Block setup Tab
ZMI4104C identifier

Select the identifier for the ZMI card identity with 1 for ZMI card one and 2 for ZMI card two.

Measurement axis

Select the axis for the measurement (1 to 4)

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Error Bits
VME Error Status and Interrupt Enable Bits

The following Bits are indicating the 20-bit output of the Status driver block, whereas the first 15 bits are read from the VME Error Status 0 register followed by the 4 lowest bit of the VME Interrupt Enable 1 register :

  • 0 - Power Error

  • 1 - Write Error

  • 2 - Reference Signal Missing

  • 3 - Reference PLL Error

  • 4 - Reset Complete

  • 5 - Reset Failure

  • 6 - FPGA Sync Error

  • 7 - Overtemp Error

  • 8 - Measure Signal Missing

  • 9 - Measure Signal Satured

  • 10 - SSI May Limit

  • 11 - Measure Signal Dropout

  • 12 - Measure Signal Glitch

  • 13 - Acceleration Error

  • 14 - Phase Noise Error

  • 15 - CEC Error

  • 16 - Velocity Error

  • 17 - User Velocity Error

  • 18 - 37-bit Position Overflow

  • 19 - VME 32 bit Position Overflow
