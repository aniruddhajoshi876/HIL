IO602-4 Pin Mapping — Reference information about the I/O module connector

IO602-4 Connection Options

There are two available onboard connector variants for the IO602-4 I/O module: a 25-pin D-sub and a 37-pin D-sub. For both variants there is a 25-pin, respectively 37-pin female D-sub to 4x 9-pin male D-sub cable available.

For proper operation, a CAN topology requires electrical termination in the form of resistors.

The IO602-4 I/O module is delivered with the termination resistors disabled. The termination resistors can be enabled by request at the time of order.

For proper operation, a CAN topology requires electrical termination in the form of resistors.

The IO602-4 I/O module does not include termination resistors. The full resistor comes with the CAN module loopback cable provided by Speedgoat.

The IO602-4 I/O module has no feed-through option. Please use the channels as end-points within a CAN-FD bus in order to ensure optimal performance.
