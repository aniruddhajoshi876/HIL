IO641 - Send

IO641 - Send — Transmits cyclic data to PROFIBUS slaves

Library

Simulink Real-Time - Speedgoat

Description

This block is used to transmit data to the PROFIBUS slaves connected with the IO641 module.

Your model can contain only one Send block for each I/O module in your target machine.

Tip

You can autogenerate the entire data assembly and extraction part for your model including Send, Receive, Packing and Unpacking blocks with the help of the createFromSycon function.

Ports

Inputs

One vector of data type UINT8 which the block writes to the output data area of the dual-port memory. This area contains data which is sent to the PROFIBUS slaves. Use Byte Packing blocks to assemble the vector from specific data. The Number of Bytes parameter sets the length of this vector.

Type: scalar | vector

Data Type: uint8

Outputs

This block does not have any output ports.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Port Type

Always select 1 port with n element vector of type uint8

Number of Bytes

This parameter defines the length of the input port and thus the number of bytes to be written to the module's output data area (TX). Refer to the usage notes to learn how to use this parameter.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.
