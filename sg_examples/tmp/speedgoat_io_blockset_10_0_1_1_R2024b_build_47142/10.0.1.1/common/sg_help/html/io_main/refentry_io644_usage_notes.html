IO644 Usage Notes

IO644 Usage Notes — Usage information about the I/O module

Description

This section describes how to configure the CANopen network.

EDS File

To set up CANopen communication, you must import the device description files of CANopen slaves (EDS file) into your CANopen Master configuration tool or PLC programming tool. Find the EDS file of the IO644 CANopen Slave module here:

>> [speedgoatroot, '\sg_blocks\cifx\eds\CIFX CO COS.eds'].

Front Plate Description

IO644 PCI and PCIe modules

The rotary switch has no functional role.

IO644 mPCIe module

Note that in some real-time target machines, the mPCIe module is reversed; that is, the Error LED appears on the right.
