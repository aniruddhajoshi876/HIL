IO423

IO423 — The IO423 is a Synchro/Resolver to digital converter I/O module

Introduction

The IO423 is a 16-bit Synchro/Resolver to digital converter I/O module with up to 4 channels.

Converter channels featuring:

  • Input ranges: signal conditioning adapters individually built on customer specification

  • Velocity output ±4V

Signal conditioning adapter:

  • Reference oscillator option available

  • High precision option available
