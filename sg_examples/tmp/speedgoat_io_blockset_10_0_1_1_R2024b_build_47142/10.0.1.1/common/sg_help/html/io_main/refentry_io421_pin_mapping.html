IO421 Pin Mapping

IO421 Pin Mapping — Reference information about the I/O module connector

Description

All modules share a unique port (78-pin D-Sub) and the pins associated to the module change with the slot location.

An 80-pin terminal board is provided with the IO421. Pin 79 and 80 are not connected.

Signal descriptions, and operational information are described in the following sections.

The location of each module installed in your IO421, is mentioned in a separate custom document.
