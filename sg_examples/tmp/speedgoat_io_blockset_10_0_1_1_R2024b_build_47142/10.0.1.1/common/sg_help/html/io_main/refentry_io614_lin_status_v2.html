IO614 - LIN Status v2

IO614 - LIN Status v2 — This block provides status information from the LIN channel

Library

Simulink Real-Time - Speedgoat

Description

This block provides status information from the LIN channel.

Ports

Outputs
Op_Mode

This port can have the following values:

  • 0: the board acts as a slave

  • 3: the board acts as a master

Data Types:uint32

Baud Rate

The current configured baud rate.

Data Types:uint32

BusLoad

The current percentage (0..100) of LIN bus load.

Data Types:uint32

Data_Overrun

1 if data overrun occurred.

Data Types:uint32

Init_Mode_Act

1 if LIN controller is still in init mode.

Data Types:uint32

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Get status for channel

Choose the LIN channel to which this driver block should be connected.

Enable OP Mode

Enables the output port for operation mode information.

Enable Baud rate

Enables the output port for baud rate information.

Enable Busload

Enables the output port for busload information.

Enable Data Overrun

Enables the output port for data overrun information.

Enable init mode active

Enables the output port for init mode information.
