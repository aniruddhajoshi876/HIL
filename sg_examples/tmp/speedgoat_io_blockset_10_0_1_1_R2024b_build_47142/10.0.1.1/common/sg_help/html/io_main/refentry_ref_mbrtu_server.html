Modbus RTU Server

Modbus RTU Server — Simulink driver blocks for the native Modbus RTU Server interface

Introduction

Simulink driver blocks for Modbus RTU server enable data to be exchanged with a remote Modbus RTU client. Support for Modbus RTU server is provided with plug-in serial I/O modules.
