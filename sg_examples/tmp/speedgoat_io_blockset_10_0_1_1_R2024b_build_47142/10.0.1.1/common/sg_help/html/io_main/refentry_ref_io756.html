IO756 — Configurable EtherNet/IP Adapter I/O module

Introduction

The IO756 and the IO756-32 are configurable EtherNet/IP Adapter I/O modules. They belong to the IO64X/IO75X I/O module family, which provides support for a wide range of industrial protocols. The IO756 module acts as one EtherNet/IP Adapter exclusively, whereas the IO756-32 simulates up to 32 EtherNet/IP Adapter nodes. The IO756 driver blocks can be used with the IO756 module as well as with the IO756-32 module.
