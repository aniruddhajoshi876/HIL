IO812 - Reset

IO812 - Reset — Reset of a ZMI4104 measurement axis..

Library

Simulink Real-Time - Speedgoat

Description

This driver block resets the desired values of the measurment axis (position, time and error).

Ports

This driver block has three input ports.

Input Ports
Position

If this input value is 1, the position register is reset.

Time

If this input value is 1, the time register is reset.

Axis

If this input value is 1, the complete axis (position, time and error) is reset.

Parameters

Block setup Tab
ZMI4104C identifier

Select the identifier for the ZMI card identity with 1 for ZMI card one and 2 for ZMI card two.

Measurement axis

Select the axis for the measurement (1 to 4)

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
