IO203 - Read

IO203 - Read — Reads the IO203 digital inputs

Library

Simulink Real-Time - Speedgoat

Description

To read the digital inputs, one block per channel group (Lower & Upper) can be added to the Simulink model for each module of this type in your target machine.

Ports

This driver block has no input ports. The output ports can be set to 5 different types:

32 ports of type double

32 output ports of type double are shown. Each port is a scalar with a value of either 0.0 (Low) or 1.0 (High).

32 ports of type boolean

32 output ports of type boolean are shown. Each port is a scalar with a value of either 0 (Low) or 1 (High).

1 port with 32 element vector of type double

One output port of type double is shown. The port has a width of 32 with each element having a value of either 0.0 (Low) or 1.0 (High).

1 port with 32 element vector of type boolean

One output port of type boolean is shown. The port has a width of 32 with each element having a value of either 0 (Low) or 1 (High).

1 port with scalar of type uint32

One output port of type uint32 is shown. The port is a scalar containing all 32 channels as a single uint32 value.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel Group

Select either Lower or Upper as appropriate.

Port Type

Select one of the five available port types.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
