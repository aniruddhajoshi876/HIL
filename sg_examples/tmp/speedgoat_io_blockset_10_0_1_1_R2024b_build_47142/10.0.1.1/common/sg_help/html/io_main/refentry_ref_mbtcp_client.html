Modbus TCP Client

Modbus TCP Client — Simulink driver blocks for the native Modbus TCP Client interface

Introduction

Simulink driver blocks for Modbus TCP Client enable data to be exchanged with an unlimited number of remote Modbus TCP Servers. Support for Modbus TCP Client is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
