DNP3 Server — Simulink driver blocks for DNP3 server

Introduction

Simulink driver blocks for DNP3 server enable data to be exchanged with multiple remote DNP3 clients. Support for DNP3 server is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
