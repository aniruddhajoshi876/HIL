IO512

IO512 — The IO512 I/O module is a serial module supporting the SDLC and HDLC protocols

Introduction

The IO512 I/O module provides 4 fully independent full-duplex serial ports supporting the SDLC and HDLC synchronous protocols.

The buffer size is 32 kByte per direction for each channel.
