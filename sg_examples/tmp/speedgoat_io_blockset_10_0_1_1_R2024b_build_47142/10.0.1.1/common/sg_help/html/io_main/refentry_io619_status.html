IO619 - Status

IO619 - Status — Reads the device status information

Library

Simulink Real-Time - Speedgoat

Description

This block provides status information of the specifed device in the corresponding Setup block.

Ports

Outputs
LAT

Line A trusted status flag.

RLD

Redundant line disturbed status flag.

Line A Error

Counter increments if the device status or process data frame is received on line B but not on line A.

Line B Error

Counter increments if the device status or process data frame is received on line A but not on line B.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Enable Line Errors

Select whether the line error counter output should be available.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
