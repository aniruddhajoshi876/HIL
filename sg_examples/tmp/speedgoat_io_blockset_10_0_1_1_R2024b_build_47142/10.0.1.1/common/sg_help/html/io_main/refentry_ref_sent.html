SENT

SENT — The SENT driver blocks provides transmission and reception of SENT SAE J2716 messages.

Introduction

Speedgoat provides code modules for configurable I/O modules to send or receive SENT SAE J2716 messages. The code modules supports fast messages as well as enhanced serial messages. Additionally, the code modules supports SPC (Short PWM Code) protocol, which enhances the standardized SENT protocol with bidirectional communication.

The following two code modules are available:

  • SENT Tx

  • SENT Rx
