Modbus

Modbus — Speedgoat driver blocks for Modbus

Introduction

Modbus is a communication protocol based on a client-server architecture. Servers provide data in four data tables: Coils, Discrete Inputs, Holding Registers and Input Registers. Clients access servers to read and write data according to a function code. Speedgoat provides UART/Serial and Ethernet as transport layers to use Modbus, all of which come with Simulink driver blocks.

Transport Layers

Modbus RTUModbus RTU interface that communicates over the serial line. Supported with plug-in serial I/O modules. The Modbus protocol stack runs on the target machine's CPU
Modbus TCPModbus TCP interface that communicates over Ethernet. Supported with onboard Ethernet interfaces and plug-in Ethernet I/O modules. The Modbus protocol stack runs on the target machine's CPU
