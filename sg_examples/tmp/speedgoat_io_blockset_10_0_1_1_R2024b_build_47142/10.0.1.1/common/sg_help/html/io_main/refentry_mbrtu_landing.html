Modbus RTU — Speedgoat driver blocks for Modbus RTU

Introduction

Modbus RTU is a serial communication protocol based on a client-server architecture. Servers provide data in four data tables: Coils, Discrete Inputs, Holding Registers and Input Registers. Clients access servers to read and write data according to a function code.

Speedgoat provides a range of serial I/O modules for Modbus RTU communication, all of which come with Simulink driver blocks. The Modbus RTU protocol stack runs on the target machine's CPU, whereas the data exchange on the serial line is being processed by the serial I/O module.
