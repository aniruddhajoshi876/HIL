IO105 - Analog input

IO105 - Analog input — Reads the IO105 analog inputs

Library

Simulink Real-Time - Speedgoat

Description

Your model can only contain one of these blocks for each I/O module in your target machine.

Ports

This driver block has either n scalar output ports or 1 output port with a width of n depending on the setting of the Port type dialog field (where n is the number of selected analog input channels).

If Port type is set to "n ports of type double" the driver block shows n ports with a signal width of 1. Each port (signal) returns the converted A/D value in Volts.

As the IO105 module has a high channel count which can lead to a large number of output ports (see above), you can set Port type to "1 port with n element vector of type double" as an alternative. In this case the driver block just shows one output port of type double but with a signal width of n.

Outputs
X (X is the analog channel number)

The value from analog channel X in volts.

Data Type: double

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Port Type

Select either "n ports of type double" or "1 port with n element vector of type double". The data type is double in both cases. For more information please see the previous 'Inputs and Output' section.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
