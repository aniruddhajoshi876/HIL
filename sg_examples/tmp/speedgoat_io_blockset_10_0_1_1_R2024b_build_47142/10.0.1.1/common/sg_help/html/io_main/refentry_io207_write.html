IO207 - Write

IO207 - Write — Writes the IO207 digital outputs

Library

Simulink Real-Time - Speedgoat

Description

Your model can only contain one or two of these blocks for each I/O module in your target machine.

Ports

This driver block has n input ports, where n is the number of selected digital output channels. The input ports can be set to 4 different types:

  • 32 or 64 ports of type double: 32 or 64 input ports of type double are shown. Each port is a scalar with a value of either 0.0 (low) or 1.0 (high).

  • 32 or 64 ports of type boolean: 32 or 64 input ports of type boolean are shown. Each port is a scalar with a value of either 0 (low) or 1 (high).

  • 1 port with 32 or 64 element vector of type double: One input port of type double is shown. The port has a width of 32 or 64 with each element having a value of either 0.0 (low) or 1.0 (high).

  • 1 port with 32 or 64 element vector of type boolean: One input port of type boolean is shown. The port has a width of 32 or 64 with each element having a value of either 0 (low) or 1 (high).

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Channel Group

Select either Front or Rear as appropriate.

Port Type

Select one of the four available port types.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
