DNP3 Client — Simulink driver blocks for DNP3 client

Introduction

Simulink driver blocks for DNP3 client enable data to be exchanged with multiple remote DNP3 servers. Support for DNP3 client is provided with onboard Ethernet interfaces and plug-in Ethernet I/O modules.
