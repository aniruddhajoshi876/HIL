IO61X - Setup

IO61X - Setup — Setup of parameters for CAN, CAN-FD and LIN channels

Library

Simulink Real-Time - Speedgoat

Description

This CAN and LIN Setup driver block is part of the generic block library for the IO610, IO611, IO612, IO613 and IO614 I/O modules. Your model must contain one CAN and LIN Setup driver block for each module in your target machine.

The Setup block dialog box allows all of the supported CAN I/O modules (IO610, IO612, IO613) and CAN and LIN I/O modules (IO611, IO614) to be configured. It therefore has an impact on all the other driver blocks (CAN Write, CAN Read or LIN Write, LIN Read).

Ports

This driver block has no input or output ports.

Parameters

Main Tab
Module ID

The Module ID has two functions:

  • It defines the logical connection between the Setup block and its I/O blocks

  • It also informs the auto-search feature of the PCI Slot parameter. If only one I/O module of this type is installed, the Module ID must be set to 1. If n modules are installed, it must be in the range 1:n. Not all the I/O modules installed in the target machine need to be used.

Module Type

Select the type of your I/O module installed in your target machine.

PCI Slot (-1: auto-search)

There are two approaches for mapping this block to a specific I/O module installed in your target machine. All modules of the same type must be configured using the same method.

  • Auto-Search: with the default value -1 the I/O module will be automatically located in the target machine. If you have multiple modules of the same kind, the Module ID defines which module is associated with this block. To see how each I/O module maps to a Module ID, use this Speedgoat API: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat")

  • Explicit Addressing: to explicitly define the logical address of the I/O module in the target machine, you can provide the PCI bus and slot numbers as a vector: [bus, slot]. To determine these numbers, run the following command in the MATLAB command window: 

    speedgoat.getIoInterfaces("TargetName", "mySpeedgoat", "Advanced", true)

    Note that the PCI address can change whenever an I/O module is added or removed – usually, auto-search is the best option.

CAN Channel Operation Mode Selection

Configuration of the respective protocol mode for each channel. The available options are:

  • Disabled

  • CAN (HS)

  • CAN-FD

Note

CAN (HS) according to ISO 11898-2 and CAN-FD according to ISO 11898-1

LIN Channel Operation Mode Selection

Configuration of the respective protocol mode for each channel. The available options are:

  • Disabled

  • Slave

  • Master

Note

LIN Channel Operation Mode Selection is only visible if the Module Type is set to IO611 or IO614.

Initialization Structures

Defines CAN messages sent during initialization of the Setup block. For more information, refer to the usage notes

Termination Structures

Defines CAN messages sent during termination of the Setup block. For more information, refer to the usage notes

CAN Channel Setup Tab

The tab for a CAN channel is visible only if the respective CAN channel is enabled in the Main tab.

Nominal Baud Rate

Select the baud rate for CAN (HS) or the arbitration baud rate for CAN-FD. The options are defined according to the hardware configuration.

Note

The User defined option should be used if a baud rate is required that is not configured by default or if a certain sample point is required. Selecting User defined enables the [BRP, SJW, TSEG1, TSEG2] parameter. Refer to the usage notes for more information.

[BRP, SJW, TSEG1, TSEG2]

If the User defined option has been selected with the Standard Baud Rate parameter, this parameter is used to configure the bit timing. The [BRP, SJW, TSEG1, TSEG2] parameter is a vector with the following elements:

  • Bit Rate Prescaler (BRP)

  • Synchronization Jump Width (SJW)

  • Time Segment 1 (TSEG1)

  • Time Segment 2 (TSEG2)

Refer to the usage notes for more information.

Flexible Data Baud Rate

This parameter is only available if the CAN-FD option is chosen with the CAN Channel parameter. The options are defined according to the Hardware configuration.

Note

The User defined option should be used if a baud rate is required that is not configured by default or if a certain sample point is required. Selecting User defined enables the [BRP, SJW, TSEG1, TSEG2] parameter.

[BRP, SJW, TSEG1, TSEG2]

The principle is the same as for Nominal Baud Rate.

LIN Channel Setup Tab

The tab for a LIN channel is visible only if the respective LIN channel is enabled in the Main tab.

Baud Rate

This parameter is valid for Master and Slave operation. Range between 1 000 and 20 000
