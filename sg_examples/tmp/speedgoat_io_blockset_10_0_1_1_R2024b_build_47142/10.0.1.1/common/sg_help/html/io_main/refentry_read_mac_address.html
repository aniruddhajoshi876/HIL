Read MAC address

Read MAC address

Library

Simulink Real-Time - Speedgoat/Utilities

Description

This block reads the MAC address of the target machine's Host Link Ethernet port.

The block inherits the sample time. It only gets executed once at model start.

Supported Target Machines

  • Speedgoat Mobile real-time target machine

  • Speedgoat Performance real-time target machine - Core

  • Speedgoat Baseline real-time target machine (R2019a or later)

Ports

Outputs
MAC

The MAC address has a vector of uint8 with 6 elements. Every element contains one octet of the MAC address.
