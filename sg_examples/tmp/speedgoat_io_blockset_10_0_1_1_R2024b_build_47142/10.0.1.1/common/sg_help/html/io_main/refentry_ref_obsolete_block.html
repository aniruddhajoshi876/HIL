Speedgoat Obsolete Block

Library

Simulink Real-Time - Speedgoat

Description

This block replaces Speedgoat driver blocks that are not supported in a specific MATLAB release.

Supported Releases

This block is used from MATLAB release R2020b. A detailed overview of the driver blocks not supported is available in the release notes of the corresponding Speedgoat I/O Blockset.

Parameters

This block does not have any parameters to define. Each parameter stored in the block that has been replaced will appear in the Speedgoat Obsolete Block mask with the last value set in the release where the model was saved. Refer to the image below for an example of the IO121 Analog output block.
