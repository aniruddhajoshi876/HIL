CAN Database Parser

CAN Database Parser — CAN Read and Write messaging supporting database parsing

Introduction

Automotive network engineers frequently use *.dbc files to describe nodes, messages and signals of CAN (HS) and CAN-FD networks. The CAN DB Parser Read and Write blocks have been introduced to simplify the workflow when *.dbc files are required. The main features (and additional comments) are listed below:

  • The CAN DB Parser Read and Write blocks consist of subsystems dynamically populated with input/output ports, CAN and CAN FD unpack/pack blocks, standard CAN Read/Write blocks and the interconnecting lines

  • A Database Manager tool has also been introduced. Its purpose is to parse a *.dbc file and generate a Simulink library containing a set of corresponding preconfigured CAN/CAN FD pack/unpack blocks. The Simulink library is generated in the current folder and is used by the CAN DB Parser Read and Write blocks to populate the subsystems

  • When a CAN DB Parser Read or Write block is placed in a model, the link to the library is broken

  • A subsystem can be accessed (Ctrl+u) and modified after generation, however if the user presses the OK or Apply buttons of the CAN DB Parser Read or Write block, the content of the subsystem will be cleared and recreated. Any modifications made by the user will also be deleted
