IO812 - Position and Time

IO812 - Position and Time — Real all Position and Time of selected axis from one ZMI4104 card.

Library

Simulink Real-Time - Speedgoat

Description

This driver block returns the desired position and/or velocity of the selected measurement axis upon input enable.

Ports

This driver block can have from zero to up to 16 output ports, depending on the selected measurment values in the mask.

Outputs Port
Axis n

Contains the n velocity measurment value for the position of the selected axis. Axis 1-4 for card one, axis 5-8 for card two.

Time n

Contains the n time measurment value for the position of the selected axis. Axis 1-4 for card one, axis 5-8 for card two.

Parameters

Block Setup Tab
Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Measurment Tab
Velocity measurement

Adds one output port to measure the velocity. This measurement requires one 32-bit PCI read.

Time measurement

Adds one output port to measure time. This measurement requires one 32-bit PCI read.
