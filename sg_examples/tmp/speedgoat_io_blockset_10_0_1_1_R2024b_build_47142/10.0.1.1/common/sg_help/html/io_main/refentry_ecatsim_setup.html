EtherCAT SubDevice Emulator - Setup

EtherCAT SubDevice Emulator - Setup — Configures the EtherCAT network to be emulated on one Ethernet interface

Library

Simulink Real-Time - Speedgoat

Description

The Setup block sets up the emulation of one EtherCAT network containing multiple EtherCAT subordinate devices. An EtherCAT network is defined in a configuration file called the EtherCAT network information file (ENI). The emulator only works in conjunction with an existing ENI file. Use EtherCAT tools such as Beckhoff's TwinCAT or Acontis' EC-Engineer to configure EtherCAT networks and export ENI files. Every EtherCAT subordinate device to be emulated requires a runtime license.

Note

In the Ethernet Configuration Tool, select EtherCAT for the interface that will be used with the EtherCAT Emulator. Enter the following in the MATLAB command window to open the tool: 

>> speedgoat.configureEthernet

Ports

Inputs

This block does not have any input ports.

Outputs

This block does not have any output ports.

Parameters

Tab: General
Interface ID

The Interface ID is used to assign EtherCAT Emulator blocks to a particular Ethernet interface. The number is the position of the interface in the list shown in the Ethernet configuration tool. Performance real-time target machine: The first available interface (after the host-link) used for the EtherCAT Emulator has ID 1. All other machines: The first available interface (after the host-link) used for the EtherCAT Emulator has ID 2.

You can simulate multiple EtherCAT networks: one network must be assigned to one Ethernet interface.

First Device

The emulator emulates the subordinate device specified by the station address in this parameter, along with all subsequent devices listed in the ENI file. Setting this parameter to -1 will cause the emulator to simulate all devices defined in the ENI file.

This parameter is useful for excluding specific devices at the beginning of the topology—such as Beckhoff’s EK1110 extension module or other modules connected directly to the EtherCAT main device—that should not be emulated.

Configuration File

The path to the ENI file on the host PC. Enter an absolute path to the file or use a function to obtain a relative path.

'C:\projects\myeni.xml'
[pwd, '\..\myeni.xml']

Instead of typing the path to the file manually, click the Select Configuration File (ENI/EXI) button and simply select the file.

Type: char
