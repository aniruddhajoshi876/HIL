ARINC 825 - Update Scheduled Message

ARINC 825 - Update Scheduled Message — Update scheduled messages

Library

Simulink Real-Time - Speedgoat

Description

This block updates the specified scheduled message(s). Multiple blocks can be used per channel.

Ports

Inputs
Data

CAN(-FD) message(s) with the corresponding ID to update.

CAN-FD message:

  • Protocol Mode: Not used (Predefined in the Setup block)

  • Extended: Not used

  • Length: Number of data bytes

  • Remote: Not used

  • Error: Not used

  • BRS: Not used (Predefined in the scheduled messages table in the Setup block)

  • ESI: Not used

  • DLC: Not used

  • ID: Message ID

  • Timestamp: Not used

  • Data: Payload data vector

Enable

Enable/Disable CAN message(s) updates.

Parameters

Module Type

Select the type of your I/O Module installed in your target machine.

Module ID

This ID defines the link to the corresponding Setup block

Channel

Select the channel to which this driver block corresponds.

Message ID

Specify the 29-bit ID of the message(s) to be updated.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Show Enable Input

Select whether the enable input is active. Otherwise messages are always updated.
