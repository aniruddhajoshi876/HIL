EV - Setup

EV - Setup — Configures one EV charging board

Library

Simulink Real-Time - Speedgoat

Description

The EV Setup block configures one EV charging board, establishing the MQTT connection to the EV Charging box using the configured IP address and allowing the configuration of some static base parameters. These parameters can be adjusted throughout the charge cycle.

Ports

This driver block has no input or output ports.

Parameters

The two tabs of the setup parameter dialog box contain the configuration settings for the EV charging board.

Main Tab
Station ID

The Station ID is used to assign Setup, Read and Write blocks to a particular MQTT client station. Station IDs range between 0 to 65535 and must be unique along all Setup blocks in a model. You can define multiple clients by placing a Setup block with a unique Station ID for each client.

Connection ID

The Connection ID is used to assign Publish and Subscribe blocks to a particular client-broker connection. Connection IDs range between 0 to 65535 and must be unique along all Connections blocks of the client (these blocks have the same Station ID).

Client Identifier

The Client Identifier represents the MQTT client in the local network and must be unique along all clients in that network. The parameter is a character array with a length limit of 256.

Local IP Address

Enter the IP address of the MQTT client. This step does not assign the IP address to an Ethernet interface; instead, it binds the Setup block to an IP address, which was previously configured in the Ethernet Configuration Tool. Refer to the MQTT usage notes for further information.

Sample Time

Defines the base sample time at which data is exchanged with the EV charging board. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Remote TCP Port

Enter the TCP port the remote MQTT broker is listening on for connection requests. The default value is 1883.

Remote IP Address

Enter the IP address of the EV charging board.

Vehicle Configuration Parameters Tab
Departure Time [s]

Defines the expected departure time of the vehicle from the charging station in seconds from now.

Max. Voltage Limit [V]

Defines the maximum voltage limit of the EV's charge interface in volts.

Max. Current Limit [A]

Defines the maximum current limit of the EV's charge interface in amperes.

Min. Current Limit [A]

Defines the minimum current limit of the EV's charge interface in amperes.

Max. Power Limit [W]

Defines the maximum power limit of the EV's charge interface in watts.

RESS SOC

Defines the current state of charge (SoC) of the EV's rechargeable energy storage system (RESS).

Energy Capacity

Defines the total energy capacity of the EV's rechargeable energy storage system (RESS) in watt-hours.

Energy Request

Defines the energy amount in watt-hours the EV will request from the charge station.

Full SOC

Defines the state of charge (SoC), in percentage, that the EV considers fully charged. Typically 100.

EV Bulk SOC

Defines the state of charge (SoC), in percentage, at which the EV's bulk charge is complete. Typically 80.
