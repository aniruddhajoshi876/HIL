SPI

SPI — SPI master, slave and sniffer code modules for configurable I/O modules

Introduction

Speedgoat provides two SPI code modules for the IO3xx configurable I/O modules.

  • SPI - Master and Slave functionality

  • SPI Sniffer - For monitoring an existing SPI communication

These are described in the following sections in more detail.

Driver Blocks

  • MasterSlave v1

  • MasterSlave v2

  • Sniffer v1

Usage Notes

  • CPOL and CPHA

  • Timing Diagram

  • SPI Transfer Timing with synchronized Master

  • SPI Transfer Timing with non-synchronized Master when sample time is bigger than SPI frame length

  • SPI Transfer Timing with non-synchronized Master when sample time is smaller than SPI frame length

  • SPI Transfer Timing with Slave when sample time is bigger than SPI frame length

  • SPI Transfer Timing with Slave when sample time is smaller than SPI frame length

Examples

  • IO3xx SPI - Loopback Master Sync

  • IO3xx SPI - Loopback Master Sync Multislave
