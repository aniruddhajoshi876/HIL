Serial

Serial — The Serial (UART) driver blocks enable serial communications on configurable I/O modules

Introduction

The Serial (UART) driver blocks enable serial communications for standards such as RS232, RS485 and RS422 on configurable I/O modules.

Driver Blocks

  • Setup v1

  • Read HW FIFO v1

  • Read Frame v1

  • Write HW FIFO v1

  • Setup v2

  • Read HW FIFO v2

  • Write HW FIFO v2

  • Read Character Timeout Status v1

Examples

  • IO3xx Serial - Loopback

  • IO3xx Serial - Loopback Interrupt

  • IO3xx Serial - Loopback Halfduplex
