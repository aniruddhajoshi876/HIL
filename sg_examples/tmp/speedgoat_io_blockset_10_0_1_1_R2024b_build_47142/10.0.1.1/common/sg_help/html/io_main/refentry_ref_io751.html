IO751 — Configurable PROFINET Controller I/O module

Introduction

The IO751 is a configurable PROFINET Controller I/O module. The solution is part of the IO64X/IO75X I/O module family which provides support for a wide range of industrial protocols. The IO751 module acts as one PROFINET Controller exclusively.
