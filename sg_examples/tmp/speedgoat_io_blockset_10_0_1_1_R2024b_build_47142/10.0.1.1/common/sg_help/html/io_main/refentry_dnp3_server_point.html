DNP3 - Server Point

DNP3 - Server Point — Reads and writes data in local point groups

Library

Simulink Real-Time - Speedgoat

Description

This block is used to read and write data to point groups in the local DNP3 server. Furthermore, the block indicates control requests from the client.

Ports

Inputs
Enable

Available only with write operation.

If set to 1, the block writes the values at the Value input port to the specified point range. This is done at each sample hit according to the block's sample time.

Data Type: boolean

Value

Available only with write operation.

Array of length Quantity that is written to the point range specified by the Command, Index and Quantity parameters. The data type depends on the selected command.

The two bits of a double-binary value are encoded as one uint8.

Data type: boolean | uint8 | int16 | uint16 | int32 | uint32 | single | double

Outputs
New Data

Available only with analog and binary control indications.

Array of length Quantity that indicates new data for each data point specified by the Index and Quantity parameters.

Data type: boolean

Value

Available only with analog control indications.

Array of length Quantity that includes the control values received from the client for the point range specified by the Index and Quantity parameter.

Data type: double

Control Code

Available only with binary control indications.

Outputs the control code received for the point specified by the Index parameter.

For further information refer to the DNP3 Client Command block help documentation.

Data type: uint8

Count

Available only with binary control indications.

Outputs the repetition counter for the point specified by the Index parameter.

For further information refer to the DNP3 Client Command block help documentation.

Data type: uint8

Time On

Available only with binary control indications.

Outputs the on-time for the point specified by the Index parameter.

For further information refer to the DNP3 Client Command block help documentation.

Data type: uint32

Time Off

Available only with binary control indications.

Outputs the off-time for the point specified by the Index parameter.

For further information refer to the DNP3 Client Command block help documentation.

Data type: uint32

Parameters

Server ID

Apply the Server ID of the corresponding Server Setup block. Must range between 0 and 65519.

Operation Mode

Select the operation mode of the block. You can either write data to specific point groups or indicate control requests from the client.

Refer to the DNP3 usage notes for an overview of the supported groups.

Index

The first index of the point range you want to read or write. Must range between 0 and 999.

Quantity

The length of the point range you want to read or write. Index + Quantity must not exceed 1000.

The parameter is ignored for binary control indications.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
