IO117 — 16-bit analog module with 32 galvanically isolated input channels

Introduction

The IO117 is a 16-bit analog module providing 32 single-ended or 16 differential analog input channels, which are galvanically isolated.

  • 32/16 analog input channels featuring:

    • Single-ended (32 channels) or true differential (16 channels) inputs

    • Galvanic isolation for all channels

    • Voltage ranges of ±1V, ±2V, ±5V, ±10V (selectable for every channel)
