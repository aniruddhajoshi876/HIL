IO750 - Send

IO750 - Send — Transmits cyclic data from the subordinate device to the EtherCAT network

Library

Simulink Real-Time - Speedgoat

Description

This block is used to transmit cyclic data from the subordinate device to the EtherCAT network. You can only use one EtherCAT SubDevice Send block for each physical module installed.

If you are using configuration files, note that in SYCON.net the data input and output convention is referenced to the main device side. "Input Data Bytes" are the output bytes for the EtherCAT subordinate device (RxPdo).

Ports

Depending on the value of the Port Type parameter, this block will have:

  • n input ports of type uint8, where n is defined by the Output Data Bytes parameter, or

  • 1 input port which is a vector with n elements, where n is defined by the Output Data Bytes parameter

Inputs
1

Data byte to send. Type uint8.

X (X is the port number between 1 and the value of the Output Data Bytes parameter)

Data byte to send. Type uint8.

Inputs
Out

A vector of data bytes to send. The number of elements in the vector is defined by the Output Data Bytes parameter.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Port Type

The type of the input/output ports. The options are:

  • n ports of type uint8 to have an input/output port for each signal

  • 1 port with n element vector of type uint8 to have a single vector with an element for each signal

Output Data Bytes

The number of bytes to receive from the main device. This parameter in SYCON.net is named "Input Data Bytes" because it refers to the main device side.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Caution

All blocks that interface with the same I/O module must have identical sample times.
