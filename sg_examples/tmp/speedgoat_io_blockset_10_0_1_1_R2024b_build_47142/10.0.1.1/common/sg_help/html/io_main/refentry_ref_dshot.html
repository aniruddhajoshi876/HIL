Dshot

Dshot — The Dshot driver blocks transmits and receives Dshot messages.

Introduction

Speedgoat provides code modules for configurable I/O modules to send or receive Dshot messages supporting Dshot 150, Dshot 300, Dshot 600 and Dshot 1200. Additionally, the code modules offer the choice between an automatic and manual telemetry bit setting.

The following two code modules are available:

  • Dshot Tx

  • Dshot Rx
