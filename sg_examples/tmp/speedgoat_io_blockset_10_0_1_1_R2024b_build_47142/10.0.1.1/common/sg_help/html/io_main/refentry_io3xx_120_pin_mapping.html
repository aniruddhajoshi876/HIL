-120 Pin Mapping

-120 Pin Mapping — Reference information about the I/O module connector

Description

The -120 I/O interface extension provides:

  • 16 x 16-bit analog inputs up to 1.5 MSPS sampling rate with simultaneous sampling

  • 16 x 16-bit analog outputs up to 10 MSPS update rate
