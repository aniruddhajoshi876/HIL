IO611 - LIN Master Write v2

IO611 - LIN Master Write v2 — Send messages over LIN

Library

Simulink Real-Time - Speedgoat

Description

This block allows LIN messages to be transmitted. The message information (LIN version, ID, DLC) can be set in the block mask.

The buffer size is 20 messages per channel, so depending on the selected baud rate and the "LIN Master Write" block sample times, it is important to not let the input buffer overflow.

For each LIN message a single write block is required.

Ports

Inputs
Data

The number of bytes is defined in the block mask with the parameter DLC. Data Type: uint8

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Send message with channel

Choose the LIN channel to which this driver block should be connected.

Message Type

Currently only the message type RAW is supported.

LIN Version

Select the LIN version:

  • LIN 1.X representing versions 1.1, 1.2 and 1.3 uses Classic Checksum.

  • LIN 2.X representing versions 2.0, 2.1 and 2.2 uses Enhanced Checksum except for IDs 60 and 61.

Identifier

Message ID of the LIN message without parity protection. Valid values are in the range 0 through 63.

Caution

LIN specifies the Protected ID (PID) to be a 8-bit value, where bits 7 and 8 contain parity sums over the other bits. The ID therefore consists of bits 1 through 6.

DLC

Identifies the length of the LIN message data array (Data Length Code). The value can be chosen in the range of 1 through 8.

Caution

LIN version 1.1 defines the DLC as a function of the ID (0-31: 2; 32-47: 4; 48-63: 8).
