Warning

The maximum voltage applied to any single pin in analog input is ±12 V.

Important

Unused analog input pins must be connected to Analog Ground.

0 V is internally connected to the ground of the target machine, whereas analog ground is connected to the ground of the I/O module. 5 V are supplied by the real-time target machine, which is capable of providing 1 A continuous current. For more information, refer to the real-time target machine user manual.
