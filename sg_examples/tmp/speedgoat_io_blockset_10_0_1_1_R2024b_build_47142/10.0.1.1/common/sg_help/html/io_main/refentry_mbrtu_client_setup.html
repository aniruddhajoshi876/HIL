Modbus RTU - Client Setup

Modbus RTU - Client Setup — Configures one Modbus RTU client node

Library

Simulink Real-Time - Speedgoat

Description

The Setup block configures one Modbus RTU Client node, which can be connected to Modbus RTU Servers and enables the Send and Receive blocks to exchange data on the serial line. Every Modbus RTU Client Setup block in the model requires a runtime license.

For serial interface configuration, the Modbus RTU Client Setup block requires the Setup block of the corresponding serial I/O module to be placed in the model. If you use an IO503, for example, add an IO503 Setup block to the model and make sure both Setup blocks have the same Module ID.

Ports

This driver block has no input or output ports.

Parameters

Physical Layer
Serial Interface

Select the type of the serial interface you want to use for Modbus communication. The list consists of supported serial I/O modules.

Module ID

Enter the Module ID of the related serial module's Setup block.

Channel

Enter the channel number of the serial I/O module to which you want to assign the Modbus RTU client node.

Parameters
Interface ID

The Client Setup block defines one Modbus RTU client interface bound to a specific serial channel. The interface ID is used to assign Setup, Send and Receive blocks to that interface. Interface IDs range between 0 to 65535 and must be unique along all Modbus RTU Client and Server setup blocks in a model. You can define multiple clients by placing multiple Setup blocks in your model with unique interface IDs for each client.

Automatic Interface ID

The automatic interface ID checkbox enables the automatic generation of a unique interface ID, based on the above physical layer selection.

Response Timeout

Specifies the time in milliseconds that the client should wait for a response from the server before sending another request. The response to the initial request is ignored if it is received after the time has elapsed.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
