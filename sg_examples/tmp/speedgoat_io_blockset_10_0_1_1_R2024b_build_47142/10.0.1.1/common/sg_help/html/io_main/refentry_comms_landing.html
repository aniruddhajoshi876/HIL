Communications Protocols — Speedgoat I/O modules for Communications Protocols

Introduction

To communicate with your devices, Speedgoat supports a wide range of industrial protocols either using dedicated I/O modules or using code modules. All solutions are ready to use out of the box, installed into a real-time target machine and supplied with Simulink® driver blocks for a seamless easy-to-use workflow.

  • ARINC 429, ARINC 629 and AFDX

  • CAN FD, CAN, J1939 and LIN

  • CANopen

  • DNP3

  • EtherCAT

  • EtherNet/IP

  • Ethernet Interfaces

  • EV Charging

  • FlexRay

  • GNSS (GPS, GLONASS etc.)

  • I2C

  • IEC 61850

  • MIL-STD-1553

  • Modbus

  • MQTT

  • MVB

  • OPC UA

  • POWERLINK

  • PROFIBUS

  • PROFINET

  • PSI5 and wheel speed sensor protocols

  • PTP

  • Restbus

  • Shared Memory

  • Raw Ethernet

  • Real-Time UDP

  • SCPI

  • SDLC and HDLC

  • SPI

  • SSI

  • Serial

  • TCP

  • TSN

  • XCP
