EVSE - Isolation Read

EVSE - Isolation Read — Reads data from the EVSE board during the Isolation state of the charge cycle.

Library

Simulink Real-Time - Speedgoat

Description

The EVSE Isolation Read block reads data from the EVSE charging board during the Isolation state of the charge cycle.

Ports

Outputs
EV Ready

Indicates if the EV is ready to charge generally.

  • 0: not ready

  • 1: ready

EV Errorcode

Errorcode following enumeration table "DC_EVErrorCodeType" ISO 15118-2:

  • 0: EV_NO_ERROR

  • 1: EV_FAILED_RESS_TEMPERATURE_INHIBIT

  • 2: EV_FAILED_EV_SHIFT_POSITION

  • 3: EV_FAILED_CHARGER_CONNECTOR_LOCK_FAULT

  • 4: EV_FAILED_EVRESS_MALFUNCTION

  • 5: EV_FAILED_CHARGING_CURRENTDIFFERENTIAL

  • 6: EV_FAILED_CHARGING_VOLTAGE_OUT_OF_RANGE

  • 7: EV_RESERVED_A

  • 8: EV_RESERVED_B

  • 9: EV_RESERVED_C

  • 10: EV_FAILED_CHARGING_SYSTEM_INCOMPATIBILITY

  • 11: EV_NO_DATA

EV RESS SOC

Current state of charge (SoC) of the EV's rechargeable energy storage system (RESS).

Parameters

Station ID

Defines the Station ID of the corresponding Setup block. Must range between 0 and 65535.

Connection ID

Defines the Connection ID of the corresponding Setup block. Must range between 0 and 65535.

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
