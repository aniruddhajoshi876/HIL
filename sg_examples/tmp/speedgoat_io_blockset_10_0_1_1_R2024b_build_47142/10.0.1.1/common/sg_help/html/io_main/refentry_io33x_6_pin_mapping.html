IO33X-6 Pin Mapping

IO33X-6 Pin Mapping — Reference information about the I/O module connector

Description

The IO33x-6 provides 16x 16-bit 500kHz A/D converters, 8x 16-bit D/A converters with 10µs settling time and 16x digital TTL I/O lines.
