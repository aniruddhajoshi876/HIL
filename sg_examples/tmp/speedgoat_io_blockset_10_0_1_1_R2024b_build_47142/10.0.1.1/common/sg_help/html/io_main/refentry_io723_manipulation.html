IO723 - Manipulation

IO723 - Manipulation — Controls the configured manipulations

Library

Simulink® Real-Time™ - Speedgoat

Description

This block controls the configured manipulations from the database. Each manipulation can be controlled individually or combined in a sequence of manipulations.

Ports

Inputs
Manipulation (boolean)

Enable the manipulation indicated by the block port label.

Manipulation (Bus)

Control the manipulation indicated by the block port label. If the source of the manipulation values is the block input port, a bus with the following elements is used:

  • Enable

  • Value1

  • Value2

  • Value3

Note

Depending on the manipulation type, not all manipulation values are used.

Sequence

Select one of the configured sequences. A value of 0 disables all sequences; if a specified sequence is selected, the manipulation enable input has no effect.

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.

Manipulation Value Source

Select whether the manipulation values should be taken from the database or read from the block input port.
