IO191 - Digital input

IO191 - Digital input — Reads the IO191 digital inputs

Library

Simulink Real-Time - Speedgoat

Description

Your model can only contain one of these blocks for each I/O module in your target machine.

Ports

This driver block has n double-type scalar output ports, where n is the number of selected digital input channels. Each port (signal) returns the read digital value.

Outputs
X (X is the digital input channel number)

The following values are obtained from digital input channel X:

  • 0 - TTL low

  • 1 - TTL high

Data Type: double

Parameters

Module ID

This ID defines the link to the corresponding Setup block

Sample Time

Defines the base sample time at which this driver block gets its sample hit. This parameter can also be set to -1 for inherited sample time. The units are in seconds.
