Release Notes

Release Notes — Changes, rectifications and software support for new products.

About the Speedgoat I/O Blockset

The Speedgoat I/O Blockset contains all the driver blocks and functions required to use Speedgoat hardware with Simulink® Real-Time™. Each Speedgoat I/O Blockset is available for the last six MATLAB® releases and can be downloaded from the Speedgoat Customer Portal: speedgoat.com/login.

For additional information about new products, please contact Speedgoat Sales.

Software Support for New Products

    • Added support for the following new signal conditioning modules:

Feature Improvements

  • Battery Management Testing System (BMTS): BMTS Setup driver block

    • Added functionality to configure gain and offset correction values for each BCE cell

  • Configurable I/O: Introduced the following driver blocks

    • Cam and Crank Angle v4 driver block

      • Provides a common angular position reference for the Events Capture v4 and Variable Reluctance Sensor v4 driver blocks

    • Cam and Crank Events Capture v4 driver block

      • The new block introduces the following features:

        • Capturing cam- and crank-related digital pulses in the angular domain, including pulse duration in seconds

        • Sorting captured events based on the order of occurrence

        • Windowing to suppress pulses outside the defined angular range

    • Cam and Crank Variable Reluctance Sensor v4 driver block

      • The new block introduces the following features:

        • Emulates variable reluctance sensor analog output signals for cam and crank tooth wheels

        • Lookup table–based signal generation referenced to the crank angle

        • Switching between four lookup tables during runtime to emulate fault scenarios

        • Custom lookup table configuration or predefined cam or crankshaft patterns

  • ARINC 429 Parser

    • Added an ARINC 429 Parser tool that supports the IO682 module. The tool imports ARINC 429 communication databases and automatically configures driver blocks and message schedules in Simulink

    • The tool provides a graphical mapping application to associate Simulink signals with ARINC 429 signals

    • It also performs validation checks for database and mapping configurations to help detect configuration errors before deploying the model

    • The ARINC 429 Parser is particularly suitable for avionics and test engineers working with complex ARINC 429 networks who want to accelerate setup and ensure consistent, repeatable configurations

  • IO723: Driver blocks

    • Added support for non-physical CAN signals

    • Added support for the LIN automotive bus interface

    • FL3X Config feature support:

      • Added support to control signal manipulation and manipulation sequences

      • Added support to control global variables

  • Onboard Serial driver blocks: Custom baud rates (Pulse real-time target machine)

    • Added option to define custom baud rates for RS-232 and RS-422/485 communication within the supported range. A runtime license is required to use this feature

  • Performance PCIe+ real-time target machine

    • Added support for the Performance PCIe+ real-time target machine (Item ID 109400) on MATLAB R2026a

    • Enhanced the block mask interface and usability

Software Support for New Products

  • IO337-650k: New Simulink-programmable FPGA and configurable I/O module with analog and digital I/O capabilities

    • The IO337 I/O module supports 32 fast, single-ended analog outputs, 8 differential simultaneous sampling analog inputs, and 4 LVDS digital I/O lines. The I/O capabilities can be increased by adding an I/O interface extension (-21, -22, or -24)

    • The module also features an AMD Zynq UltraScale+ MPSoC, and the programmable logic has 650k logic cells to accommodate large and complex designs

    • The IO337 is ideal for HIL applications requiring a high number of fast analog outputs, for example, in the automotive and power electronics industries

    • Enables emulation of up to 256 EtherCAT subordinate devices in a single model on a single Ethernet interface for programmable logic controller (PLC) testing
