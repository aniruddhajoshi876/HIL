I/O Connectivity

Introduction

Speedgoat offers a vast range of I/O connectivity options to connect your real-time target machine with your hardware for real-time simulation and testing. I/O modules are installed into your real-time target machine and come with Simulink® driver blocks and full documentation. The majority also include a set of I/O cables and terminal boards. The range of I/O modules includes:

  • 150+ fixed-functionality I/O modules

  • Simulink-programmable FPGA I/O modules with automatic HDL code generation using HDL Coder™ from MathWorks®

  • Configurable I/O modules providing I/O connectivity and communication protocols
