# Controller HIL Testing for Three-Phase PMSM with Two-Level Inverter

**About**

This reference example showcases model-in-the-loop (MIL) and hardware-in-the-loop (HIL) testing of field-oriented control (FOC) running on a F28379D LaunchPad™ development kit for C2000™ Delfino™ MCU by Texas Instruments. The motor drive consists of a three-phase two-level inverter and a Permanent Magnet Synchronous Motor (PMSM).

----------

**Learn how to:**

- Model and simulate and high-fidelity PMSM drive system digital twin, including ripples and switching harmonics
- Set up a HIL test system for testing FOC running on target hardware
- Perform interactive motor controller testing with Simulink® and MATLAB®
- Expedite motor controller development with automated and continuous HIL testing 

----------

**Getting started**

    1. Open MATLAB and open Simulink Project File
    2. Click in 'Getting Started' project shortcut
    3. Follow the steps in the live script documentation
